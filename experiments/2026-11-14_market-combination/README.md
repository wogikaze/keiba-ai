# 市場（10 分前）とオッズなしモデルの結合

オッズを使わないモデル（`experiments/2026-11-14_lgbm-nomarket/` の A・B・C と、ここで作る線形の条件付きロジット）が、
発走 10 分前の市場（`experiments/2026-11-14_market-baseline/` の推奨参照: 10 分前の中間オッズ × power_fit、k は train で推定）に
情報を足すかを測る。分割・対象・参照の決め方は [ADR 0003](../../docs/adr/0003-provisional-split-and-features.md)。

コード: `run.py`（この実験）、`src/keiba_ai/market_offset.py`（レース内 softmax の目的関数、条件付きロジット、標準化）、
テストは `tests/test_market_offset.py`（勾配・ヘッセ行列の差分チェック、合成データでの残差学習）。

## 仮説

（実行前に書いた）

1. **Benter の 2 段階で α は正で 0 と区別できるが、改善は小さい。** valid（約 1 万レース）で当てはめると、
   A・B・C の α は 0.1〜0.3（SE 0.03 前後）、β は 0.85〜1.0。test の結合 − 市場の ΔlogLoss は −0.002〜−0.008 で、
   レース単位の CI は 0 を含まないが、開催日単位の CI は 0 に近づく。
   オッズなしモデルの情報（過去成績・騎手など公開情報）の大半は 10 分前の市場にすでに入っている。
   10 分前の市場は確定より 0.038 悪い（market-baseline）ので、足せる余地はあるが、その差の大半は締切直前の投票の情報で、
   公開の過去成績からは取れない。
2. **市場オフセットの LightGBM は Benter の結合と同程度（Δ ≈ −0.003〜−0.010）。** 非線形に残差を学べるぶん少し良いかもしれないが、
   オッズを特徴量に入れないので、オッズ帯ごとの較正のずれ（大穴の買われすぎ）は学べない。学習した補正 f の SD は 0.1〜0.3。
3. **線形の条件付きロジット（24 列 + 欠損指示）は test logloss 2.09〜2.13 で LightGBM より悪く、α も小さい。**
4. **プラセボ: レース内で並べ替えたモデルは α ≈ 0（|α| < 2 SE）、Δ ≈ 0 か少し正。**
   **リークの陽性対照（確定オッズを「モデル」に入れる）は α が大きく（≈ 1 以上）、β は小さいか負、Δ ≈ −0.03〜−0.04**
   （確定 − 10 分前の差 −0.038 に近い）。これが「リークがあるとこう見える」の目安になる。
5. **賭け（戦略ではなく健全性の確認）: p·odds > 1.0 / 1.1 / 1.2 の均等賭けの ROI は −0.15〜−0.30 で、CI に 0 を含まないか、
   含んでも点推定は控除率の水準。** α が小さければ、市場との差は主にモデルの誤差で、p·odds > 1 の馬は「モデルが買いかぶった馬」になる。

## 変更点

- 比べるレース: market-baseline の共通レース（60・30・10・5 分前・最後の中間・確定のすべてで全出走馬のオッズがある）のうち、
  A・B・C の予測と features_v1 が全出走馬にあり、勝ち馬のいるレース。**すべてのモデルを同じレースで比べる**（件数は結果に書く）。
- 市場の参照: 10 分前 × power_fit。k は market-baseline と同じ集合（共通レースの train）で当てはめ、値が一致することを確かめる。
- Benter の 2 段階: p ∝ exp(α·log p_model + β·log p_market) を **valid** で当てはめ（A・B・C の train 行は学習データ上の予測なので使わない）、
  test で結合 − 市場の ΔlogLoss を測る。CI はレース単位と開催日単位のクラスタブートストラップ（2000 回）。
- 市場オフセットの LightGBM（graphite278 の方法を再実装）: init_score = log p_market（学習・valid・test のどの行も 10 分前のオッズ、
  確定オッズは使わない）、目的関数はレース内 softmax の自作（勾配 p − t、対角ヘッセ p(1−p)）。特徴量は features_v1 の 81 列すべて
  （オッズ・人気はない）。train で学習、valid の race logloss で early stopping。
- 条件付きロジット: features_v1 から 24 列（lgbm-nomarket の gain 上位の数値列。レース内で一定の列は除く）を train の統計で標準化、
  欠損は中央値 + 欠損指示変数、L2 は {0, 1e-4, 1e-3, 1e-2} から valid の logloss で選ぶ。train で当てはめ、そのあと Benter で市場と結合。
- プラセボ: (a) valid と test の両方でモデルの確率をレース内で並べ替えて α を当てはめ直す（10 回）。
  (b) **デモ**: 確定オッズの比例正規化を「モデル」として結合する（リークの見え方の陽性対照。使ってはいけない）。
- 賭けの健全性: valid の logloss が最小の結合モデル（test では選ばない）で、p·(10 分前のオッズ) > 1.0 / 1.1 / 1.2 の馬を 1 単位ずつ買い、
  HR の単勝払戻金で払い戻す。判断の確率は決定時刻の発表に載っている全馬で正規化する（market-baseline の 124 レースの件）。
  決定時刻の発表に載っていて後で取消・除外になった馬のいるレースは、その馬のモデル予測がないので賭けから除く（件数を書く）。
  残りのレースでは発表の全馬 = 出走馬なので、出走馬で正規化した確率がそのまま判断の確率になる。

### 市場オフセットの LightGBM

early stopping で 1,079 反復（学習 81 秒）。valid の race logloss は反復 0（= 市場そのもの）1.9968 → 1.9786。
学習した補正 f のレース内 SD は train 0.361・valid 0.356・test 0.354（train と test でほぼ同じで、過学習の兆しは小さい）。
gain の上位は `race_symbol_code` 0.050、`venue_code` 0.031、`horse_weight` 0.027、`h_corner4_mean3`、`h_l3f_1`、`h_fig_max5_z`、`h_days_since`、`jk_win_rate_z`、

当日の馬体重・調教・脚質が上に来る。

### 条件付きロジット

L2 の格子 {0, 1e-4, 1e-3, 1e-2} で valid は 2.16877 → 2.16824 と単調に下がり、格子の端の 0.01 を選んだ（もっと強い L2 はまだ試していない）。
単独では LGBM より 0.07 悪く、市場に足す情報はない（α = 0.001 ± 0.018）。

### プラセボ

- (a) レース内で並べ替え（valid・test の両方、10 回）: α の平均は A +0.002、B −0.001、C +0.003、条件付きロジット +0.002（SE 約 0.009、最大 |α| 0.020）。
  test の Δ の平均は +0.0005〜+0.0006（係数を 1 つ余分に当てはめた分だけ悪くなる）。α は 0 に潰れた。
- (b) **デモ（リークの陽性対照、使ってはいけない）**: 確定オッズの確率を「モデル」に入れると α = 1.286 ± 0.050、β = −0.278 ± 0.050、
  test Δ = −0.0413 [−0.0458, −0.0368]。リークがあると α が 1 を超え、β が負になる（市場が「モデル」に置き換わる）。
  A・B・C の α（0.19）と β（0.83）はこの形と違う。

## 結論

- **仮説 1（Benter の α は正で 0 と区別できるが改善は小さい）: 支持。** α は 0.19〜0.20（SE 0.02、約 9 SE）、β は 0.83。
  test の Δ は −0.002〜−0.003 で、レース単位・開催日単位の CI とも 0 を含まない（上端 −0.0004〜−0.0013）。ただし 2022 年は 3 本とも Δ ≥ 0 で、
  効いているのは 2023 年以降。予想の範囲（−0.002〜−0.008）の小さい側。
- **仮説 2（市場オフセットは Benter と同程度）: 否定（良い方に）。** Δ = −0.0136 [−0.0168, −0.0102] で、Benter の約 5 倍、4 年とも負。
  確定オッズとの差（0.038）の約 36% を埋めた。線形の Benter（log p_model を 1 つの係数で足す）は「市場と独立に学んだモデル」を足すので、
  市場がすでに織り込んだ部分（過去成績の主成分）と重なる。オフセットで学ぶと、市場が織り込んでいない残差（レース条件との交互作用、当日の馬体重、
  調教、脚質）だけを学ぶ。重要度の顔ぶれの違いがそれを示す。補正 f の SD は 0.35 で予想（0.1〜0.3）より大きい。
- **仮説 3（条件付きロジットは LGBM より悪く α も小さい）: 支持（予想より強く）。** α は 0 と区別できず、Benter の結合は市場より +0.0005 悪い
  （係数 1 つ分の過学習）。線形の 24 列が持つ情報は、10 分前の市場にすべて入っている。
- **仮説 4（プラセボ）: 支持。** 並べ替えで α は ±0.02 以内に潰れ、確定オッズのリーク対照は α = 1.29・β = −0.28・Δ = −0.041 で、
  実モデルの形（α 0.19・β 0.83）と明らかに違う。
- **仮説 5（ROI は控除率の水準）: 一部だけ支持。** 市場オフセットで p·odds > 1 を買うと test −9.9% [−16.0%, −3.6%] で、全馬の −29%、
  票数比例の −22% より損が小さい。閾値 1.2 では +3.1% だが CI は [−17%, +24%] で、黒字とは言えない。valid では閾値によらずほぼ 0。
  logloss で −0.014 は、控除の 20% を越えるには足りない。

**10 分前の市場に情報を足すものはある。** オッズなしの特徴量を、市場をオフセットにして学ぶと、test の 4 年すべてで race logloss が 0.009〜0.017 下がった。
線形の結合では −0.002〜−0.003 しか取れない。どちらも確定オッズ（締切 10 分の投票）の情報量には遠い。

注意と次にすること:

- 市場オフセットのプラセボ（レース内で特徴量を並べ替えて学習し直す、または時間をずらしたラベル）はまだしていない。f の重要度上位に
  当日の馬体重があり、10 分前の時点で発表済みかを確かめる（馬体重は通常発走の約 70 分前に発表）。
- 市場オフセットは valid で early stopping しているので、valid の ROI はやや楽観的。test の結果が本来の評価。
- 条件付きロジットの L2 は格子の端で決まった。強い L2 を足しても α が 0 から動くとは考えにくいが、確かめていない。
- 評価軸（ウォークフォワード、主指標）が決まったら、市場オフセットを同じ枠組みで評価し直す。オッズ帯の項を足した較正（大穴の買われすぎ）も
  オフセットの残差に入るかを試す。
