# 賭け方の評価（全券種、P1〜P3）

[ADR 0004](../../docs/adr/0004-evaluation-axes.md) の賭け方の評価を、初めて全券種でやる。
確率は市場オフセット LightGBM（`experiments/2026-11-14_market-combination/` と同じモデル。予測を保存していなかったので `make_preds.py` で作り直し、test の race logloss 1.93171 が一致することを確かめた）。

コード: `run.py`、`make_preds.py`、`src/keiba_ai/betting/`（`combos.py` 組合せの確率、`kelly.py`、`pricing.py` 価格モデル・オッズ変化のモデル、`policy.py` 方針・成績・プラセボ・Holm、`data.py` 読み込み）。
テストは `tests/test_betting.py`。

## 仮説

（実行前に書いた）

1. **組合せの割引 γ**: 市場（train）は γ2 ≈ 0.8〜0.9、γ3 ≈ 0.7〜0.85（2・3 着で人気薄が来やすい。Benter 1994 の 0.81・0.65 より 1 に近い）。モデル（valid）も同じくらい。
2. **価格モデル**: 確定オッズとの対数誤差の RMSE は、馬連・ワイドで 0.25〜0.35、馬単・3連複で 0.3〜0.4、3連単で 0.4〜0.5。
   馬連では、価格モデルの予測と実際の 10 分前オッズのずれが、10 分前オッズと確定オッズのずれ（約 0.15）より大きい。
3. **単勝・複勝（実際の 10 分前オッズ）**: 選ばれた設定の test の回収率は −5%〜−15% で、Holm で補正すると 0 と区別できないか負。
   ケリー（P2）はほとんど賭けず、対数の資金増加は 0 に近い負。P3（オッズ変化の補正）は P2 より賭ける回数が減り、回収率は少しだけ良い。
4. **ワイド・馬単・3連複・3連単（価格モデル）**: 推定した価格の誤差が大きいので、期待値 ≥ τ の組番は「価格を高く見積もりすぎた組番」に偏る。
   test の回収率は −20%〜−35%。穴の帯ほど悪い（穴の組番は買われすぎで、票数が少なく自分の賭け金の影響も大きい）。
5. **プラセボ**: 単勝ではモデルの賭けが無作為の賭けの中央値は上回るが、95 パーセンタイルは超えない。
6. **全体**: ADR 0004 の test の条件（Holm 補正 p < 0.05 と、プラセボの 95 パーセンタイル超え）を満たす券種 × 方針は 0。勧めるのは P0（見送り）のまま。

## 変更点

- 予測: market-combination の市場オフセット LightGBM（同じ設定で作り直し）。
- 対象: その実験の比較レースのうち、10 分前の発表の全馬に予測があるレース（決定時刻のあとで取消・除外の出たレースは除く）。
- 判断オッズ: 単勝・複勝は 0B41、馬連は 0B42 の 10 分前。ワイド・馬単・3連複・3連単は価格モデル（train で当てはめ）。
- 払戻は HR。自分の賭け金による払戻の低下を補正する（`policy.effective_pay`）。不成立・特払・返還のあった券種はそのレースで賭けない。
- 方針・グリッド・選び方は `config.yaml`。valid で選び、test は選んだ設定を 1 回だけ。

- Holm で補正した p 値は、family の 17 個すべてで 1.0 でした。**ADR 0004 の test の条件を満たした券種 × 方針は 0 です。**
- test の点推定がプラスなのは馬単 / P1 だけです（+6.6%）。年ごとに見ると 2022 年 +3%、2023 年 −13%、2024 年 +38%、2025 年 −1% で、2024 年の少数の大きな的中に頼っています。CI も 0 を大きくまたいでいます。
- ケリー（P2・P3）は、どの券種でも valid で一番小さい λ（0.05）が選ばれました。valid の対数の資金増加はすべて負で、「少なく賭けるほど良い」ということです。つまり P0（見送り）が一番良い結果でした。test の最大ドローダウンは資金の 52〜91% です。
- 自分の賭け金による払戻の補正の影響は、この賭け金の大きさ（1,000 円、ケリーは資金 100 万円から）では 1 ポイント未満でした。
- 無作為の賭けとの比較では、モデルの賭けがどの券種でも、無作為に賭けた場合（−21%〜−31%）よりずっと損が小さかったことを示しています（多くは無作為の賭けの中での順位が 100）。

## 結論

- 仮説 6（合格 0、勧めるのは見送り）は支持されました。**今の推奨は P0（見送り）です。**
- 仮説 3 と 4 はおおむね支持されました。外れた点は 2 つです。
  - 価格モデルの券種も −10%〜−20% 程度に収まり、思ったほど悪くありませんでした。
  - 穴の帯が特に悪いわけでもありませんでした（3連単の 200〜2,000 倍は −9.5%）。
- 仮説 5 は外れました。モデルの賭けは、無作為に賭けた場合の 95 パーセンタイルをほとんどの方針で超えました。
  - モデルの確率にはオッズ帯の中で良い馬券を選ぶ情報があり、無作為なら −25% 前後の損を −3%〜−10% まで縮めています。
  - それでも控除率（20〜27.5%）は越えられません。ΔlogLoss −0.014 という小さな上乗せと合っています。
- valid と test の差は大きく、valid で +20% 以上だった設定（ワイド、馬単の P1）は test で大きく下がりました。グリッドから一番良い設定を選ぶと楽観的になるので、valid の回収率はそのまま信じられません。
- 次にやること:
  1. 予測の改善が先です。主指標の ΔlogLoss を、10 分前と確定オッズの差（0.038）にもっと近づけます。たとえば締切直前の情報（オッズの動き、馬体重）を足します。
  2. 単勝以外の券種の判断オッズには、ペーパートレードで記録している 0B30（全券種、10 分前）を使って、価格モデルを置き換えます。
  3. 市場オフセットのモデル自体のプラセボと、馬体重が使える時点の確認は、まだ残っています。
