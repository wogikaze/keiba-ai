# 0001 時系列分割で評価する

## 状況

レース単位のデータは時間的に依存している（同じ馬・騎手・調教師が繰り返し出る、馬場やルールが年ごとに変わる）。
ランダム分割すると未来の情報が学習に混ざり、評価が楽観的になる。

## 決定

- 学習・検証・テストは日付で分割する。テスト期間は最新側に置く。
- 1レースの出走馬は必ず同じ分割に入れる。
- 特徴量はレース発走前に確定している情報だけから作る。

## 理由

実運用は「過去で学習して未来を予測する」なので、評価もそれに合わせる。

## 検討した代替案

- ランダム K-fold: リークのため却下。
- グループ K-fold（レース単位）: 時間方向のリークが残るため却下。

## 影響

- 分割期間は各実験の `config.yaml` に明記する。
- 期間を変えたら過去実験と直接比較できないので、INDEX では `split` 列で区別する。
