# 0004 評価の軸（予測と賭け方）

## 状況

[0002](./0002-evaluation-metrics-draft.md) は評価ライブラリでできることを並べた下書きで、[0003](./0003-provisional-split-and-features.md) は最初の実験群のための暫定の分割だった。
ベースライン（市場、オッズなし LightGBM、条件付きロジット、Benter 結合、市場オフセット LightGBM）を並べた結果は次のとおりだった。

- オッズを使わないモデルは、単独では締切 10 分前の市場に大きく負ける（ΔlogLoss +0.11 前後）。
- 市場オフセット LightGBM が test で Δ −0.0136 [−0.0168, −0.0102] になり、4 年すべてで市場に勝った。
- 回収率はどのモデルでも 0 と区別できなかった。

あわせて、回収率には「どう賭けるか」が要る。
全頭にモデルの確率どおり賭けたときの 1 レースあたりの対数の資金増加は、log(1 − 控除率) +（払戻オッズの市場の logloss − モデルの logloss）になる。
単勝では log 0.8 = −0.223 に対し、10 分前の市場との差は +0.014 しかない。払戻に使われる確定オッズの市場（1.907）には、モデル（1.932）はむしろ負けている。
したがって、平均の優位で控除率を越えることはできない。モデルが払戻の価格より正しい一部の馬券に絞れるかどうかが、賭け方の問いになる。

この ADR で、予測の評価と賭け方の評価を分けて確定する。0002 と 0003 はこの ADR で置き換える。

## 決定

### 1. 分割と時点

- 分割は 0003 と同じにする。train 2004-01-01〜2018-12-31、valid 2019-01-01〜2021-12-31、test 2022-01-01〜2025-12-31（両端を含む）。
- 学習以外で当てはめるもの（early stopping、Benter の係数、組合せ確率の割引、賭け方の閾値・比率）は valid だけで決める。test は決めたものを 1 回だけ評価する。
- **本番の holdout**: 2026-01-01 以降のデータ（これから溜まる分を含む）。予測と賭け方のルールを凍結したあとで 1 回だけ評価する。それまでは集計もしない。
- 購入を決める時点は **発走 10 分前**（`announced_at <= post_at − 10 分` の最後の中間オッズ）を標準にする。5 分前・2 分前は副次として並べてよい（2022 年を境に最後の中間オッズの時刻が変わるので、主には使わない）。
- 対象レースと取消馬の扱いは 0003 と同じ（異常区分 1〜3 を除いて正規化、判断の確率は決定時刻の発表に載っている全馬で正規化）。

### 2. 予測の評価

- **主指標**: 単勝の勝率について、締切 10 分前の市場（power_fit、k は train で当てはめる）に対するレース単位の ΔlogLoss（モデル − 市場）。
  CI は **開催日単位のクラスタブートストラップ**（2,000 回、95%）。
- **改善と認める条件**（すべて満たす）:
  1. Δ の 95% CI の上端が 0 未満。
  2. test の 4 年すべてで Δ < 0。
  3. プラセボ（レース内で予測を並べ替える）を当てはめ直すと、Benter の α の CI が 0 を含み、Δ の CI も 0 を含む。
  4. 特徴量・オフセットに、決定時刻より後の情報（確定オッズ、10 分前より後の発表、当日の結果）を使っていない。使える時点を `features.FEATURES` に書き、テストで検査する。
- **副指標**（報告するが合否には使わない）: Benter の α・β とその CI、較正（ECE と較正表）、年・競馬場・芝ダート・頭数ごとの Δ、確定オッズの市場との差。

### 3. 賭け方の評価

賭け方は「確率と決定時刻のオッズと資金を入力にとり、各馬券の賭け金を返す関数」（以下、方針）とし、予測モデルとは別に評価する。

**券種と、判断に使うオッズ**

| 券種 | 判断に使うオッズ（10 分前） | 払戻 |
|---|---|---|
| 単勝・複勝 | 0B41 の中間オッズ（複勝は下限） | HR の払戻金 |
| 馬連 | 0B42 の中間オッズ | HR |
| ワイド・馬単・3連複・3連単 | 過去分の時系列がない。10 分前の単勝オッズから確定オッズを予測する価格モデル（train で当てはめる）の予測値 | HR |

馬連では、実際の 10 分前オッズで判断した場合と価格モデルで判断した場合の両方を出し、価格モデルの判断がどれだけずれるかを確かめる。
価格モデルで判断した券種の結果は「実際には見えていた価格と違う」ことを結果に書き、実運用の前のペーパートレード（下の 5）で実際のオッズに置き換えて確かめる。

**組合せの確率**: 単勝の勝率から、2 着・3 着の強さを p^γ に割り引いた Harville 型（Benter 1994 の方法）で計算する。γ はモデルについては valid、価格モデルの市場については train で当てはめる。

**払戻への自分の賭け金の影響**: パリミュチュエルなので、自分の賭け金で払戻オッズが下がる。
券種ごとの票数合計とオッズから的中組番の票数を推定し、払戻を (T + s)(1 − t) / (W + s) に直す（T 総票数、W 的中組番の票数、s 自分の賭け金、t 控除率）。
穴の組番ほど票数が少なく、この補正が効く。

**方針**（あらかじめ決めた 4 種類だけを試す）

| 方針 | 内容 |
|---|---|
| P0 見送り | 賭けない（基準、回収率 0%） |
| P1 定額 | 期待値 p × オッズ ≥ τ の馬券に同じ額を賭ける。オッズ帯で絞れる（穴狙いはここで高いオッズ帯を選ぶ） |
| P2 分数ケリー | 排反な馬券（単勝・馬連・馬単・3連複・3連単）はレース内の同時ケリー（Smoczynski–Tomkins）、排反でない馬券（複勝・ワイド）は 1 点ずつのケリー。その λ 倍を賭け、1 レースの上限を資金の c 倍にする |
| P3 オッズ変化の補正つき分数ケリー | P2 と同じだが、判断のオッズを「10 分前のオッズから予測した確定オッズ」に置き換える（予測は train で当てはめる） |

τ・オッズ帯・λ・c の候補（グリッド）は実験の `config.yaml` に実行前に書く。

**選び方**: 券種 × 方針ごとに、valid で 1 つの設定を選ぶ。

- P1 は valid の回収率の 95% CI の下端が最大のもの（賭けた回数が 300 回以上の設定に限る）。
- P2・P3 は valid の 1 レースあたりの対数の資金増加が最大のもの。

test では、選んだ設定だけを 1 回評価する。

**報告するもの**: 回収率（控除率込み、払戻は HR）と開催日単位のブートストラップ CI、対数の資金増加、最大ドローダウン、賭けた回数と金額、オッズ帯ごとの回収率、年ごとの回収率。的中率は参考として載せる。

**賭け方のプラセボ**: 同じ券種・同じオッズ帯・同じ回数で無作為に選んだ馬券を、同じ方針で賭ける（1,000 回）。
人気薄ほど回収率が低い傾向（大穴バイアス）があるので、オッズ帯の選び方だけで回収率は変わる。モデルが効いたと言うには、この分布の 95 パーセンタイルを上回る必要がある。

**合格の条件**（ある券種 × 方針について、すべて満たす）:

1. test で回収率 > 0 の片側検定が、試したすべての券種 × 方針の中で Holm 法で補正して p < 0.05。
2. test で賭け方のプラセボの 95 パーセンタイルを上回る。
3. holdout（2026 年以降）でも回収率 > 0（点推定）。
4. ペーパートレードで回収率 > 0（点推定）、かつ test の CI に入る。

### 4. 実際に賭けることを勧める条件

上の合格の条件をすべて満たした券種 × 方針だけを、実際にお金を賭けてよいものとして勧める。
それまでは、助言の表示（モデルの確率、市場の確率、期待値、ケリーの賭け金）を出しても、推奨は「見送り」とする。

### 5. ペーパートレード

速報（JVRTOpen）で、各レースの発走 10 分前に実際に見えている全券種のオッズを記録し、その時点で方針が出す賭け金を記録する（お金は賭けない）。
期間は 3 か月以上かつ 1,000 回以上の賭けとする。結果は払戻の確定後に集計する。

## 理由

- 研究の問いは「市場に何を上乗せできるか」なので、主指標は市場との ΔlogLoss にした。回収率よりずっと分散が小さく、少ないレースで差を測れる。
- 回収率は分散が大きく、賭け方の自由度（閾値、オッズ帯、券種）で簡単に過剰適合する。そのため、方針の種類を前もって 4 つに限り、valid で選び、test は 1 回だけ、多重比較は Holm で補正する。
- 開催日単位のブートストラップにしたのは、同じ日のレースが馬場・天候・市場の状態を共有し、レース単位では CI が狭くなりすぎるため。
- 穴狙いの賭け方は、高いオッズ帯の P1 と、ケリーが自然に選ぶ穴の馬券で評価できる。穴は票数が少なく、自分の賭け金が払戻を下げるので、その補正を入れた。
- 単勝以外の 10 分前オッズは過去分がない。確定オッズで判断すると、購入時点で知り得ない情報を使うことになる。そこで価格モデルを train で当てはめ、馬連の実際のオッズで検算する。

## 検討した代替案

- 回収率を主指標にする: 分散が大きく、方針の選び方に左右されるので採らない。副指標と、賭け方の合格の条件に置く。
- ウォークフォワード（年ごとに学習し直す）: 実運用に近いが、今のモデルは学習に時間がかかる。test を 4 年まとめて年ごとの Δ を見ることで代える。モデルを凍結したあとの holdout とペーパートレードで、時間とともに劣化しないかを確かめる。
- 単勝以外の券種を確定オッズで判断する: リークになるので採らない。
- 券種ごとに方針の候補を自由に増やす: 多重比較で偽の当たりが出やすくなるので、4 種類に固定する。

## 影響

- 0002・0003 は置き換えられた（status を superseded にした）。
- 今後の実験は、予測の結果をこの ADR の主指標と改善の条件で書く。賭け方の実験は、方針・グリッド・選び方を `config.yaml` に実行前に書く。
- ペーパートレードのため、速報の取得（`scripts/jravan/jv_realtime.py`）に、発走 10 分前の全券種オッズの記録を足す。
