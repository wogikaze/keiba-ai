# 取引所オッズはブックメーカーより当たる：欧州サッカー 5,478 試合での市場間比較

> 一言で: 同じ試合について Betfair（取引所）と8社のブックメーカーの暗黙確率を比べると、Betfair のほうが試合結果をよく説明し、ブックメーカーの確率に Betfair との比を加えると説明力が上がる。「Betfair の確率がブックメーカー平均より高い結果」に賭けるだけで平均以上、条件によっては正の回収率になる。

原本は著者の所属機関ページに置かれた出版版の著者用コピー（12ページ、誌面 448–459）。以下のページは誌面の頁番号。

Betfair とランダムに選んだブックメーカーの暗黙確率の相関は、引き分け 0.917、アウェー勝ち 0.978、ホーム勝ち 0.981 (p.451)。両市場はほぼ同じ値をつけており、以下の差はその上での小さな差である。

### 暗黙確率の作り方

オッズの逆数の合計は控除（overround）のため1を超える。控除が各結果に均等に乗っていると仮定し、$\pi_i=(1/O_i)/\sum_j(1/O_j)$ で正規化する (p.449)。この均等配分の仮定自体がロングショットバイアスの扱いに影響する点は、後で「批判的に読む」で触れる。

## 方法

1. **単変量プロビット**: 各結果（ホーム・引き分け・アウェー）と各市場について、実際の結果（0/1）を暗黙確率で説明するプロビットを推定し、McFadden の擬似 $R^2$、McKelvey–Zavoina の $R^2$、ROC 面積、Brier スコアで比べる (p.452–453)。
2. **追加説明力の検定**: ブックメーカーの確率に、比 $\pi^{BF}/\pi^{BM}$ を説明変数として加え、その係数が正かを見る (p.455)。両確率を同時に入れると多重共線性が強いため比を使った、と注記している。
3. **賭け戦略**: Betfair の確率がブックメーカー平均の確率を上回る結果に、各ブックメーカーのオッズで1単位賭ける (p.455–456)。さらに比 $R_i^*$ の階級ごとの平均リターンを局所多項式回帰で描く (p.457–458)。

VC Bet（ホーム・引き分け）と Stan James（引き分け）を除き、Betfair がすべての指標で上回る (p.453)。ただし Stan James と VC Bet は観測数が約3,600 と少ない。差は Brier で 0.001〜0.002 程度と小さい。

プロビットの限界効果（暗黙確率の係数）は、すべてのブックメーカーとすべての結果で1を大きく上回り、Betfair が最も1に近い（例: ホーム勝ちで Betfair 1.124、ブックメーカー平均 1.264）(p.454, Table 2)。著者はこれをロングショットバイアスと解釈し、取引所の精度の高さの少なくとも一部はバイアスが弱いことによるとする (p.453)。

### 追加説明力 (p.455, Table 3)

比 $\pi^{BF}/\pi^{BM}$ の係数は、全ブックメーカー・全結果で正で有意。ホーム勝ちで 0.39〜0.48、アウェー勝ちで 0.44〜0.47（いずれも 0.1% 水準）、引き分けでは 0.23〜0.29（5% または 1% 水準）。ブックメーカーのオッズは Betfair が持つ情報を取り込み切っていない。

## 著者の解釈と留保

著者は、ブックメーカーが情報処理に失敗しているとは解釈しないと述べる (p.458)。理由の候補として、情報を持つ賭け手が取引所に自己選択すること、ブックメーカーが偏った需要に合わせて意図的に価格を傾けること（Levitt 2004）を挙げ、検証は今後の課題としている。

## 批判的に読む

- **オッズの時刻**: 試合の2〜3日前の金曜・火曜午後の値で、締切直前のオッズではない (p.451)。直前の情報（先発メンバーなど）を反映した後でも差が残るかは分からない。
- **取引所の手数料**: リターンはブックメーカーのオッズで計算しており、Betfair 側の手数料は関係しない。逆に、Betfair で賭ける戦略の評価ではない。
- **多重比較**: 「上位 5% で +10%」は事後的に閾値を選んだ結果で、ホールドアウトでの検証は無い。821 件で標準誤差は（オッズの分散にもよるが）数% あると見られ、+10% が偶然でないかは未検定（推測）。
- **控除の均等配分**: 暗黙確率の正規化で控除を均等に配分している (p.449)。実際の控除は長距離側に多く乗る（FLB）ので、ブックメーカーの確率が不利に見える一因になりうる。Shin 法など別の正規化で結果が変わるかは検討されていない。
- 差は小さく（Brier で千分の一桁）、統計的な有意差の検定は Table 2 の比較自体には付いていない。

## keiba-ai での使い方

- **複数市場の確率の差を特徴量にする**: JRA には取引所は無いが、同じ構図は「単勝オッズ vs 複勝オッズから逆算した確率」「前日オッズ vs 直前オッズ」「単勝 vs 馬連・三連単から逆算した勝率」で作れる。仮説: 単勝の暗黙確率に対し、他の券種から逆算した勝率との比を加えると、ロジットでの勝率予測の対数損失が下がる（本論文の Table 3 と同じ検定）。
- **評価の型**: 「市場確率だけのモデル」に候補特徴量を足して係数の有意性と擬似 $R^2$ の増分を見る、という手順は、特徴量が市場に無い情報を持つかの最小限の検定として使える。Benter 型の「市場確率と自前モデルの結合」の前段階に当たる。
- **戦略評価の注意**: 比の上位 X% に絞った回収率は、閾値を学習期間で決めて検証期間で評価する。本論文はこれをしていない。
- **控除の配分方法**: JRA のオッズから確率を作るとき、均等正規化と FLB を考慮した正規化を両方試し、どちらが結果の説明力（Brier、対数損失）が高いかを確認する。
