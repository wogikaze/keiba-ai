# グレイハウンド競走で専門家3人・ID3・誤差逆伝播NNの単勝成績を比べた初期実験

> 追記（2026-11-13）: 原本は機械 OCR 済み（RapidOCR）。`library/1994-chen-greyhound-expert-symbolic-nn/source.txt` で全文検索できる。OCR の誤認識が残るため、数値は PDF のページ画像で確認すること。本ノートの本文は OCR 前にページ画像を読んで書いたもの。

> 一言で: Tucson Greyhound Park の100レースで、専門家3人は全員が単勝で約$60〜70負けたのに、ID3 決定木は +$69.20、誤差逆伝播ネットは +$124.80 だった。的中数では ID3 が最多、払戻では的中数の少ない NN が最大で、差は穴馬（穴犬）の拾い方から来ていた。

**原本はスキャン PDF のため（当時）OCR 待ち。** 本ノートは、アリゾナ大学機関リポジトリの PDF（IEEE Expert 掲載版の誌面スキャン、全8ページ中 p.21-27 が本文）をページ画像として読み、内容を自分の言葉でまとめたもの。ページ番号は誌面のページ。

## 要旨

「機械学習はゲーム的な状況の不確実性を減らせるか」「人間の専門家より当たるか」を問う。題材は Tucson Greyhound Park のグレイハウンド競走（p.21）。競走プログラムに載る約50変数から、専門家の意見で10変数に絞り、ID3（決定木）と誤差逆伝播ニューラルネット（BPNN）で各犬を勝ち／負けに分類した。評価は 100 レースで、選ばれた犬に$2の単勝を賭けたときの払戻（p.25-26）。

## データ

- 市場: Tucson Greyhound Park（米アリゾナ）。週に約112レース、1プログラム約15レース、グレードは A（最上位）〜D。メイデン（M）等の特殊グレードは除外 (p.21)。
- プログラムの情報: 各犬の最速タイム、出走数、1〜4着回数、直近7走の枠・第1コーナー（ブレイク）位置・第2/第3コーナー位置・着順・タイム・グレード、前日結果と配当 (p.21-22, Figure 1)。
- 専門家: 競走場と無関係の予想家3人。予想はプログラムと同じ公開情報のみに基づく（と著者は理解している）(p.22)。
- 学習 200 レース × 8頭 = 1,600 事例、テスト 100 レース（800事例）。全データの2/3を学習、1/3をテスト。再標本化（交差検証）はテスト件数の多さと BPNN の計算コストを理由に行っていない (p.24)。
- 期間（何年何月か）は本文に明記がない。Figure 1 の例は1992年8月の出走。未確認。

## 特徴量（専門家が選んだ10変数, p.22-24）

| 変数 | 内容 |
|---|---|
| fastest time | 5/16 マイルの最速タイム |
| win / place / show percentage | 1着・2着・3着の回数を出走数で割ったもの |
| break average | 第1コーナー位置の直近7走平均 |
| finish average | 直近7走の平均着順 |
| time 7 average / time 3 average | 直近7走・3走の平均走破タイム |
| grade average | 直近7走のグレードを A=4, B=3, C=2, D=1, その他=0 として平均 |
| up grade | 格下げ戦への加点。直近の上位グレード出走が1走前なら3、2走前なら2…、直近3走に無ければ0 |

前処理の要点は「レース内での相対化」。各レースで最も悪い値を0とし、他の犬はそこからの差で表す（例: 最遅の最速タイム 32.00 秒を0、31.00 秒の犬は 1.00）。グレードごとにタイム水準が違うためと説明している (p.24)。

## アルゴリズム

1. **ID3**: 連続変数は値を昇順に並べ、両端の「勝ちだけ」「負けだけ」の区間を切り出す三分割（ternary partition）版を自作し、通常の二分割版と比べた。三分割の方が木が単純でエントロピー低減も大きかった (p.24)。根は break average、次に up grade、show %、fastest time、grade average、win %、time 7 average、finish average、time 3 average、place % の順に分岐する (p.25, Figure 2)。著者によると最初の5変数が1着の判定に効いていた。
2. **BPNN**: 3層。隠れ層 15/20/25/30/35 を試して25が最良。学習率 0.2〜0.4（0.05刻み）、モメンタム 0〜0.1 を試し、学習率0.2・モメンタム0.1 に固定。エポックを 2,500〜20,000 で動かした (p.25-26)。
3. 賭け方: 予測勝者に$2の単勝。複数の勝者を予測したら全部に賭け、勝者なしなら見送り。複勝・連勝式は扱わない (p.25)。オッズは公表配当を使い、自分の賭けによるオッズ変化は無視できるとしている (p.26)。

## 結果

100 レースの結果 (p.26, Table 1):

| 手法 | 的中 | 不的中 | 見送り | 払戻（$） |
|---|---|---|---|---|
| 専門家1 | 19 | 81 | 0 | −71.40 |
| 専門家2 | 17 | 83 | 0 | −61.20 |
| 専門家3 | 18 | 82 | 0 | −70.20 |
| ID3 | 34 | 50 | 26 | +69.20 |
| BPNN | 20 | 80 | 0 | +124.80 |

- ID3 の利益は少数の高配当に依存する。例: 31レース目 $24.40、59レース目 $41.20、83レース目 $26.80。専門家の最高配当は $11.40 (p.26)。二分割版 ID3 は +$69.00 でほぼ同じ (p.26)。
- BPNN の払戻はエポック数で大きく揺れる。2,500〜10,000 では −$73.00〜−$39.80、12,500 で +$44.60、17,500 で最良の +$124.80、20,000 で +$44.60 に戻る (p.26, Table 2)。BPNN も10レース目 $78.00 などの穴で稼いだ (p.26)。
- 一元配置分散分析では5群の平均差は 10% 水準で有意（p=0.083）。BPNN は最良の専門家に対し t 検定で p=0.084、ID3 は専門家に対し p=0.15 で有意でなく、BPNN と ID3 の差も p=0.68 (p.26-27, Figure 3)。レース当たり平均払戻は専門家 −0.61〜−0.71、ID3 +0.69、BPNN +1.25、標準偏差は BPNN が 10.2 と最大 (p.27, Figure 3)。

> 著者は結論で、成績変数を50から10に絞る段階での専門家のヒューリスティクスが、機械学習の成功に決定的だったと述べている (p.27)。

## 批判的に読む

- **テスト集合でのハイパーパラメータ選択**: BPNN のエポック数（17,500）は 100 テストレースの払戻を見て選んでいる (p.26, Table 2)。Table 2 の振れ幅（−$73 から +$125）を見ると、報告された +$124.80 は楽観的なバイアスを含む。隠れ層数も同様。
- **サンプルサイズ**: 100 レース・$2 単勝では、数レースの高配当で収支が決まる。統計的有意性は 10% 水準でも際どい。
- **控除率と配当**: 払戻は公表配当（控除後）で計算されており、その点は実戦に近い。ただし ID3 は26レースを見送っているので、投資額が他と違う（回収率で比べると ID3 は 74 レース×$2=$148 の投資で +$69.20）。この点は本文に回収率として整理されていない（計算は筆者）。
- **リーク**: 特徴量は過去走のみで、レース後情報は使っていない。ただし学習/テストの分割が時系列順かは明記がない（未確認）。
- **「勝ちか負けか」の独立分類**: 各犬を独立に分類するので、1レースで勝者0頭・複数頭が起こる。確率出力ではなく、レース内の正規化もない。
- 二次資料（Schumaker & Johnson 2008 経由の旧ノート）では専門家の損失を $67.60 としていたが、原本 Table 1 は −$71.40/−$61.20/−$70.20 で、単一の値ではない。

## keiba-ai での使い方

- **レース内相対化特徴量**: 最悪値を0とする差分表現は、keiba-ai のレース内標準化・順位化特徴量（例: スピード指数のレース内偏差）の古い先例。仮説: 絶対値特徴量に加えてレース内相対値を入れると、クラス横断の学習で対数損失が下がる。
- **格下げ（up grade）とクラス平均**: 前走より格の低いレースに出る馬への加点は、JRA のクラス替わり・降級（過去制度）・地方→中央の移籍特徴量に対応する。
- **評価設計の反面教師**: エポック数をテスト払戻で選ぶと回収率は簡単に過大になる。keiba-ai では検証期間でハイパーパラメータを決め、テスト期間は1回だけ使う（[Sugiura 2026](./2026-sugiura-leakage-aware-evaluation.md) と同じ立場）。
- **的中率と回収率の乖離**: 的中20%の BPNN が的中34%の ID3 より儲かった。主指標を回収率・対数損失に置き、的中率は補助とする根拠の一つ。
