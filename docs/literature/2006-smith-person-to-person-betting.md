# 取引所では FLB が小さい：英国競馬 700 レースで Shin の z を3種類の価格で比べる

> 一言で: 同じ英国競馬 700 レースについて、ブックメーカー平均・最良ブックメーカー・Betfair の3種類の価格から Shin の $z$（FLB の大きさ）を推定すると、取引コストが低い順に $z$ が小さい（2.17% > 1.19% > 0.90%）。また情報の多いレースほど $z$ が小さく、FLB はリスク選好より情報コストで説明できる、と主張する。

## 原本について

Nottingham Trent University の機関リポジトリにあった著者最終稿（2005年8月付、27ページ）を、リポジトリ移転のため Internet Archive の保存版から取得した。出版版と要旨の文言が異なり、最終稿は「取引所は弱度・強度の効率性を示す」と強く書いている (p.2)。出版版は「有意に小さい市場バイアス」と控えめになっている（出版社ページの要旨による）。本文の数値が出版版と同じかは未確認。ページは最終稿の頁番号。

## 仮説

- **取引コスト仮説**（Hurley and McDonough 1995）: 取引・情報コストが高いほど、賭け手は真の確率を調べず均等に近く賭けるので FLB が大きくなる (p.5–6)。
- **情報モデル**（Sobel and Raines 2003）: 情報が全く無ければ各馬への投票割合は $1/N$。情報が増えるほど客観確率に近づく (p.6–7)。
- Betfair の手数料は勝ち分の最大 5%。サンプルのブックメーカー平均のオーバーラウンドは 25.63% (p.8)。したがって FLB はブックメーカーで大きいはず、が検証すべき予測。

## データ

| 項目 | 内容 | ページ |

| 市場 | 英国競馬（平地と障害） | p.9 |
| 期間 | 2002年（2001-02 障害シーズン後半、2002 平地、2002-03 障害シーズン初め） | p.9 |
| 対象日 | 流動性のため土曜など売上の大きい日に限定 | p.9 |
| ブックメーカー価格 | Racing Post のウェブサイト。各馬の平均と最良価格（outlier） | p.9 |
| 取引所価格 | Betfair。毎日 10:30 に同時刻で取得 | p.10 |

| 標本 | 799 レース → 700 レース、8,258 頭、平均出走頭数 11.8 | p.10, p.21 |

価格が名目でないことを確かめるため、5〜20 ポンドの実際の賭けを試した、とある (p.9)。

情報の多さの代理として、売上でレースを4クラスに分けた（Class 1: 171、Class 2: 265、Class 3: 137、Class 4: 127 レース）(p.10–11, p.21 Table 1)。公式のレース格付けは使っていない。

## 方法

1. **Shin の $z$**: レースのオーバーラウンド $D_i$ を出走頭数 $n$ と価格の「分散」で回帰する Shin (1993) の式を使う (p.12)。

   $$D_i = z(n-1)_i + \sum_k a_k n_i^k \mathrm{Var}(p)_i + \sum_k b_k n_i^k [\mathrm{Var}(p)]_i^2$$

   $n-1$ の係数 $z$ がインサイダー取引の割合で、FLB の大きさの指標になる。結果データ（どの馬が勝ったか）を使わずに推定できるので、少数のレースでも使える (p.12)。
2. 3種類の価格は同じレースなので、見かけ上無関係な回帰（SUR）で同時推定し、$z$ の等しさを検定する (p.13)。
3. **リスクモデル vs 情報モデル**（Sobel and Raines）: 主観確率 $\rho$ と客観確率 $\pi$ の関係を、リスクモデルは $\log\rho=\alpha+\beta\log\pi$、情報モデルは $\rho=\alpha+\beta\pi$ とする (p.13–14)。$\rho$ はブックメーカー平均の正規化確率、$\pi$ は **Betfair の正規化確率を代理に使う** (p.14)。Weitzman のオッズ階級ごとに平均して加重最小二乗で推定する。

## 推定結果

### 全レースの Shin $z$ (p.22, Table 3)

| 価格 | $z$ | 標準誤差 |
|---|---|---|
| ブックメーカー平均 | 0.0217 | 0.0003 |
| ブックメーカー最良 | 0.0119 | 0.0003 |
| Betfair | 0.0090 | 0.0005 |

Betfair の $z$ は両方のブックメーカー価格より有意に小さい (p.15, Table 8)。平均価格の 2.17% は Shin 自身の推定（178 レースで 2.5%）と同程度 (p.12, p.15)。

### 情報クラス別の $z$ (p.23–25, Tables 4–7)

| クラス（1 が情報最少） | 平均 | 最良 | Betfair |
|---|---|---|---|
| 1 | 0.0258 | 0.0132 | 0.0182 |
| 2 | 0.0261 | 0.0147 | 0.0124 |
| 3 | 0.0186 | 0.0105 | 0.0052 |
| 4 | 0.0173 | 0.0089 | 0.0038 |

Betfair だけがクラス1→4で単調に減少する (p.16)。ただし Class 1 では Betfair（0.0182）が最良ブックメーカー（0.0132）より大きく、両者の差は有意でない（χ² = 0.09, Table 8）。著者は売上の少ないレースでの取引所の流動性不足によると解釈している (p.16)。

Betfair の $z$ は小さいが標準誤差は最も大きい。著者はこれを、インサイダー取引は取引所で広く行われてはいないが、個別のレースでは目立って現れうる、と読む (p.17)。

### リスクモデル vs 情報モデル (p.26, Table 9)

| モデル | $\alpha$ | $\beta$ | $R^2$ |
|---|---|---|---|
| リスク（対数線形） | −0.3103 | 0.8655 | 0.9976 |
| 情報（線形） | 0.0050 | 0.9405 | 0.9998 |

情報モデルでは主観確率と客観確率の交点が $\alpha/(1-\beta)=0.0849$ で、平均出走頭数の逆数 $1/11.8=0.0847$ にほぼ一致する (p.18)。情報モデルの予測どおりで、FLB はリスク選好より情報で説明できる、と結論する (p.18–19)。

Weitzman 階級別の値を見ると、払戻 21 倍以上の階級で主観確率が客観確率を上回り（例: 101 倍の階級で 0.0102 vs 0.0060）、短いオッズでは逆になる (p.21, Table 2)。

## 批判的に読む

- **結果データを使っていない**: Shin の $z$ はオッズの形だけから推定する。さらにリスク vs 情報の比較では、Betfair の価格を「客観確率」の代理にしている (p.14)。Betfair に FLB が小さいという前段の結論を前提に使っており、実際の勝率と照合した検証ではない。取引所の効率性を、取引所の価格を正解として測っている循環がある。
- **$z$ はブックメーカーのモデルの量**: Shin のモデルはブックメーカーの価格設定から導かれたもので、取引所に当てはめてよいかを著者自身が論じている (p.17–18)。
- **価格の時刻**: 10:30 の朝の価格で、発走直前の価格でも SP でもない (p.10)。直前には差が縮まる可能性がある。
- **情報モデルの $R^2$**: 23 階級の平均値に対する回帰なので、$R^2$ が 0.99 を超えるのは当然に近く、0.9976 と 0.9998 の差でモデルを選ぶのは弱い根拠である。交点が $1/N$ に一致する点の方が実質的な証拠になる。
- 標本は売上の大きい日に限定され、さらに売上の小さいレースを除外している (p.9–10)。FLB が大きいはずの低流動性の市場が外れている。

## keiba-ai での使い方

- **控除率と FLB の関係**: JRA の単勝の控除率は約 20% で、本論文のブックメーカー（オーバーラウンド 25.63%）に近い。取引コスト仮説が正しければ、JRA の単勝オッズにもはっきりした FLB があるはずで、オッズから確率を作るときに補正が要る（オッズの逆数をそのまま正規化しない）。
- **Shin の $z$ を特徴量にする**: 結果を使わずにレースごとに計算できるので、レース単位の「市場の歪みの大きさ」を表す特徴量になる。仮説: 単勝オッズから推定した $z$ が大きいレースほど、市場確率に対するモデルの上積み（対数損失の改善）が大きい。
- **情報量の代理**: 本論文では売上を情報量の代理にした。JRA でも売上（または重賞・条件戦の別、新馬戦・未勝利戦の別）で FLB の強さが変わるかを確かめる価値がある。新馬戦は Class 1 に相当すると考えられる（推測）。
- **均等投票の極限 $1/N$**: 情報モデルの交点が $1/N$ という性質は、オッズ補正のパラメータ（例: 市場確率と $1/N$ の混合）を出走頭数で変えるべきことを示唆する。
