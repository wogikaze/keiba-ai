# 騎手は走行タイムに効くか（JRA 1988〜1990年、混合モデルの母数効果の検定）

> 原本未取得。Wiley の有料誌で、OpenAlex・Semantic Scholar・ResearchGate に無料の全文や著者版は見つからなかった。本ノートは出版社要旨（OpenAlex 経由で取得した英・仏・独の要旨）と、同じ著者の後続論文での引用に基づく。数値の多くは未確認。

> 一言で: JRA の 1988〜1990年のデータで、レース・騎手・負担重量が芝・ダート6距離のすべてで走行タイムに高度に有意（p<0.01）な効果を持つことを混合モデルで検定し、騎手を補正せずに馬の遺伝的評価をすべきでないと結論した。

## 位置づけ

沖博憲（JRA 競走馬総合研究所）が Iowa State 大学の Willham らと出した「日本のサラブレッドの競走能力の遺伝学」シリーズの一本。
同じ年・同じ号に、走行タイムの遺伝パラメータを REML で推定した論文（J. Anim. Breed. Genet. 112:146–150）がある。
前年の II 報（111:128–137, 1994）では、芝・ダートの環境変動と、性・年齢・負担重量の影響を扱っている。
本論文はそこに騎手を加え、「騎手を母数効果としてモデルに入れるべきか」を検定した。
[沖・佐々木 1996](./1996-oki-genetic-trend-running-time.md) の BLUP では、実際に騎手を母数効果に入れており、本論文の結論がそのまま使われている（1996 論文 p.121 の文献11）。

## データ（要旨から分かる範囲）

- JRA が収集した 1988〜1990年の成績。
- 2つ以上の年齢が混ざったレースだけを使う（年齢効果とレース効果を分離するため）。
- 騎手と馬の間に連結性（connectedness）があるレースだけを使う。同じ騎手が異なる馬に、同じ馬が異なる騎手に乗っている記録がつながっていないと、騎手効果と馬効果を分けられないため。
- 芝・ダートの6距離（どの距離かは未確認）。
- レース数・頭数・騎手数は未確認。

旧ノートは二次情報として「1986〜1990年」とする説も挙げていたが、出版社要旨は 1988〜1990年である。

## 方法

混合モデルの母数効果（レース、年齢、騎手、負担重量）について、線形仮説 $H: K'b = 0$ を検定する。
$b$ は母数効果のベクトル、$K'$ は検定したい効果を取り出す行列。
馬は変量効果として入り、分子血縁行列の逆行列 $A^{-1}$ を混合モデル方程式に入れた場合（馬の血縁を考慮）と入れない場合の両方で解析している。
どちらでも有意水準は変わらなかった（要旨）。

## 主な結果（要旨）

- レース、騎手、負担重量は、芝・ダートの6距離すべてで p<0.01。
- 年齢効果の結果は要旨に明記がない（未確認）。
- 騎手の技量は距離・馬場を問わず走行タイムの重要な変動要因であり、補正係数の導出、遺伝パラメータの推定、育種価の予測で考慮すべき。

> The skill of the jockey is an important source of variation in racing time across distances and track types (要旨)

旧ノートにあった「着順タイムへの寄与は馬 94.8%、騎手 5.2%、距離が長いほど騎手の寄与が増える」という要約は出典を確認できなかった。本論文の数値なのか、後続の別研究の数値なのかは未確認として扱う。

## 批判的に読む

- 示したのは「有意かどうか」で、効果の大きさ（騎手間の差が何秒か）は要旨からは分からない。数万件の記録があれば小さな効果でも p<0.01 になる。
- 騎手を母数効果として扱っている。騎手の数が多く記録の少ない騎手もいるので、現代的には変量効果（縮小推定）の方が自然。母数効果だと乗り鞍の少ない騎手の推定値が極端になる。
- 騎手と馬の割り当ては無作為でない。上手な騎手は良い馬に乗る。$A^{-1}$ を入れて馬の血縁を使っても、馬の永続環境（育成・厩舎）と騎手の相関は残る。調教師効果が入っているかは未確認。
- 連結性のあるレースに絞る操作で、地方から来た騎手や乗り鞍の少ない騎手は落ちている可能性が高い。
- 1988〜1990年の JRA で、外国人騎手の短期免許（1994年〜）以前のデータ。現在の騎手間の差の構造とは違う。

## keiba-ai での使い方

- 騎手は特徴量に入れる価値がある、というのが本論文の結論。ただし馬の能力と交絡するので、騎手 ID の target encoding は「騎手の平均着順」ではなく「馬の能力を条件づけた上での騎手の上積み」を測る方が良い。
- 仮説 H1: 騎手効果を「その馬の他の騎手での成績との差」で推定した特徴量（馬を固定した差分）は、単純な騎手勝率よりも、乗り替わりレースで log loss を下げる。
- 仮説 H2: 騎手効果は乗り鞍数で縮小推定（経験ベイズ・階層モデル）した方が、少数乗り鞍の騎手で過学習しない。中北・中妻の階層ベイズと比較する。
- 負担重量も全距離で有意。斤量そのものと「前走からの斤量の変化」の両方を特徴量に入れる根拠になる。
- 走行タイムを目的変数にした補助モデル（タイム指数）を作るなら、レース効果（ペース・馬場）を母数効果で除いた上で、騎手・斤量を補正する本シリーズの設計が参考になる。
