# 混合効果モデル（BLUP）で JRA の競走成績はどこまで予測できるか：血統だけの予測相関は平均 0.08

> 一言で: JRA の芝・良馬場・4競馬場（東京・中山・京都・阪神）のレースを、競馬場×距離帯の 12 カテゴリに分けて別形質とし、平均速度を混合効果モデル（反復モデル）で分解した。分散の8割強は「レース効果」で、それを除くと育種価（相加的遺伝効果）の割合は 0.10〜0.22。2010 年までのデータで推定した育種価で、2009 年以降生まれ（＝2010 年までに出走歴が無い）の馬の補正済み成績を予測すると、相関は平均 0.084、重賞勝ち馬の判別 AUC は平均 0.613。どちらも長距離ほど高い。

原本は Wiley の出版社版（CC BY-NC の OA、pp.24–32）。ページは雑誌のページ番号。著者は龍谷大学農学部の小田大輝・小野木章雄。

## 問いと位置づけ

競走成績の遺伝率は多くの集団で推定されてきた。日本では Oki ら (1995) が走破タイムの遺伝率 0.081–0.254 を報告し、短距離ほど高いとした (p.24–25)。一方、**個々の馬の成績をどこまで予測できるか**はあまり調べられていない (p.25)。本論文はこの「予測可能性」を、時間で分けたデータで評価する。

成績指標は平均速度（距離 ÷ 走破タイム）。生物学的に解釈しやすく、タイム系の指標が広く使われているから、という理由 (p.25)。

## データ (p.25, Table 1)

- JRA-VAN から取得した JRA の平地競走。**芝・良馬場・3歳以上**のレースだけで、競馬場は東京・中山・京都・阪神の4場。
- 期間は 1986 年1月（JRA-VAN の最古）から 2021 年 12 月 (p.25)。ただし予測の節では全データを「1986–2022」と書いており (p.26)、本文の中で終わりの年が一致しない。旧ノートの「1986〜2022 年」は後者に由来する。
- 除外: 降着・失格のあったレース。JRA 以外の所属馬（外国馬など）。1着から 4.5 秒以上遅れた馬。レース内の平均速度から ±3 SD 外れた馬。
- 距離帯: 短距離（1600 m 以下）、中距離（1600 m 超 2400 m 以下）、長距離（2400 m 超）。4場 × 3距離帯 = 12 カテゴリを別形質として独立に解析する (p.26)。競馬場ごとに回りや坂が違うので、遺伝と環境の交互作用を想定したため。

旧ノートは「ダート」や「馬場状態」の限定に触れていなかった。原本では芝の良馬場だけで、ダートは対象外である。

| レース数 / 馬数 (Table 1, p.26) | 東京 | 中山 | 京都 | 阪神 |
|---|---|---|---|---|
| 短距離 | 2,317 / 16,685 | 1,715 / 12,505 | 2,223 / 15,624 | 2,037 / 14,433 |
| 中距離 | 2,729 / 16,457 | 1,843 / 13,119 | 2,337 / 13,548 | 1,899 / 12,046 |
| 長距離 | 100 / 785 | 340 / 2,164 | 100 / 891 | 229 / 1,619 |

長距離はレース数が1桁小さい。平均速度は短距離で約 60.4–60.8 km/h、長距離で約 57.6–58.4 km/h (Table 3, p.27)。

## モデル (p.26)

全効果を入れた Model 0 は次の通り。

$$y_{id} = \mu + \alpha_1 z_{1i} + \alpha_2 z_{2i} + \beta_1 x_{id} + \beta_2 x_{id}^2 + \gamma_1 w_{id} + \gamma_2 w_{id}^2 + r_d + b_i + t_{id} + j_{id} + u_i + pe_i + e_{id}$$

- $y_{id}$: 馬 $i$ のレース $d$ での平均速度
- 固定効果: $z_{1i}, z_{2i}$ は牝馬・せん馬のダミー、$x_{id}$ は日齢（1次・2次）、$w_{id}$ は馬番（1次・2次）
- 変量効果: $r_d$ レース、$b_i$ 生産者、$t_{id}$ 調教師、$j_{id}$ 騎手、$u_i$ 育種価、$pe_i$ 恒久環境効果（同じ馬の繰り返し出走に共通する非遺伝的な部分）、$e_{id}$ 残差
- 負担重量は性・年齢と相関するので入れていない (p.26)。
- 推定は gibbs3f90 によるギブスサンプリング。50,000 回、burn-in 30,000、間引き 10。事後平均を報告 (p.26)。

モデル選択は、Model 0 から育種価と恒久環境以外の説明変数を1つずつ抜いた Model 1–9（性、年齢、年齢の2次項、馬番、馬番の2次項、レース、生産者、調教師、騎手）を DIC で比べる (Table 2, p.27)。さらにもう1つ抜いても DIC はどのカテゴリでも下がらなかった (p.26)。

## 結果

### 選ばれたモデル (p.27, Table 4)

- Model 0（全部入り）: 東京中距離、京都短・中距離、阪神短・長距離の5カテゴリ。
- Model 5（馬番の2次項なし）: 中山短・中距離、阪神中距離の3カテゴリ。
- Model 1（性なし）: 中山長距離、京都長距離。長距離では性が重要でないという結果で、著者は新しい知見とする (p.29)。
- Model 7（生産者なし）: 東京短距離。Model 8（調教師なし）: 東京長距離。理由は分からないと著者自身が書く (p.29)。
- どのカテゴリでもレース効果を抜くと DIC が最も悪化した。12 中5カテゴリでは、悪化の大きさの順がレース、騎手、年齢だった (p.27)。

### 分散成分 (Tables 5–6, p.30)

レース効果込みの割合（Table 5）では、レース効果が 0.82–0.91 で圧倒的。残差、恒久環境、育種価、騎手が続く。

レース効果を除いて計算し直した割合（Table 6）の主要な値を抜き出す。

| 効果 | 範囲（12カテゴリ） | 備考 |
|---|---|---|
| 育種価（相加的遺伝） | 0.096–0.215 | 京都長距離 0.215 が最大 |
| 恒久環境 | 0.057–0.268 | 長距離で小さい |
| 騎手 | 0.029–0.097 | 京都長距離 0.097 が最大 |
| 調教師 | 0.013–0.050 | |
| 生産者 | 0.006–0.071 | |
| 残差 | 0.44–0.65 | |

本文 (p.27) は育種価の割合を「0.11–0.22」と書くが、Table 6 では中山中距離が 0.0957 で、0.11 を下回る。小さな食い違い。

レース効果を除いた割合の方が説明変数の効きを議論するのに向く、と著者は述べる。競馬はタイムではなく着順を競うので、レース以外の要因は「速度そのもの」ではなく「そのレースの平均速度からのずれ」に効くからである (p.28)。

> This reflects the fact that horse racing is conducted to compete for rank rather than for time. (p.28)

育種価の割合は長距離ほど高く、短距離ほど遺伝率が高いとした先行研究（Oki ら 1995 など）と逆になった。著者は2つの理由を挙げる。(1) 先行研究は 2400 m 超を含んでいない。(2) 長距離はデータが少なく過適合で過大推定された。予測力も長距離で高いので、過適合なら起きにくいとして (1) を採る (p.29)。

### 予測可能性 (p.27, Tables 7–8)

予測の手順 (p.26):

1. 全データで最良モデルを推定し、2009 年以降生まれの馬の成績から、育種価と恒久環境「以外」の効果を差し引く（補正済み表現型値）。
2. 同じモデルを 2010 年までのデータだけで推定し、その育種価で 1 の値を予測する。
3. 2010 年までの育種価で、2009 年以降生まれの馬のうち各カテゴリで重賞を勝った馬を判別し、AUC を出す（pROC）。

2009 年以降生まれの馬のデビューは 2011 年以降なので、2010 年までのデータには本馬の出走が無い。予測は血縁（父母・兄弟）経由の遺伝情報だけで行われている。旧ノートでこの点を推測として書いたが、原本の記述 (p.26) で確認できた。

| 相関 (Table 7) | 東京 | 中山 | 京都 | 阪神 |
|---|---|---|---|---|
| 短距離 | 0.065 | 0.058 | 0.024 | 0.054 |
| 中距離 | 0.093 | 0.081 | 0.051 | 0.073 |
| 長距離 | 0.113 | 0.174 | 0.235 | 0.000（実際は −0.014 を0とした） |

| 重賞勝ち馬の AUC (Table 8) | 東京 | 中山 | 京都 | 阪神 |
|---|---|---|---|---|
| 短距離 | 0.661 | 0.524 | 0.560 | 0.565 |
| 中距離 | 0.635 | 0.578 | 0.516 | 0.592 |
| 長距離 | 0.668 | 0.628 | 0.776 | 0.655 |

- 距離帯ごとの平均相関は短 0.050、中 0.075、長 0.127 (p.27)。
- 相関を育種価割合の平方根で割った「正確度」は約 0.140 ± 0.116 (p.27)。
- 12 中7カテゴリで AUC < 0.6 で、ランダムよりわずかに良い程度 (p.29)。
- 重賞勝ち馬の割合は短・中距離で約 1%、長距離では 3.4–9.8%（東京長距離 0.098）。長距離で AUC が高いのは、遺伝率の高さに加えて陽性例の割合が大きいことも効く、と著者は述べる (p.29)。

## 著者が挙げる改善点 (pp.29–31)

1. **指標の選択**: 着順を争う競技なので、上級レースが下級レースより速いとは限らない。レース効果を入れると、新馬戦と重賞の水準差が完全に消える。賞金やレーティングに基づく指標の方が予測に向く可能性がある（生物学的解釈は犠牲になる）(pp.29–30)。
2. **距離の分け方**: 3区分は粗い。ポーランドのデータでは 1000 m と 1600 m の遺伝相関が 0.87 で、別形質とみなす目安 0.8 を超える (p.30)。
3. **モデル**: 距離・年齢による能力の変化を捉える変量回帰モデル（random regression）。ドイツのトロッターでは反復モデルより順位が安定した (p.31)。

## 批判的に読む

- **予測の目的変数が全データで作られている**。補正済み表現型値は、全期間（2011 年以降を含む）で推定したレース・騎手・年齢などの効果を差し引いた値。予測側（2010 年まで）は将来を見ていないが、評価対象の作り方に将来のデータが入っている。血統の予測力を測るには妥当だが、実運用の予測精度とは別物。
- **予測しているのは育種価だけ**。恒久環境効果（育種価より大きいカテゴリが多い）と残差は予測しようがない。著者も、育種価が分散の一部しか説明しないので相関や AUC は1に届かないと認めている (p.29)。
- **重賞勝ち馬の AUC は陽性率に影響される**。長距離のカテゴリは出走馬数が少なく重賞の比率が高い。距離帯間の AUC の比較は、母集団の違いを含んでいる。
- **芝・良馬場・4場・3歳以上に限定**。ダート、道悪、ローカル場、2歳戦の結果は分からない。
- **外れ値の除外**（1着から 4.5 秒以上、±3 SD）は、大敗した馬のデータを落とす。能力の低い馬の分布が切られている可能性がある。
- **再現性**: データは JRA-VAN（有料）で、R スクリプトは要請に応じて提供 (p.31)。
- 旧ノートでは、長距離で予測が良い理由として MSTN 遺伝子の関与を推測していたが、原本はそれに触れていない。著者の説明は「先行研究が 2400 m 超を含まない」ことと陽性率である。

## keiba-ai での使い方

- **血統特徴量の上限の目安**。出走歴の無い馬について、血縁だけから作る能力推定の相関は 0.02–0.24、平均 0.08。新馬戦の予測で血統特徴量に多くを期待しない。距離が長いほど血統の情報量は増える（長距離で相関 0.13 前後）。
- **目的変数はレース内の相対値にする**。分散の 82–91% がレース効果なので、走破タイムや速度をそのまま目的変数にすると、モデルはレース条件の差を学ぶだけになる。レース平均からの偏差、着差、レース内順位を使う。これは本論文の「着順を争う競技」という整理 (p.28) と一致する。
- **騎手効果の大きさの目安**。レース効果を除いた分散の 3–10%。育種価（10–22%）や恒久環境（6–27%）より小さいが無視できない。騎手のターゲットエンコーディングの寄与を測るときの比較基準になる。
- **馬番は線形で十分なことが多い**。2次項は12中4カテゴリで不要 (p.29)。馬番の特徴量を作るとき、まず線形の効きから確認する。
- **実験案（仮説）**: 新馬戦・未勝利戦を対象に、(a) 父・母父の産駒成績だけ、(b) それに調教・馬体重などを加えたモデルで、勝ち馬判別の AUC を比べる。(a) が 0.55–0.65 程度なら本論文と整合し、(b) との差が血統以外の情報の価値になる。距離帯（1600 m 以下 / 2400 m 以下 / それ超）別に分けて報告し、長距離ほど (a) が強いかを確かめる。
- **評価設計の教訓**。本論文は「予測側は 2010 年まで」を守ったが、目的変数の補正に全期間を使った。keiba-ai で、レース水準の補正（スピード指数の基準タイムなど）を全期間データで作ると同じ種類のリークになる。補正値も学習期間のデータだけで作る。
