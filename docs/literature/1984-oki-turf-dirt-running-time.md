# 同じ馬の芝タイムとダートタイムはどれだけ連動するか（JRA 3歳馬 83,594 頭）

> 一言で: 1970〜78年生まれの JRA 3歳馬（当時表記で4歳）の良馬場タイムを芝とダートで比べ、芝はダートより 2.5〜4.8 秒速く、分散も小さいこと、同じ馬の芝・ダートタイムの相関は 0.22〜0.57 にとどまり、距離が長いほど下がる傾向を示した。

## 要旨

JRA 競走馬総合研究所の沖による、走行タイムを競走能力の指標とする遺伝研究シリーズの第1報。
遺伝的評価の前段として「馬場の種類（芝・ダート）が環境要因としてどれだけ異質か」を調べた。
父の産地（外国産・内国産）と性で層別し、距離別に加重平均タイム・加重分散・変異係数・頻度分布・同一個体の芝ダート相関を比べている（p.215–218）。
統計手法は平均と分散の検定、相関係数だけで、モデルらしいモデルはない。
価値は、40年前の JRA データで「芝とダートは別の能力に近い」ことを数字で示した点にある。

## データ

日本中央競馬会『競馬成績公報』の磁気テープから、次の条件で抽出した（p.215）。

- サラブレッド、芝またはダート、内国産馬
- 4歳時（旧表記。現在の3歳）の成績
- 1970〜1978年生まれ
- 良馬場のみ
- 競走中事故、障害競走、去勢馬は除外

合計 83,594 頭分の成績（Table 1, p.215）。

| | 父外国産 | 父内国産 | 計 |
|---|---:|---:|---:|
| 牡 | 42,247 | 6,119 | 48,366 |
| 牝 | 30,983 | 4,245 | 35,228 |
| 計 | 73,230 | 10,364 | 83,594 |

当時は外国産種牡馬の産駒が9割近くを占めていたことが分かる。
距離は 1,200〜1,800m（相関分析は 1,700m を含む）で、長距離は対象外。
1頭が同条件で複数回走った場合の扱い（平均か、初回か）は本文から読み取れず未確認。

## 方法

1. 各個体について、馬場の種類別・距離別に平均タイムを求める。
2. 馬場・父産地・性・距離で層別し、頭数で重みづけした加重平均タイム $M$ と加重分散 $V$ を求める（p.215）。
3. 芝とダートの分散の差を F 検定し、等分散なら通常の t 検定（式1）、不等分散なら Welch 型の近似 t 検定（式2、自由度 $\phi$ は Satterthwaite 型）で平均の差を検定する（p.216）。

$$t = \frac{|M_t - M_d|}{\sqrt{V_t/N_t + V_d/N_d}},\quad \frac{1}{\phi} = \frac{c^2}{N_t - 1} + \frac{(1-c)^2}{N_d - 1},\quad c = \frac{V_t/N_t}{V_t/N_t + V_d/N_d}$$

$M_t, M_d$ は芝・ダートの加重平均タイム、$V$ は加重分散、$N$ は頭数。

4. 変異係数（CV）と頻度分布を比べる。
5. 芝とダートの両方を同じ距離で走った個体について、芝タイムとダートタイムの相関係数 $\gamma$ を求める。

## 主な結果

### 平均と分散（Table 2, p.216）

芝はすべての層でダートより有意に速い（P<0.01）。
差は父外国産の牝で 2.52〜4.54 秒、牡で 2.57〜4.59 秒、父内国産の牝で 2.84〜4.71 秒、牡で 2.95〜4.80 秒（p.217）。

抜粋（父外国産・牡）:

| 距離 | 芝 N | 芝 M (秒) | 芝 V | ダート N | ダート M | ダート V |
|---|---:|---:|---:|---:|---:|---:|
| 1,200m | 1,040 | 73.24 | 2.801 | 1,850 | 75.76 | 5.114 |
| 1,400m | 1,230 | 86.27 | 3.169 | 1,955 | 89.19 | 2.666 |
| 1,600m | 2,889 | 98.74 | 2.481 | 1,958 | 102.88 | 4.521 |
| 1,800m | 3,304 | 112.53 | 2.991 | 2,463 | 117.07 | 4.415 |

分散はおおむね芝 < ダートだが、父外国産の 1,400m は牡牝とも逆（芝 > ダート）になる。父内国産は雌雄とも芝 < ダートで、牡 1,800m、牝 1,200m・1,400m を除き 1% 水準で有意（p.216 本文）。ただし Table 2 の検定欄で P>0.01 なのは牝 1,800m、牡 1,200m・1,400m で、本文と表で雌雄が入れ替わっている（誤植とみられるがどちらが正しいかは未確認）。
父産地の比較では、芝はすべて父外国産 > 父内国産（遅い）、ダートはすべて父外国産 ≦ 父内国産で、つまり芝は内国産種牡馬の産駒、ダートは外国産種牡馬の産駒がやや速い（p.217）。
性では、父外国産芝 1,200m と父内国産ダート 1,200m を除き、牝が牡より遅い（p.217）。

### 変異係数（Table 3, p.217）

父外国産の牡牝とも、芝の CV は距離が長くなるほど下がる（牝 2.12 → 1.55、牡 2.29 → 1.54）。
ダートではその傾向ははっきりしない。
著者はダートのクッション層（上層に反流動性の砂）が走りにくく、タイムのばらつきを大きくしていると解釈している（p.218）。

### 頻度分布（Fig. 1, p.217）

1,200m と 1,800m の頻度分布で、ダートの分布は芝の分布を x 軸の右（遅い方）へ平行移動した形をしている。
これは「ダートでは一律に遅くなる」ことを示すが、個体の順位まで保たれるかは相関を見ないと分からない。

> 芝馬場とダート馬場の環境要因が異質的であることが示唆された。（p.215 要約）

## 批判的に読む

- 相関の分母が小さい。芝とダートを同じ距離で走った馬は各セル 53〜277 頭しかなく、全体 83,594 頭のごく一部。両方を走る馬は「芝で勝てずダートに回った」など選択された集団で、相関は全体の馬の真の相関より低く出ている可能性がある（推測。著者はこの選択バイアスに触れていない）。
- 補正なしの生タイム。レース（ペース・開催日・競馬場）、負担重量、騎手を補正していない。続報の [沖ら 1995](./1995-oki-jockey-racing-time.md) と [沖・佐々木 1996](./1996-oki-genetic-trend-running-time.md) で混合モデルによる補正に進む。相関が低い理由の一部はレース条件のノイズ（測定誤差）による希釈で、能力そのものの相関はもっと高い可能性がある。
- 競馬場が混ざっている。競馬場ごとのコース形状・ダートの砂質の違いは層別されていない。
- 3歳・良馬場・1,200〜1,800m に限るので、古馬・道悪・長距離には一般化できない。
- 1970年代のダートは現在と砂の厚さや管理が違う。数値をそのまま現在の JRA に当てはめない。
- 遺伝研究と言いつつ遺伝率や遺伝相関は推定していない（表現型相関のみ）。

## keiba-ai での使い方

- 能力特徴量は馬場種別ごとに分けて作る。芝の過去タイム指数をダートの予測にそのまま使うと、表現型相関 0.2〜0.6 程度の情報しかない。芝・ダート別の指数を持ち、片方しかない馬には「もう一方の馬場からの縮小推定」（相関係数ぶん平均に寄せる）を使う案が考えられる。
- 仮説 H1: 「初ダート」「初芝」フラグと、反対馬場での指数を両方入れたモデルは、反対馬場の指数を同じ馬場の指数として混ぜたモデルより、初挑戦馬の log loss が小さい。評価は初挑戦馬に限った log loss とキャリブレーション。
- 仮説 H2: 芝・ダートの相関は短距離ほど高い（1,200m で 0.55 前後）。距離別に「反対馬場からの移植の効き」を変える（短距離では強く、中距離では弱く）と良い。現在のデータで同一馬の芝・ダートのタイム指数相関を距離別に再計算し、この古い結果が再現するか確かめる。
- ダートの方がタイムの分散が大きい（Table 2）ので、ダートのレースでは予測分布をより広くとる（勝率がより平らになる）可能性がある。レースタイプ別にキャリブレーションを確認する根拠になる。
- 父系の特徴量（父の産地・系統）が芝とダートで逆向きに効く例として、馬場種別と血統の交互作用を入れる根拠になる。
