# 香港の公開データで市場に勝てるかを検定し、「勝てない（NO-GO）」と結論した研究ツール

> 一言で: 2025/26年の HKJC 1季（765レース、うちウォークフォワードの外部検証356レース）で、条件付きロジット＋勾配ブースティングの基本モデルを Benter 型の2段階で市場と結合した。モデルの確定オッズに対する log loss の改善は +0.0045 nats/レース（95%CI −0.0013〜+0.0107）で有意でなく、結合の重みは市場 1.17、モデル 0.02。控除率 17.5% を超える +EV の馬は0頭。「賭けない」を既定の出力にした。

## データ

- HKJC の結果ページ（サーバ描画）から、レース条件、着順、枠、斤量、騎手・調教師、区間タイム、確定単勝オッズ（SP）、全券種の配当を取得。robots.txt を守り、1ホストあたり4秒以上の間隔、キャッシュ、取得元の記録、1回の取得件数の上限を設ける。
- HKJC は過去オッズの履歴を公開していないので、SP（結果ページの単勝オッズ）が終値（closing line）。
- Kaggle の `gdaley/hkracing` 形式の CSV も取り込める。
- 生データは利用規約上再配布しない。

## 特徴量

- レース条件、申告済みの出走馬情報、**厳密に過去のレース**から集計した成績、過去だけで作った基準タイム（par）に対するスピード指数、控除を除いた市場確率（de-vigged）。
- 「未来のレースを追加しても過去の行の特徴量が変わらない」ことをテストで保証する。

## モデルと目的変数

- 1着の確率。条件付きロジット（Plackett–Luce）と勾配ブースティング。
- **Benter の2段階結合**: `log(model_prob)` と `log(market_prob)` を説明変数にした2パラメータの結合器を学習。
- 組み合わせ券は Harville とモンテカルロで確率を出す。

## 評価

- ウォークフォワードの外部検証。
- **主指標は closing-line value（CLV）**: パリミュチュエルでは終値が精算価格そのものなので、「終値に勝つ」= 市場より較正が良いこと。勝ち馬の log loss の差（モデル − 市場）を外部検証で測り、ブートストラップ CI を付ける。
- 期待値は `EV = p·O − 1`（O は控除込みの確定オッズ）。市場確率で全頭買えばちょうど −控除率になる。
- 対照として、全頭買い、1番人気買い、モデル1番手買い、**プラセボ**（市場と整合する帰無モデルで同じパイプラインを回す）、学習と外部検証の差を出す。
- 履歴の紙上取引バックテストは、各レースの前までのデータで学習し、実際の確定オッズで買って控除後の損益を集計する。

## 結果

「The result, up front」の表より（2025/26季、外部検証356レース）:

| 検定 | 結果 |
|---|---|
| CLV（log loss 差） | +0.0045 nats/レース、95%CI [−0.0013, +0.0107]、有意でない |
| 控除後に +EV の馬 | 0頭 |
| 全頭買い ROI | ≈ −控除率 |
| 2段階結合の重み | 市場 ×1.17、モデル ×0.02 |
| プラセボ | 差 ≈ 0（パイプラインが偽の優位を作らない） |
| 判定 | NO-GO |

- 紙上取引: モデル1番手、1番人気、全頭買いはいずれも有意に負（≈ −控除率）。非負の数値は、モデルと市場が大きく食い違った**4レース**に集中した少数の賭けだけで、意味をなさない。先読み（lookahead）と統計の誠実さについて、2人の監査役による敵対的レビューを受けたと書いている。

## 落とし穴と教訓

- Phase 0 の調査報告（research_report.md）で、先に「勝てない見込み」を文献から見積もってから作っている。HKJC は売上が大きく（2024/25年の競馬売上 約1,389億 HKD）、売上の大きい市場ほど効率的（Walls & Busche 1996）。Benter の利益は市場との結合、大規模、締切直前の購入、リベートの組み合わせで成り立っていた、と整理している。
- 控除率は単勝・複勝・馬連・QPL で約17.5%、組み合わせ券で23〜25%。1プール内のダッチング（全頭買い）は代数的に −控除率で、プール間の価格差は裁定ではない。
- 「賭けない」を既定にし、優位判定のゲートは既定で切っておく。推奨はそのときのオッズとともに記録し、結果と突き合わせて自分の CLV と損益を追う。

## 批判的に読む

- 外部検証は356レースと短い。log loss 差 +0.0045 の CI 幅（約0.012）は、小さな優位を検出するには足りない。「優位がない」ではなく「この規模では優位を示せない」と読むのが正確。
- 確定オッズを市場確率に使っているので、購入時点のオッズでの評価ではない。ただし結論が否定的なので、この差は結論を弱めない。
- 特徴量は公開の結果ページにあるものに限られ、調教、獣医情報、馬具、コメントなどは入っていない。[stevw 2026](./2026-stevw-hkjc-ml-research-platform.md) はそれらを入れても同じ結論に至っている。
- 開発には LLM エージェントが関わっているように読める（2人の監査役レビュー、短期間）。数値は README の範囲でしか確認できない。

## keiba-ai での使い方

- **CLV（市場との log loss 差）にブートストラップ CI を付けたものを主指標の一つにする**。JRA でも、確定オッズから控除を除いた市場確率の log loss を基準に、モデルや結合モデルの差と CI を報告する。回収率より分散が小さく、少ないレース数で判定できる。
- **プラセボ検定**: 市場確率そのもの（あるいは市場確率からサンプリングした着順）を入力にしてパイプライン全体を回し、回収率が −控除率、CLV が0になることを確かめる。評価コードのバグや先読みの検出に使える。
- 「未来のレースを追加しても過去の特徴量が変わらない」テストは、特徴量生成の回帰テストとしてそのまま入れる。
- Benter の第2段結合器を学習したときの市場とモデルの重みを毎回記録する。モデルの重みが0に近ければ、その特徴量セットは市場に情報を足していない。
