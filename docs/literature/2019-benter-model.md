# Benter モデル：ファンダメンタルモデルと市場オッズの2段階結合

> ファイル名は 2019 のままだが、原論文は 1994 年。原本は World Scientific 2008 年再録版（gwern.net に置かれたもの、16ページ）で、ページ番号は書籍の 183-198。

> 一言で: ファンダメンタル要因の条件付きロジットで作った勝率は、単独では校正されて見えても「大衆とずれた馬」で系統的に大衆側へ外れる。そこで勝率の対数と大衆確率の対数をもう1段のロジットで結合し、偏りを消す。モデルの価値は単独の疑似 $R^2$ ではなく、大衆に加えたときの $R^2$ の増分 $\Delta R^2$ で測る (pp.186-189)。

## 背景と立場

著者は香港で5年間、コンピュータ予想による賭けを実際に運用した当事者である (p.195)。
既存の儲かる方式はオッズだけを見る「テクニカル」なもの（複勝・連勝の歪み、オッズの動き）が中心で、機会が少なく利益も小さい。職業として成り立つには、全レースを予想して多くの有利な賭けを見つけるファンダメンタル方式が必要、という問題意識 (p.183)。

## ファンダメンタルモデル

Bolton and Chapman (1986) の多項ロジットを使う (p.184)。ファクターは次の5群 (p.184)。

- 現在の調子: 近走成績、前走からの間隔、調教、馬齢
- 過去成績: 着順、着差、補正タイム
- 過去成績の補正: 相手の強さ、斤量、騎手の寄与、不利、枠の有利不利
- 今回の条件: 斤量、騎手の能力、枠
- 適性: 距離、芝ダ、馬場状態、競馬場

ファクターの定義の作り込みが利益を決める、と強調する。距離適性の例 (p.185):

| 名前 | 出典 | 定義 |
|---|---|---|
| NEWDIST | Bolton–Chapman | 過去4走中3走が1マイル未満なら1 |
| DOK | Brecher | 今回距離 ±1/16 マイルの過去走で上位半分か 6.25 馬身以内なら1 |
| DPGA | 著者 | 距離以外の全要因で過去各走の着順を回帰予測し、残差を「今回距離との近さ」に回帰。その傾きを標準誤差で割って標準化 |

DPGA の計算は数千行のコードになる (p.185)。
他にも、常識的な理由が分からないのに有意な「過去の出走数」のような変数は、標本が大きいから確信をもって入れられる、と述べる (p.186)。変数は高度に相関した寄せ集めになり、個々の係数は解釈しにくいが、予測には問題ない (p.186)。

必要なデータ量は、モデル開発と検証で 500〜1,000 レースが最低限。1,000 レースを超えてもサンプル外精度は劇的には上がらない (p.185)。閉じた馬の集団（同じ馬同士が限られた競馬場でだけ走る、香港のような場）が最もモデル化しやすい (p.185)。

## なぜ2段階が要るか：大衆とずれた馬での偏り

データは香港ロイヤルジョッキークラブの 1986年9月〜1993年6月の全レース、3,198 レース、32,877 頭 (p.187)。

- 大衆確率（Table 1）もファンダメンタル確率（Table 2）も、確率帯ごとの実際の勝率とよく一致する (pp.186-187)。
- ところが「大衆 > モデル」の馬（15,741 頭）と「大衆 < モデル」の馬（17,136 頭）に分けると、モデルの確率は**どの帯でも大衆側に外れる** (p.187, Tables 3-4)。

| 確率帯（モデル） | 大衆 > モデル: 予測 → 実際 (Z) | 大衆 < モデル: 予測 → 実際 (Z) |
|---|---|---|
| .050-.100 | .073 → .091 (4.7) | .074 → .058 (−4.3) |
| .100-.150 | .122 → .147 (3.7) | .123 → .098 (−4.2) |
| .150-.200 | .172 → .227 (5.0) | .173 → .154 (−2.1) |

(p.187, Tables 3-4 から抜粋)。「大衆 < モデル」はまさにモデルが買いと判断する馬なので、この偏りを放置すると優位性を過大に見積もる (p.187)。

### 結合式

$$c_i=\frac{\exp(\alpha f_i+\beta\pi_i)}{\sum_j\exp(\alpha f_j+\beta\pi_j)}$$

$f_i$ は**サンプル外**のファンダメンタル確率の対数、$\pi_i$ は大衆の暗黙確率の対数 (p.187, 式1)。$\alpha,\beta$ は過去レースで最尤推定する。ファンダメンタル確率を学習に使ったレースで結合すると、モデルの重要度を過大評価するので、別の標本のレースで推定する (p.188)。$\alpha$ と $\beta$ はモデルと大衆の相対的な正しさと読める。

結合後の確率は全体でも (Table 5)、大衆とのずれで分けても (Tables 6-7) 偏りがない。結合モデルは大衆やモデル単独より確率の散らばりが大きく、より情報を持つ (p.188)。

## 評価指標：$\Delta R^2$

疑似 $R^2 = 1-\mathrm{LL(model)}/\mathrm{LL(等確率)}$ (Bolton–Chapman) を使い、$\Delta R^2=R^2_{\text{結合}}-R^2_{\text{大衆}}$ をモデルが加えた情報量の指標とする (p.189, 式3-4)。

| モデル | $R^2$ |
|---|---|
| 大衆 | .1218 |
| ファンダメンタル | .1245 |
| 結合 | .1396 |
| $\Delta R^2$ | .0178 |

(p.189)。小さく見えるが、大きな利益に対応するという。著者の経験では、$\Delta R^2$ が大きいほど賭けのシミュレーションの利益も必ず大きかった (p.189)。

単独の $R^2$ では価値が分からない例 (pp.189-190; 1988年9月〜1993年6月の 2,313 レース):

| モデル | 単独 $R^2$ | 大衆と結合 |
|---|---|---|
| 大衆 | .1237 | — |
| 9変数のファンダメンタル | .1016 | .1327 |
| 新聞予想家 約48人の集計 | .1014 | .1239 |

予想家は1着 6点・2着 3点・3着 1点で集計した。単独では同等だが、大衆と結合すると予想家はほとんど情報を足さない (p.190)。

## 賭け方

- 期待リターン $er=c\times div$、優位性 $=er-1$ (p.190)。
- 出走歴がなくモデルが確率を出せない馬（unratable）は大衆の確率をそのまま与え、残りを再正規化する (p.190)。
- 単一の賭けの Kelly 比率は $K=\text{advantage}/(\text{dividend}-1)$ (p.191, 式5)。
- 全額 Kelly は勧めない。優位性を2倍以上過大評価すると資金の成長率が負になり、実運用では過大評価が起こりやすい。資金の半分以上を失う下落もよくある。1/2 や 1/3 の分数 Kelly を使う (p.191)。
- パリミュチュエルでは自分の賭けが配当を下げるので、資金が無限でも期待利益を最大にする賭け額がある。例: 勝率 .06、配当 20、プール \$100,000 なら最大は \$416（期待利益 \$39.6）。その 2/3 の \$277 でも期待利益の 90% が得られる (p.191)。

### 連勝式

単勝では不利な2頭（$er$ .955 と .996）でも、Harville で計算した連複の確率は大衆の 1.4 倍になり、控除率 17% を仮定した合理的な配当で $er=1.16$ になる (p.192)。

> the more exotic (i.e. specific) the bet, the higher the advantage (p.192)

複勝・ワイド型（place, show）は逆に差が薄まる (p.192, 注2)。

### Harville 公式の補正

Harville は2着・3着の争いがよりランダムになることを無視する。1着（と2着）を既知としたときの条件付き確率を見ると、人気薄は予測より多く、人気馬は少なく2・3着に来る。3着でより顕著（勝率 .400 超の馬の3着: 予測 .492、実際 .333、Z = −8.3）(p.193, Tables 9-10)。

補正 (p.193, 式7-9):

$$\sigma_i=\frac{\exp(\gamma\log\pi_i)}{\sum_j\exp(\gamma\log\pi_j)},\quad \tau_i=\frac{\exp(\delta\log\pi_i)}{\sum_j\exp(\delta\log\pi_j)},\quad \pi_{ijk}=\frac{\pi_i\,\sigma_j\,\tau_k}{(1-\sigma_i)(1-\tau_i-\tau_j)}$$

最尤推定値は $\gamma=0.81$、$\delta=0.65$ で、偏りが大きく減る (pp.193-194, Tables 11-12)。これらは普遍定数ではなく、競馬場によって大きく違う値が報告されている (p.194)。
また、勝率に本命大穴バイアスがある市場では、それが Harville の偏りと打ち消し合うので、偏りは目立ちにくい (p.197, 注3)。

## 実現可能性と結果

- 1レースの売上に対する現実的な最大期待利益は 0.25〜0.5%（資金無限の場合）。小さな市場でも 1.5% を超えることはまずない。資金が1レース売上の半分程度なら 0.1〜0.2% (p.195)。
- 他のコンピュータ予想家の存在は特に不利。独立に作ったモデルでも互いに相関し、同じ馬の配当を下げ合う (p.195)。
- 運用: データベース構築と優位なモデルの開発に約5人年、高収益化にさらに約5人年。初期の開発・検証は約 2,000 レース。1レースの売上が 1,000 万ドル超でオッズが安定し、最終オッズを正確に見積もって賭けられた。単一レース・連勝式の全プール（複勝系を除く）の期待値プラスの賭けを保守的な分数 Kelly で買い、年約 470 レースに賭けた。控除率は平均約 19% (p.195)。
- 5シーズン中4シーズンが黒字、赤字の年の損失は初期資金の約 20%。連勝式の方が単勝より回収率が高く、理論と整合した (p.195)。資金の対数の推移図を示すが、回収率の数値はない (p.196)。

## 批判的に読む

- **数値の大半はモデル開発の内部評価**で、Table 1-7 の確率がどの期間のサンプル外予測かは明示が弱い（「ファンダメンタル確率はサンプル外」と言うのみ）。結合式の $\alpha,\beta$ を推定した標本と、Table 5-7 の評価標本が同じかどうかは書かれていない。
- **運用成績は定量的でない**。回収率、賭け件数、賭け金の推移、統計的有意性の計算がない（著者も「厳密な計算はしていない」と書く, p.195）。
- 実運用中もモデルを継続的に改良・再推定しており、どのモデルでの成績かは固定されていない。
- 疑似 $R^2$ はレース頭数の分布に依存するので、市場間・期間間で $R^2$ の水準を比べるのは危うい。$\Delta R^2$ は同じ標本での差なので比較的安全。
- 1990 年前後の香港という条件（閉じた集団、巨大なプール、コンピュータ予想家が少ない）に強く依存する。著者自身、他の予想家が増えれば市場は効率化すると予言している (p.196)。

## keiba-ai での使い方

- **評価指標の標準化**: 実験のリーダーボードに「オッズのみモデルの log loss − 結合モデルの log loss」（$\Delta R^2$ と同じ情報）を必須の列として置く。単独の log loss や的中率では、予想家の例のように価値を誤判定する。→ ADR 候補
- **2段階の分割**: 第1段は時系列 out-of-fold 予測で作り、第2段 $(\alpha,\beta)$ はそれと別の期間で推定する（[Sung 2007](./2007-sung-two-step-conditional-logit.md) も同じ）。
- **偏りの診断表**: Tables 3-4 と同じ「大衆 > モデル / 大衆 < モデル」で分けた校正表を、評価スクリプトの標準出力にする。買い対象の馬（大衆 < モデル）での校正が回収率に直結する。
- **3連単**: $\gamma,\delta$ を JRA データで推定する（discount 補正）。仮説: JRA でも $\delta<\gamma<1$ で、値は芝ダ・頭数で異なる。
- **新馬・出走歴の少ない馬**: unratable 馬に大衆確率を割り当てて再正規化する方法を、新馬戦や海外馬の扱いの基準にする。
- **期待利益の上限**: JRA の売上規模で、自分の賭けによる配当低下を入れたシミュレーションを行う。結果の回収率が「売上の 0.25〜0.5%」という目安と比べて非現実的に高ければ、リークを疑う。
