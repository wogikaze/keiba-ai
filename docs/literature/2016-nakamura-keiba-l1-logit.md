# L1 正則化ロジスティック回帰で JRA の1着馬を当てる（学部2年生の自主研究報告）

> 一言で: JRA の 2010〜2013年で学習した L1 正則化ロジスティック回帰（1着か否かの二値）で 2014年の 3,026 レースを予測し、各レースで最も確率の高い馬が勝ったのは 742 レース（24.52%）だった。オッズは使っておらず、回収率は評価していない。

## 要旨

大阪大学基礎工学部情報科学科の2年生（アドバイザー: 伊森晋平）による自主研究奨励事業の報告書（p.2）。
本文は実質4ページで、査読はない。
目的は「新規の競馬ファンの予想を助ける情報を示す」ことで、変数選択で重要な説明変数を見つけ、予測値を見せる簡単な Web アプリまで作っている（p.2, p.4–5）。
研究としては小さいが、オッズを使わない線形モデルで JRA の単勝的中率がどの程度になるかの参考値として使える。

PDF の p.1 はリポジトリの表紙で、報告書本体は p.2〜5。

## データ

- JRA の過去のレース結果を Web サイトから収集（どのサイトかは書かれていない）（p.3）。
- 学習 2010〜2013年、テスト 2014年（p.4）。テストは 3,026 レース。学習側のレース数は書かれていない。
- 前走のデータを使うので、前走のない馬（新馬など）を含むレースは丸ごと除外（p.4）。この除外で 2014年の JRA 全レース（約3,450）のうち約 3,026 が残ったと読める（全レース数はノート作成者の概算）。
- Twitter の投稿を API で集める計画だったが、件数が想定より少なく予測には使わなかった（p.3）。

## モデル（p.4）

- 目的変数: 各出走馬が1着なら 1、それ以外 0。
- 説明変数: 騎手名、年齢、性別、調教師名、枠番、馬番、斤量、負担重量（両方挙がっているが違いは不明）、前走距離、前走との距離差、前走着順、出走する競馬場・枠番ごとの平均着順など。質的変数はダミー変数。
- L1 正則化つきロジスティック回帰。正則化パラメータは交差検証で決定。ランダムフォレストなど他の手法も試したが、L1 ロジスティック回帰より良くなかった（具体的な数値はなし）（p.3–4）。
- 評価指標は「正判別率」= 各レースで予測確率が最大の馬が実際に1着になった割合。

レース内で確率を正規化していない（各馬を独立な二値分類として扱う）点は、条件付きロジットとの違いとして意識しておくべき。

## 結果

### 的中率（p.4）

| テスト | レース数 | 的中 | 正判別率 |
|---|---:|---:|---:|
| 2014年 | 3,026 | 742 | 24.52% |

### 変数選択（p.4）

非ゼロ係数 153 個、ゼロ係数 566 個。

| 残った説明変数（係数≠0） | 落ちた説明変数（係数=0） |
|---|---|
| 騎手ダミー 64 人分 | 騎手ダミー 258 人分 |
| 年齢、性別 | 前走着順 |
| 調教師ダミー 61 人分 | 調教師ダミー 288 人分 |
| 枠番、馬番、斤量、負担重量 | 競馬場・枠番別の平均着順 |

前走着順が係数 0 になったのは直感に反する。
騎手・調教師のダミーが馬の強さの代理になって前走着順の情報を吸収した可能性、または前走着順を数値のまま線形に入れたことの影響が考えられる（推測。著者は理由を議論していない）。
前走距離・距離差が残ったかどうかは本文に明記がない。

### その他（p.4–5）

- ツイートは MeCab で形態素解析し、出走馬名と同じツイートに出るポジティブ・ネガティブな単語を数えて馬の「イメージ」を数値化した。予測には使っていない。
- Flask で Web アプリを作り、予測勝率と、単勝オッズから計算した「払戻率の期待値」を馬番ごとに表示した（図1）。期待値の計算方法や、それに基づく回収率の検証はない。

## 批判的に読む

- ベースラインがない。JRA の1番人気の勝率はおおむね 30% 強なので（ノート作成者の一般知識による。本報告書には記載なし）、24.5% はオッズの情報に届いていない可能性が高い。
- 評価は的中率だけ。確率の較正（log loss、Brier）も回収率もない。
- 時系列分割（2010〜13 で学習、2014 でテスト）なのでリークの心配は小さい。ただし「競馬場・枠番別の平均着順」の集計期間が学習期間に限られているかは書かれていない。
- 前走のない馬を含むレースを丸ごと落としているので、2歳戦・新馬戦が抜けている。テストの的中率は全レースのものではない。
- 騎手・調教師を数百のダミー変数で入れているので、乗り鞍の少ない騎手は L1 で 0 になるのは当然で、「重要でない」と解釈するのは早い。
- データの取得元、前処理、学習データの件数が書かれておらず、再現は難しい。

## keiba-ai での使い方

- 下限の参考値: オッズなし・線形・少数の特徴量で単勝的中率約 25%（前走あり馬のみのレース）。keiba-ai のオッズなしモデルがこれを下回るなら何かがおかしい。
- 仮説 H1: 前走着順は「数値のまま」より「頭数で割った相対着順」や「着差（秒）」の方が効く。本報告で前走着順が落ちたのは表現の問題かもしれない。アブレーションで確かめる。
- 騎手・調教師のダミーを大量に入れる代わりに、乗り鞍で縮小した target encoding を使う。L1 で大半の騎手が 0 になったのは、ダミー表現では少数乗り鞍の騎手の情報が使えないことを示す。
- 二値ロジスティック回帰の出力はレース内で合計 1 にならない。レース内 softmax（条件付きロジット）と比べると、同じ特徴量でも log loss と較正が改善するはず（仮説）。
- SNS のテキスト特徴量は、2015年時点の学生規模の収集では件数が足りなかった。テキスト特徴量を試すなら、馬名の略称・一般語との衝突（本報告 p.5 が挙げる問題）への対策が先に要る。
