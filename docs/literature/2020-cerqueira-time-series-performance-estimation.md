# 時系列の性能推定法 11 種の比較：定常ならブロック CV、非定常なら反復ホールドアウト

> 一言で: 合成データ（定常）では [Bergmeir 2018](./2018-bergmeir-cv-time-series.md) と同じく CV 系、特にブロック CV が末尾ホールドアウトより良い推定をした。しかし実データ 174 系列のうち非定常な 77 系列では、時間順を保ち複数の検証期間で繰り返すホールドアウト（Rep-Holdout）が最も正確で、通常の無作為 CV は最悪かつ楽観的だった。

Springer の OA 版（32 ページ）を読んだ。以下のページ番号は誌面の頁（1997–2028）。

## 実験設定

### データ（3.2 節）

- **実データ**：tsdl データベースの単変量系列のうち 500 点以上・欠損なしの 149 系列と、著者らの先行研究から 25 系列、合計 174 系列。金融、物理、経済、エネルギー、気象など。長さ 506〜23,741 点を最大 4,000 点に切り詰め (p.2004–2005)。
- **定常性**：Nason (2013) のウェーブレットスペクトル検定（Bonferroni と FDR の多重検定補正）で 2 次定常性を判定。**97 系列が定常、77 系列が非定常** (p.2005–2006)。
- **合成データ**：Bergmeir らと同じ S1（AR(3)）、S2（MA(1)）、S3（季節 AR）。長さ 200、各 1,000 回のモンテカルロ (p.2006)。

### 予測タスクと評価の枠組み

- 純粋な自己回帰：時間遅れ埋め込みで過去 p 点から次の 1 点を予測。p は偽近傍法（False Nearest Neighbours, 許容 1%）で選ぶ。合成データは p=5 固定 (p.2004, 2008)。
- 系列の前 70% を推定集合、後 30% を検証集合にする。推定集合の中で各手法が誤差 $\hat g$ を推定し、推定集合全体で学習し直したモデルの検証集合の誤差を真の誤差 $L^m$ とする (p.2007, Fig.6)。
- 指標：APAE $=|\hat g - L^m|$（推定誤差の大きさ）と PAE $=\hat g - L^m$（バイアス、負なら楽観的）。予測誤差は RMSE (p.2009)。
- 学習器：ルールベース回帰（Cubist、委員会 5）、ランダムフォレスト（ranger、100 本）、Ridge 付き GLM（glmnet）。本文は RBR の結果、付録に他 2 つ (p.2009–2010)。

### 比較した 11 手法（3.4.2 節, p.2008–2009）

| 系統 | 手法 | 中身 |
|---|---|---|
| CV | CV | 無作為 K-fold |
| | CV-Bl | 連続したブロックを fold にする K-fold |
| | CV-Mod | テスト点の近く（p 点）を訓練から除く |
| | CV-hvBl | ブロック CV で、テストブロックの前後 p 点を除く |
| OOS | Holdout | 推定集合の前 70% で学習、後 30% でテスト |
| | Rep-Holdout | 無作為に選んだ時点の直前 60%（系列長比）で学習、直後 10% でテスト、を 10 回 |
| 逐次（prequential） | Preq-Bls | ブロック単位、訓練窓が成長 |
| | Preq-Sld-Bls | ブロック単位、訓練窓がスライド |
| | Preq-Bls-Gap | 成長窓で、訓練とテストの間にギャップブロック |
| | Preq-Grow / Preq-Slide | 1 点ずつ「テストしてから学習」（成長窓 / スライド窓） |

K と反復数はいずれも 10。

## 結果

### 合成データ（4.1 節）

Bergmeir らの結果を再現した。CV 系、特にブロック型は Holdout より平均順位が良い。ただし Bergmeir らが試していない逐次（prequential）系も良く、S1 では Preq-Bls-Gap が最良、S2 では CV-hvBl が最良、S3 では差が小さく Preq-Sld-Bls が最良 (p.2010–2012, Fig.7–9)。

### 実データ（4.2 節）

| 系列 | 最良 | 補足 |
|---|---|---|
| 全 174 系列 | 手法ごとの順位のばらつきが大きく、すべてに最適な手法は無い (p.2012, Fig.10) | |
| 定常 97 系列 | CV-Bl（平均順位）。ベイズ符号順位検定では CV-Bl と CV-hvBl が Rep-Holdout より有意に良い | 無作為 CV と CV-Mod が最悪。「ブロック化」が重要 (p.2012–2013) |
| 非定常 77 系列 | **Rep-Holdout** が平均順位最良で、ベイズ検定でも他のすべてより有意に良い | 無作為 CV が最悪 (p.2013–2014, Fig.13–14) |

ベイズ符号順位検定（Benavoli ら 2017）では、APAE の Rep-Holdout 比の差が ±2.5% 以内を実質同等（ROPE）とした (p.2013)。

- **バイアス（PAE）**：多くの手法は誤差を過大評価する（悲観的）。**楽観的（過小評価）になるのは、1 点ずつの逐次評価（Preq-Slide, Preq-Grow）と、ブロック化しない CV と CV-Mod** (p.2015, Fig.15)。
- **Holdout より Rep-Holdout**：検証期間を複数にするだけで、どちらのシナリオでも改善 (p.2014–2015)。
- **標本サイズ**：1,000 点以上の 90 系列で推定集合を 100 点から 100 点ずつ増やしても、手法の相対順位はほぼ安定。ただし 1,000 点までの範囲での話 (p.2015–2016, Fig.16)。
- **記述的決定木**：系列の特徴（トレンド、歪度、尖度、自己相関、ハースト指数、リアプノフ指数、定常性）から最適手法を CART で予測。根は CV-Bl、最初の分岐は尖度で、尖度 2 以下なら Preq-Slide (p.2017–2018, Fig.17)。

著者は、実世界の系列は過去に現れていない未来の要素を含みうるので、Rep-Holdout が CV 系より良い選択だと結論する (p.2019)。

## 批判的に読む

- **単変量・1 期先・自己回帰のみ**。外生変数を含む多変量の予測（競馬のように特徴量の大半が外生）に結論が延長できるかは著者の「信じている」にとどまる (p.2019)。
- **真の誤差は「直後の 30%」1 区間**。非定常系列では、この区間の性質に評価が強く依存する。Rep-Holdout が良く見えるのは、検証期間とテスト期間の両方が時間順で、構造が似ているからかもしれない（推測）。
- 学習器はハイパーパラメータをほぼ既定値に固定しており、推定法を使ってモデル選択（ハイパーパラメータ探索）をしたときの「選ばれたモデルの真の性能」は評価していない。評価しているのは、固定したモデルの誤差をどれだけ正確に推定できるか。
- Rep-Holdout は無作為な時点の前後で学習・テストを取るので、テスト窓の後ろのデータは使わないが、窓同士は重なる。完全なウォークフォワードとは違う。
- 定常性の判定は 1 つの検定に依存する。

## keiba-ai での使い方

- **競馬データは非定常として扱う**：番組改編、馬場改修、騎手の世代交代、オッズ市場の参加者の変化がある。本論文の非定常系列の結果に従い、評価は時間順の分割を基本にし、検証期間を 1 つではなく複数（例：年ごと、四半期ごと）取って平均とばらつきを出す。
- **無作為 CV は楽観的**：出走単位の無作為 K-fold は、本論文の「CV（無作為）」と同様に誤差を過小評価する方向に働くと予想される。加えて、同一レース・同一馬の情報漏れがある。ハイパーパラメータ探索に使うとしても、最終報告には使わない。
- **ギャップの入れ方**：Preq-Bls-Gap のように学習とテストの間に空白期間を置く方法は、「前走情報が更新されるまでの時差」を模擬するのに使える。たとえば学習の最終日とテストの初日の間を 1 週空ける。
- **実験案（仮説）**：2015〜2022 年で、(a) 無作為 5-fold、(b) 年ブロック CV、(c) Rep-Holdout（無作為な基準日の前 3 年で学習、後 3 か月でテスト ×10）、(d) 年単位ウォークフォワードで logloss を推定し、2023 年の真の logloss との差（APAE, PAE）を比べる。本論文に従えば (c)(d) が最も正確で、(a) が最も楽観的になるはず。
