# 本賞金と騎手だけのロジスティック回帰で3着内を分類した入門記事と、その有馬記念版

> 一言で: JRA-VAN データラボの 2015〜2019 年のデータで「3着以内か」をロジスティック回帰で二値分類した入門記事。正解率 78% が「大半を4着以下と言っているだけ」だと混同行列で示し、アンダーサンプリングと標準化で F 値を 0.06 から 0.32 に上げた。続編（attach: `arima-2019`）では中山芝 2000m 以上に絞って4手法を比べ、2020 年の有馬記念を予想した。回収率は計算していない。

2020年9月公開の本編と、2020年12月の続編（LIFULL その2 Advent Calendar 2020）の2本をまとめる。どちらもランダム分割で、回収率の評価はない。価値は「正解率に騙されない」という教訓と、手法の失敗例としての読みやすさにある。

## データ

- 本編: JRA-VAN データラボを無料ソフト経由で CSV に出力した出馬表データ（syutsuba_data.csv）と成績データ（seiseki_data.csv）。期間は 2015〜2019 年の5年（「1. データの取得」の節）。3着以内 51,848 行、4着以下 193,711 行で、合計 245,559 行（「データ不均衡を修正」の節）。
- 続編: 2015 年〜2020/12/20。全体は 20,677 レース・293,120 行で、そこから「中山競馬場の芝2000m以上」の 479 レース・6,621 行に絞った（「使用するデータセットの検討」の節）。中山芝 2500m だけでは 58 レース・711 行しかなく、少なすぎると判断した。

## 特徴量

- 本編は2つだけ。本賞金（各馬の獲得賞金の合計）と騎手名のダミー変数。騎手のダミー化で列は 295 になった。
- 続編は、馬番、レースクラス（新馬・未勝利=250 から G1=7000 までの独自の数値化）、過去3走のタイム指数の中央値、過去3走の4角通過順の中央値、騎手名・種牡馬名のダミー変数。タイム指数はデータ提供元の値。

## モデルと目的変数

- 目的変数は「3着以内なら1」の二値。
- 本編はロジスティック回帰。続編はロジスティック回帰・SVM・K近傍法・ランダムフォレストを比べ、最後は `predict_proba` の 3着内確率でレース内の順位を付けた。

## 評価

- 分割は `train_test_split(test_size=0.2, stratify=...)` のランダム分割。著者は本編で「時系列の並びで分けたほうが精度も上がると思われる」と書いているが、実際にはランダムのまま。
- 続編では、分割の前にデータ全体で `StandardScaler` を当てている。
- 指標は正解率・適合率・再現率・F 値。払戻を使った回収率はどちらの記事にもない。

## 結果

本編（「4. モデルの評価」の節。テストは 49,112 行）:

| 段階 | 正解率 | 混同行列（TP / FN / FP / TN） | F 値 |
|---|---|---|---|
| そのまま | 0.787 | 339 / 10,031 / 410 / 38,332 | 0.061 |
| 学習データを 1:2 にアンダーサンプリング | 0.777 | 1,111 / 9,259 / 1,703 / 37,039 | 0.169 |
| さらに標準化 | 0.778 | 2,510 / 7,860 / 3,054 / 35,688 | 0.315 |

最終段の適合率は 0.45、再現率は 0.24。回帰係数では本賞金が 0.444 で最大、騎手ではルメール（0.186）、M.デムーロ、戸崎圭太、川田将雅が上位だった。

続編（「アルゴリズムの選定」の節）:

| 手法 | 全体の適合率 | 全体の F 値 | 有馬記念 2015〜2019 の適合率 |
|---|---|---|---|
| ロジスティック回帰 | 0.42 | 0.40 | 0.0, 0.33, 0.66, 0.5, 0.33 |
| SVM | 0.42 | 0.35 | 1.0, 0.6, 0.66, 0.5, 0.75 |
| K近傍法 | 0.32 | 0.35 | 0.2, 0.5, 0.38, 0.33, 0.25 |
| ランダムフォレスト | 0.51 | 0.35 | 0.4, 1.0, 0.6, 0.33, 0.33 |

ランダムフォレストは既定パラメータで学習データの正解率 0.999、評価データ 0.761 となり、過学習の例として示されている。
2020 年の有馬記念では SVM とランダムフォレストを3回ずつ回し、ワールドプレミア（5番）とフィエールマン（13番）が毎回上位だったため、ワイド 5-13 を1点買った（2020/12/26 の追記）。3番手は回すたびに入れ替わり、著者は小さいデータでランダム分割をしたせいだろうと書いている。的中したかどうかは記事に追記がない（実際の結果ではワールドプレミアは3着以内に入っておらず、不的中だった。ノート作成者の確認）。

## 落とし穴と教訓

- 正例が約 21% のデータでは、ほぼ全部を「4着以下」と言うだけで正解率 78% になる。混同行列を見ずに正解率で喜ぶな、という本編の主題はそのまま使える。
- 二値分類は「データ全体から見て買える馬か」を判定するので、1レースに3頭以上の「1」が付いたり、1頭も付かなかったりする（続編の「過去の有馬記念のデータで検証」の節）。著者はここで確率順の順位付けに切り替え、2023 年の続々編でランキング学習に移った（[kazuktym 2023](./2023-kazuktym-ranking-arima.md)）。

## 批判的に読む

- 著者は「F 値はランダムなら 0.5 に収束する」と書くが、これは正例と負例が半々のときの話。正例率 21% のデータで半々に当てずっぽうをすると、適合率 0.21・再現率 0.5 で F 値はおよそ 0.30 になる（ノート作成者の計算）。最終の 0.315 は、当てずっぽうとほぼ同じ水準と読むべき。
- ランダム分割なので、同じレースの馬が学習と評価に分かれ、未来のレースで過去を予測する形になる。続編の「過去の有馬記念」5レースはデータセットに含まれており、それぞれ 8 割の確率で学習側に入っている。SVM の 2015 年の適合率 1.0 は、学習データを当て直しただけの可能性が高い。
- 続編は分割前に全データで標準化しており、評価データの統計が学習に混ざる（影響は小さいが手順として誤り）。
- 本賞金が「その時点までの累計」なのか、データ取得時点の累計なのかは書かれていない。後者なら未来の賞金が入るリークになる。
- 回収率がないので、馬券として役に立つかは判断できない。

## keiba-ai での使い方

- 3着内の二値分類を評価するときは、正解率ではなく対数損失や Brier スコアを主にし、「全部0」や「1番人気から3頭」などの素朴なベースラインと並べて出す。F 値を使うなら、正例率に合わせたランダムの基準値も一緒に書く。
- 獲得賞金のような累積値は「レース前日までの累計」になっているかを特徴量の単体テストで確かめる。
- 分割は時系列のみ（CLAUDE.md の評価ルール）。スケーラーなどの前処理も学習期間だけで fit する。
