# SVR で着順を回帰し、閾値を動かして「的中率と払戻」のトレードオフを見たグレイハウンド研究（AZGreyhound）

> 一言で: 31場1,953レースのグレイハウンド競走で、各犬の着順を線形 SVR で予測し、「予測着順がカットオフ以下なら買う」という閾値を 1.0〜8.0 で動かした。低い閾値では単勝的中率 45%、高い閾値（穴まで買う）では払戻が最大化し、的中率と払戻が逆向きに動くと主張する。

原本は著者サイトの PDF（25ページ、語数表記付きの原稿体裁）。ページ番号はこの PDF のページ。掲載誌版（CIIMA 8(2)）の頁とは異なる。

## 要旨

Chen et al. (1994) と Johansson & Sönströd (2003) の後継として、ニューラルネットの「勝ち／負けの2値分類」をやめ、SVR で予測着順（連続値）を出す (p.5-7)。2値分類だと1レースで複数頭に「勝ち」が付き、順位も付かないので、連勝式の買い方が決まらないというのが動機 (p.6, Table 1)。評価軸は的中率・払戻・効率（1ベット当たり払戻）の3つ (p.8-9)。

## データ

- 取得元: trackinfo.com の出走表と配当表を自動収集。全米の稼働中のグレイハウンド場。スクーリング（格付け用）レースは除外 (p.9)。
- 期間: 2007年1月7日〜3月7日 (p.10)。
- 規模: 41,473 事例・7,760 レースを集めたが、出走表に載る過去走が5走分で、直近7走が必要なため、使えたのは 1,953 レース、7,163 頭、31場 (p.10)。
- 主要7場のレース数（Table 2, p.10）: Caliente 1,408、Raynham/Taunton 1,323、Lincoln 1,174、Wichita 962、Melbourne 898、Tucson 788、Hinsdale 700、その他 507。合計は 1,953 を大きく超えるので、Table 2 は使用前の収集レース数と思われる（推測。本文に説明なし）。
- 平均出走頭数 7.03 (p.14)。
- 特徴量: Chen (1994) の10変数をそのまま使用（最速タイムの勝ち犬との差、勝率・連対率・複勝率、ブレイク平均、着順平均、7走・3走の平均タイム、グレード平均、格下げ加点）(p.10-11)。

## アルゴリズムと賭け方

1. Weka の SMO 実装で SVR（線形カーネル）を学習。目的変数は着順。10分割交差検証 (p.12-13)。
2. 出力は各犬の予測着順（例: 1.7604）。他の犬とは独立に計算される (p.11)。
3. 単勝・複勝（place = 2着以内）・show（3着以内）: 予測着順がカットオフ以下の犬すべてに $2 を賭ける。同じレースで2頭以上が該当すれば全部に賭ける (p.11-12)。
4. 連勝式（quiniela, exacta, trifecta, superfecta とそのボックス）: レースの最小予測値がカットオフ以下なら、予測順に並べた組を1点買う (p.12)。
5. カットオフを 1.0〜8.0 まで 0.1 刻みで動かす感度分析 (p.12)。

## 主な結果

単勝・複勝・show の的中率（Table 4, p.14 の抜粋）:

| カットオフ | 賭け数 | 単勝的中率 | place 的中率 | show 的中率 |
|---|---|---|---|---|
| 1.0 | 7 | 14.29% | 100% | 100% |
| 1.6 | 86 | 45.35% | 74.42% | 90.70% |
| 2.0 | 243 | 37.04% | 63.79% | 78.60% |
| 2.5 | 825 | 27.52% | 53.82% | 73.09% |

- ランダムに選んだときの的中率は単勝 14.22%、place 28.45%、show 42.67%。単勝はカットオフ 1.3〜5.2 でランダムより有意に高い（p<0.01）(p.14-15)。
- 払戻（Table 5, p.16）: 単勝の最大は +$1,248.40（カットオフ 3.1）、place は +$2,720.17（4.2）、show は +$7,341.95（4.2, 8,289 ベット）。3券種とも 1.6〜4.6 で払戻がプラス (p.15-16)。
- 効率（1ベット当たり, Table 6, p.17）: place はカットオフ 1.1 で $6.564（12ベット）、show は 1.9 で $4.370、単勝は 2.3 で $0.946（505ベット）。著者は Chen (1994) の BPNN の $1.248 に単勝効率で及ばないと認めている (p.17)。
- 連勝式: 的中率はボックスの方が高い。trifecta box はカットオフ 1.0 で 6点中3点（50%）、quiniela は 1.5 で 34.78%、superfecta box は 1.5 で 17.39% (p.18-19)。払戻最大は superfecta box の +$41,517.37（カットオフ 4.1、的中率 6.45%）(p.19)。効率は trifecta box がカットオフ 1.0 で $73.57 (p.20)。
- 場別（superfecta box, Table 7, p.21）: 的中率は Wichita 14.62% が最高、払戻は Caliente $17,353.20 が最大だが標準偏差 $322.88 と大きい。
- 外れ値: Caliente の日曜の払戻 $5,818.60 のうち、2007年2月18日の1日だけで $5,138.80 (p.22, Table 10)。

## 批判的に読む

- **時系列リーク**: 10分割交差検証で学習と評価をしており (p.13)、同じ2か月間のレースがランダムに混ざる。同じ犬の未来の走りが学習側に入る。報告値は将来レースでの成績ではない。
- **カットオフの事後選択**: 80通りのカットオフを試し、各券種で最良のものを報告している。多重比較の補正はなく、「単勝 45.35%」「superfecta box で 2,195.5%」はどちらも選択バイアスを含む。カットオフ 1.0〜1.2 の的中率 100% は 7〜15 ベットにすぎない。
- **払戻の定義が曖昧**: 「payout」は損益（純額）として扱われているように見える（単勝カットオフ 1.0 の効率 −$1.543 は純損益でないと説明がつかない）。一方 show で 8,289 ベット・的中 4,286 で +$7,341.95 は、show の配当水準からすると大きすぎる。Table 6 の show 効率がカットオフ 1.8→1.9 で $0.85→$4.37 に跳ぶのも不自然で、配当データの誤り（例: 単位違い、取消・同着）が混じっている疑いがある（筆者の推測）。
- **ボックスの費用**: superfecta box などのボックス買いの1点当たり費用と組数（何頭ボックスか）が本文に書かれていない。効率が「$2 当たり」とされている (p.20) が、ボックスは組数分の費用がかかるので、回収率として解釈できるか未確認。
- **オッズへの影響**: 自分の賭けによるオッズ変化は考慮していない。著者も結論で、大口だとオッズが悪化すると注意している (p.23)。
- **予測の独立性**: SVR も各犬を独立に評価しており、レース内での確率正規化はない。着順を回帰で当てる設計は、勝率推定（確率）とは別物。
- 長所: 31場・自動収集・券種の網羅は先行研究より広い。カットオフで的中率と払戻のトレードオフを可視化した点は有用。

## keiba-ai での使い方

- **閾値スイープは検証期間で決め、テスト期間では固定する**。本論文の「最良のカットオフ」は評価データ上で選ばれている。keiba-ai では、購入ルールの閾値（期待値>1.0 の下限など）を検証期間で決め、テスト期間の回収率は1回だけ測る。
- **外れ値の影響を必ず報告する**: 1日で払戻の大半を稼ぐ（p.22）ような結果は、3連単・3連複の回収率で頻繁に起こる。仮説: 3連系の回収率はブートストラップ（レース単位またはレース日単位）で信頼区間を付けないと比較できない。上位1%の配当を除いた回収率も併記する。
- **着順回帰 vs 確率**: 着順を回帰する設計は、keiba-ai の LambdaRank や Plackett-Luce の比較対象（ベースライン）として使える。実験案: 同じ特徴量で「着順回帰」「勝ち2値分類」「レース内 softmax」を比べ、対数損失と回収率がどれだけ変わるか。
- **配当データの検証**: 払戻の跳び（p.17）の教訓として、JRA の払戻データも同着・返還・取消を正しく処理しているか単体テストを書く。
