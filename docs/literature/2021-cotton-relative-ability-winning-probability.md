# 勝率から能力を逆算する「horse race problem」：格子上の畳み込みで任意の走破分布を較正する

> 一言で: 全馬の走破パフォーマンス分布が同じ形 $f^*$ の平行移動だと仮定し、与えられた勝率に一致する移動量（能力）$a_i$ を、格子上の生存関数の積と1次元の線形補間だけで数回の反復で求める。1,000 頭でも数秒、計算量は頭数にほぼ線形。これで勝率と整合的な馬単・3連単・複勝の確率が任意の $f^*$ で作れる (pp.6-13)。

原本は著者サイト（winning.microprediction.org）の改訂原稿（22ページ）。脚注に「最終版にきわめて近い」とある (p.1)。ページは原稿のもの。

## 問題

$X_1,\dots,X_n$ を格子上の離散的な走破スコア（小さいほど良い）とし、馬 $i$ の「状態価格」を

$$p_i=E\left[\frac{\iota_{X_i=X^{(1)}}}{\sum_k\iota_{X_k=X^{(1)}}}\right]$$

と定義する。勝てば1、2頭同着なら 1/2、… を払う賭けの期待値で、同着を自然に扱う (p.1, 式1.1)。
共通の分布 $f^*$ と勝率 $\lbrace p_i\rbrace $ が与えられたとき、$X_i\sim f^{*\to a_i}$（$a_i$ だけ右に平行移動）で式1.1 を満たす $(a_1,\dots,a_n)$ を求めるのが**離散 horse race problem** (p.2)。非整数の移動は隣接する整数移動の線形混合で定義する (式1.3)。

### Harville との関係

Harville は走破時間が指数分布で、馬ごとに尺度（ハザード率）だけが違うモデルに当たり、平行移動族ではない (p.3)。2着の条件付き確率が勝率に比例するという性質は Luce の選択公理そのもので、Harville は実際には生成モデルを意識せず「公理」として使われている、と著者は指摘する (pp.3-4)。
人気薄が勝ったという事実は「何か予想外のことが起きた」ことを示すので、2着争いのエントロピーは選択公理が言うより高いかもしれない (p.4)。

先行研究の扱い (pp.4-5):

- 正規の平行移動族（Henery）は Taylor 展開による近似解のみ。
- 実務家は $p_i$ を $\beta$ 乗して再正規化する場当たり的な補正を使う（野球のピタゴラス勝率の指数と同類）。首尾一貫した枠組みではない、と著者は評価する。
- 汎用最適化で $n$ 個の $a_i$ を解く方法は、頭数が数十を超えると遅い。

## アルゴリズム

鍵は「残り全頭」を1頭の仮想馬として、その**1着スコアの分布 $f$、生存関数 $S$、同着の期待頭数（多重度）$m$** の3つ組で要約すること (p.6)。

1. 生存関数は独立性から積になる: $S_A(j)=\prod_{i\in A}S_i(j)$ (式2.2)。
2. 2つの集団を合併したときの多重度 $m$ は、どちらの集団から1着が出るか（あるいは同着か）の確率で重み付けた平均で更新できる (式2.4)。1頭ずつ足せば全体の $(f,S,m)$ が得られる（Algorithm 2.1）。
3. 馬 $i$ を除いた残りの生存関数は割り算 $S_{\hat i}=S/S_i$ で、多重度も式2.6 で全体から逆算できる。全頭を毎回計算し直す必要がない (pp.7-8)。
4. 馬 $i$ と「残り」の対決として、勝率の近似 $\tilde p_i\approx\sum_j f_i(j)\lbrace f_{\hat i}(j)/(1+m_{\hat i}(j))+S_{\hat i}(j)\rbrace $ を計算する (式2.7)。
5. 能力 $a$ → 勝率 $\tilde p$ の対応表を作り、目標の $p_i$ に対応する $a_i$ を**区分線形補間**で更新する。これを繰り返す（Algorithm 2.2）(pp.8-10)。

対数オッズを線形と仮定するなどの工夫を試したが、単純な線形補間で「ほぼ即座に」収束したという (p.10)。収束の証明はない（著者が欠点として認める）(p.12)。

## 精度と速度

- 10 頭なら5反復で相対誤差 1/10,000 程度（勝率 10% の馬で 1/100,000 以内）(p.11)。
- 相対誤差は頭数の対数で増えるが、60,000 頭でも 0.05% 程度 (p.11, Fig.4)。
- Python 実装で、格子 500 点・5反復のとき 1,000 頭が数秒、計算時間は頭数にほぼ線形（大きい $n$ ではやや劣線形）(pp.12-13, Fig.5)。比較対象の汎用最適化は次元が大きすぎて、公正なベンチマークの立て方が分からないとする (p.13)。

## 示唆（数値例）

### 馬単の確率は $f^*$ で大きく変わる

勝率 1/2, 1/3, 1/6 の3頭、正規分布のパフォーマンスで、Harville に対する馬単確率の増減 (p.14, Table 1):

| 1着 \ 2着 | 馬1 | 馬2 | 馬3 |
|---|---|---|---|
| 馬1 ($p=1/2$) | — | −8.1% | +16.3% |
| 馬2 ($p=1/3$) | −10.2% | — | +30.5% |
| 馬3 ($p=1/6$) | −5.7% | +8.5% | — |

最も人気のない馬が2番人気の後ろで2着に来る確率は、Harville の 1/27 に対して正規モデルでは 1/19 に近い (p.14)。
2020 年ケンタッキーダービーのオッズを使った多頭数の例では、100 倍超の馬を含む馬単確率が Harville と2倍違った (p.13)。

### 「複勝は単勝の1/4」ルールとの比較

ブックメーカーの each-way の慣行（3着内のオッズ = 単勝オッズの 1/4）を、ケンタッキーダービーの前売りオッズに skew-normal（$\alpha=2$）を較正した確率と比べると、1番人気の3着内確率はルールの 0.743 に対しモデル 0.651（−12.4%）、最も人気のない馬では 0.019 に対し 0.032（+64%）(p.15, Table 2)。
ただし大穴の勝率にはもともと本命大穴バイアスがあり、勝率を補正してから較正すれば差は縮むかもしれない、と著者は注意する (p.15)。

### その他の応用

- 出走取消時の配当調整を、選択公理による単純な再スケールでなく $f^*$ に基づいて行う (p.14)。
- 市場の勝率 $p_i$ から能力 $a_i$ を作り、予測モデルの特徴量にする (p.16, 3.6節)。
- 後半（4節）では、ディーラーへの見積もり依頼を誰に出すかという取引の問題に同じアルゴリズムを使う (pp.17-20)。

## 批判的に読む

- **実際のレース結果での検証がない。** どの $f^*$（正規、skew-normal、裾の重い分布）が馬単・3連単の実際の頻度に合うかは、本論文では一切評価していない。示されているのは「$f^*$ によって確率が大きく変わる」ことだけ。
- 全馬が同じ形の分布（分散も同じ）という仮定は強い。実際には人気薄ほどパフォーマンスのばらつきが大きいかもしれない（推測）。分散が馬で違うと平行移動族ではなくなる。
- 各馬のパフォーマンスは独立と仮定。展開（ペース）による相関は扱えない。後続研究（arXiv 2609.01133）が相関のある場合に拡張している（未読）。
- Table 2 の比較はブックメーカーの前売りオッズを「真の勝率」として較正しており、FLB の補正をしていない。
- 再現性は高い。参照実装が Python パッケージ `winning` として公開されている (p.10)。

## keiba-ai での使い方

- **着順確率の生成器**: 勝率モデルの出力 $p_i$ から、$f^*$ を選んで能力 $a_i$ を逆算し、モンテカルロまたは格子計算で馬単・3連単・ワイドの確率を作る。Harville・discount 補正と並ぶ候補にする。
- **仮説 H1**: JRA の3連単で、正規または skew-normal の $f^*$ は Harville より、2・3着の人気薄の確率を大きくし、的中組の負の対数尤度を改善する。$f^*$ の形（歪み、裾）は学習期間の2・3着の対数尤度で選ぶ。discount 補正（[Benter 2019](./2019-benter-model.md) の $\gamma,\delta$）との比較が主眼。
- **能力の特徴量**: 単勝オッズから逆算した $a_i$ は、勝率の対数より「距離」として線形に扱いやすい可能性がある（著者の 3.6 節の提案）。オッズ由来の特徴量として、$\log p$ と $a$ のどちらが GBDT の log loss を下げるか比べる。
- **出走取消**: 前日発表のオッズから取消馬を除いた勝率を作るとき、単純な再正規化（選択公理）と、$a_i$ を固定して取消馬を除いた再計算を比べる。
