# 機械学習による競馬予想で安定して勝てるのか？（nyanyanyanyanya 2022）

> 一言で: dijzpeb の本（netkeiba + LightGBM）を土台に、学習データを芝/ダート/障害/新馬・年齢条件・距離で10区分に分け、1着・2着内・3着内・穴馬の5モデルの最大スコアで4頭BOXを買った。2022年1〜5月の第8〜12レース（580レース）で三連複BOX 184.2%、ワイドBOX 104.6% だったが、6月（110レース）には三連複 44.2%、ワイド 70.6% に崩れた。著者は「時期とレースを選べば勝ち筋はあるが常勝には程遠い」と結論している。

## データ

- netkeiba からスクレイピングした JRA の過去レースと競走成績。期間は直近10年分（「学習元データの細分化」）。
- 出馬表の人気・オッズは動的表示なので ScrapingAnt 経由で取得。ただし予想には使わず、表示の補助情報だけ（「その他」）。
- 土台のコードは [dijzpeb 2020](./2020-dijzpeb-zenn-book-keiba-ml.md) の v2（購入者コミュニティには不参加）。

## 特徴量

- 削除したもの: タイム、着差、馬体重、馬体重増減（直前まで発表されない）、騎手、血統（集計方法が適切でないため）。
- 参考期間の短縮: 全期間の平均ではなく近走だけを使う（ダート転向前の芝の惨敗を5歳時の予想に使わない例）。
- 指数化:
  - コーナー通過順位を頭数で割って 0〜1 に正規化。
  - 上がり3F を芝・ダート・距離で補正。芝は 上がり3F / {0.94 + 距離/20000}、ダートは 上がり3F / {1.01 + 距離/20000}、障害はハロンタイムで別の式（著者は「最適解ではない」と断っている）。
- 「人気を裏切ったか」の指数: (人気 − 着順) / 頭数。
- フラグ: 牝馬限定戦、ハンデ戦。

## モデルと目的変数

- 学習データを10区分: 芝・ダートそれぞれを「2〜3歳限定戦 / 古馬混合戦」×「1700m 以上 / 未満」の8区分、加えて障害と新馬戦。SMILE 区分は試したが成績が悪化したので見送り。
- LightGBM の5モデル: 1着、2着内、3着内、穴馬2着内、穴馬3着内。穴馬モデルは「単勝10倍以上で2着内・3着内に来た馬」を正例にしたもの。
- 5モデルのスコアの最大値（異常に大きい値は外れ値として除外）を最重視。平均や中央値より最大値が良かった。
- 印（◎○▲△△）を付け、Excel と Power BI で買い目を分析。

## 評価

- 実運用（または運用相当の記録）の集計。各場の第8〜12レースで、スコア上位4頭のBOXを各券種で買った場合の的中率と回収率。
- 買い目の条件（第8〜12レース、4頭BOX）は運用データを見ながら「どのパターンが最もパフォーマンスが良いか」で選んだ（「運用した結果」）。BOX にしたのは、上位3頭で入着率に差がなかったため。
- 回収率は実際の払戻に基づく。控除率を踏まえて「回収率80%で平均以上、100%超で勝ち」と整理している。

## 結果

1〜5月下旬、第8〜12レース、580レース（「運用した結果」の表）:

| 券種 | 的中率 | 回収率 |
| --- | --- | --- |
| 単勝 | 54.3% | 74.1% |
| 複勝 | 46.4% | 89.3% |
| 馬連 | 24.0% | 75.0% |
| 三連複 | 9.8% | 184.2% |
| ワイド | 64.3% | 104.6% |

- 同期間の第12レースだけ（116レース）: 複勝 108.0%、三連複 267.1%、ワイド 198.8%。
- 6月、第8〜12レース（110レース）: 単勝 94.8%、複勝 74.3%、馬連 67.4%、三連複 44.2%、ワイド 70.6%。第12レース（22レース）ではワイド 125.7%。
- 上位3頭の単勝的中率は「40%強が関の山」（余話3）。
- 2022年12月の追記: ホープフルSの日のメインレースで、4頭BOXのワイドを総取り（うち2点が100倍超）。著者はこの1レースを集計に入れるかどうかで回収率が大きく動くと指摘している。

## 落とし穴と教訓

- **季節で傾向が変わる**: 6月から夏競馬に入り、3歳限定戦がなくなるなど条件が変わってモデルの成績が落ちた。著者は「季節を知らないアルゴリズムはそれを知らない」と書いている。
- **買い目を広げると回収率が下がる**。回収率だけなら3頭BOXの三連複（1点買い）が最強だった。
- **高配当1レースが回収率を支配する**。株価の「最も上がった5日を除くと成績が悪い」と同じ構造。
- **ドメイン知識の不足が特徴量の誤りにつながる**。全条件を1つのモデルで学習する、上がり3F を生の値で使う、などを元のコードの問題点として挙げている。
- 騎手・調教師・血統の過去勝率は、新人騎手や新種牡馬に対応できないので使わない、という判断（おまけ1）。これは「データ不足のカテゴリをどう扱うか」の問題で、使わないのが最善とは限らない。

## 批判的に読む

- **買い方の選択がインサンプル**: 「第8〜12レース × 4頭BOX」は1〜5月の同じデータを見て選んだ条件で、その期間の 184.2% は選択バイアスで上振れしている。翌月（6月）に崩れたのは、季節要因だけでなくこの選択バイアスでも説明できる。著者は季節要因として解釈している。
- 標本が小さい: 三連複の的中は 580レースで57本、第12レースでは15本。高配当数本で回収率が大きく動く。
- 学習期間とテスト期間の分割（時系列か、学習データに2022年が含まれていたか）は書かれていない。
- 10区分×5モデルで、区分によってはデータ量が少ない。区分ごとの成績は示されていない。
- 一方で、券種ごとの回収率を同じ買い目で並べ、6月の悪化もそのまま公開している点は、成功例だけを出す記事より信頼できる。

## keiba-ai での使い方

- **買い目ルールの選択は検証期間で**: レース番号、券種、BOX の頭数などの買い方も「ハイパーパラメータ」として扱い、テスト期間とは別の検証期間で選ぶ。テスト期間で選んだ買い方の回収率は報告しない。
- **月別・季節別の回収率**: 評価レポートに月別（または開催季節別）の回収率を出し、特定の季節だけで稼いでいないかを見る。
- **上がり3F の距離・馬場補正**: 著者の補正式は手作りだが、コース・距離ごとの標準化（コース×距離×馬場状態ごとの平均と標準偏差で z 値化）を特徴量に入れる案のきっかけになる。
- **穴馬モデル**: 「単勝10倍以上で3着内」を正例にしたモデルは、オッズ帯で条件付けた学習の一例。市場確率との残差を学ぶ方法（[namespace 2026](./2026-namespace-market-odds-residual.md)）と比べる価値がある。
- **高配当除外の回収率**: 払戻上位レースを除いた回収率を併記する（[marunage_kacho 2026](./2026-marunagekacho-roi177-mirages.md) の Top-N 除外と同じ）。
