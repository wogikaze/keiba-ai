# 13軸の重み付きスコアと LLM の作文で G1 だけを予想する個人用 AI Agent、6レースの運用記

> 一言で: 野球解説 AI Agent を作っている SRE が、JRA G1 専用の予想 AI Agent「ai-shugoro」を Claude Code で作り（Streamlit＋DuckDB＋Playwright＋Claude API）、2026年春の G1 6レースで運用した。13の評価軸を手で決めた重みで足し、上位5頭に印を付ける。6レース中3レースで三連複が的中し、AI に頼ったレースの回収率は105%（AI 以前の馬券を含めると85%）。機械学習モデルではなく、手設計のスコアと LLM の説明文の組み合わせ。

2本の記事を保存した。本文は振り返り編（2026年6月）、`attachments/dev` は開発編（2026年5月、オークス前に公開）。

## データ

- 収集元サイトは書かれていない。Playwright＋Chromium で収集し、DuckDB に入れる。宛先と収集回数を限定し個人利用の範囲にとどめた、とだけある（開発編「JRA G1専用の予想AI Agent」）。
- 収集と評価は「登録時点」「枠順確定後」「レース当日」の3段階に分け、段階ごとにスコアと予想が更新される。

## 特徴量（評価軸）

開発編「13の評価軸の重みが, そのまま予想哲学になっている」の節: 血統、コース適性、距離適性、近走成績、ローテーション、格（重賞実績）、調教、展開、枠、馬場、馬体、出走馬同士の相対評価、馬場速度適性。
重みは手で決め、最大が格（重賞実績）0.16、血統・コース・距離・近走が各0.13。出走前は基本6軸、枠順確定で展開と枠、当日に馬場と馬体が加わる。

騎手はスコアに含めない（「騎手は約60kgの重り」）。理由として、東京開催が多い春 G1 ではルメール・川田・武豊のスコアが不当に高くなること、阪神芝2200m のような稀な条件では騎手を絞っても意味がないことを挙げている（振り返り編「騎手をスコアに含めない割り切り」）。

## モデル

- スコアの統合と理由文の作成を「Marker」役の Claude に任せる。プロンプトで、他馬との比較は「フィールド相対」セクションの情報だけを根拠にし、不安要素は本馬のスコアの低い軸から1点だけ挙げる、と規則化し、v1〜v5 で改訂した（開発編）。
- 推薦は必ず5頭（◎◯▲☆△）。買い方は主に三連複。
- 学習・パラメータ推定はなく、重みは著者の予想哲学をエンコードしたもの。

## 結果（振り返り編）

| レース | 結果 |
|---|---|
| NHKマイルC | 不的中（勝ち馬を無印。サンプルの少ない新種牡馬の血統スコアが低かった） |
| ヴィクトリアマイル | 不的中（9番人気を本命、本命以外で決まる「タテ目」） |
| オークス | 三連複的中（初勝利） |
| 日本ダービー | 不的中（3着と4着が鼻差） |
| 安田記念 | 三連複的中（万馬券）。勝ち馬は AI が無印、著者が紐に追加 |
| 宝塚記念 | 三連複的中だがトリガミ。2着馬は AI が無印、著者が追加 |

AI Agent に頼ったレースの回収率 105%（TL;DR と脚注1）。外れはすべて本命が沈むパターンで、5頭に絞ったことによる「紐抜け」はなかった、と著者はまとめている。作った買い目シミュレーションと振り返り機能は一度も使わず、必要だったのは印に対する評価（eval）だったと反省している。

## 批判的に読む

- 6レースで、うち2つの的中は著者が AI の無印馬を手で足した結果。AI 単体の成績ではなく、回収率 105% は分散が支配的な数字として扱うべき。
- 重みは学習ではなく手で決めているので、較正された確率は出ない。期待値計算（オッズとの比較）もない。
- 新種牡馬の血統スコアが低く出る問題は、サンプル数の少ないカテゴリの集計値をそのまま使う典型的な欠点（縮約推定や事前分布で緩和できる）。
- 騎手を外す判断は春 G1 の6レースの結果で「良かった」とされているが、根拠は事例ベース。

## keiba-ai での使い方

- 特徴量を「登録時点」「枠順確定後」「当日（馬場・馬体重）」の3段階で入手可能になるものとして管理する発想は、予測時点ごとにモデルを分ける設計（ADR で予測時点を定義する）にそのまま使える。
- 産駒数の少ない種牡馬・騎手などの集計特徴は、件数で縮約（ベイズ平均、target encoding の平滑化）する。
- LLM を使う場合は、予測そのものではなく説明文の生成に限定し、比較の根拠を入力に含まれる数値に縛るプロンプト規則（「そこに無い比較を創作しない」）が参考になる。
- 評価は「印の当たり外れ」ではなく、印ごとの的中率・確率の較正をレース横断で見る仕組みにする（著者自身の反省点）。
