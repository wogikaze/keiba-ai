# 二段階モデルの第一段 LS-SVR を、MSE ではなく NDCG でチューニングすると儲かる（Goodwood 556レース）

> 一言で: Benter 型二段階モデル（第1段でファンダメンタル変数から着順スコア、第2段で条件付きロジットにより市場確率と結合）の第1段を RBF カーネルの LS-SVR にし、そのハイパーパラメータを「上位着順を重視する NDCG」で選ぶと、MSE で選ぶより保有外156レースの Kelly 回収率が 10.96% → 17.08% に上がった。

ページ番号は掲載誌の頁（PDF の1ページ目 = p.169）。

## 要旨

第1段を SVR にする発想は Edelman (2006/2007) による (p.170, p.177)。本論文の新しさは、SVR の超パラメータ選択の基準だけを変えたことにある。着順全体の二乗誤差（MSE）で選ぶと、賞金のない後方の着順（騎手が追わない等で信頼性が低い）まで当てようとして過学習する。そこで検索エンジン評価の NDCG を使い、上位の着順を重く評価する (p.170-171, p.175-176)。

## モデル

**第1段（LS-SVR）**: 目的変数は正規化着順。レースごとに頭数が違うため、$\hat y_i^j = -0.5 + (y_i^j - \min_j y)/(\max_j y - \min_j y)$ で $[-0.5, 0.5]$ に揃える (p.178, 式13)。入力は Bolton & Chapman (1986) と同じファンダメンタル変数のみで、オッズは入れない (p.178-179)。LS-SVR は二乗損失の SVR で、$\varepsilon$ が不要になり超パラメータは $C$ と RBF の $\sigma$ の2つだけ (p.173-174)。

**NDCG**: 実際の着順順に並べた馬に、モデルの正規化着順予測 $\widehat{NFP}$ を対応させ、重み $v_i = 1/\log_2(i+1)$ と内積を取って DCG とし、理想の DCG で割る (p.176-177, 式9-10)。閾値 $T$ を超える順位の重みを0にする拡張も示し、賞金が3着までであることから $T=3$ が妥当だと述べる (p.177, 式11)。実験で $T=3$ 版を使ったのか、全順位版を使ったのかは本文から読み取れなかった（未確認）。

**第2段（条件付きロジット）**: 最終オッズ $u$ から $Q = 1/(1+u)$、レース内で合計1に正規化した $q$ を作り、

$p_i^j = \exp(\alpha \hat y_i^j + \beta \ln q_i^j) / \sum_k \exp(\alpha \hat y_k^j + \beta \ln q_k^j)$

を最尤推定する (p.178-179, 式14-15)。

## データと実験設定

- 英国 Goodwood 競馬場、1995年5月〜2000年8月、556レース (p.179)。
- 時系列分割: 1999年5月以前の400レースを学習に使い、第1段用 S1（200レース・2,116頭）と第2段用 S2（200レース）に半分ずつ分ける。残り156レースが保有外評価 (p.179)。
- 第1段の超パラメータ: S1 内の10分割交差検証で、$\log C \in [-3, 5]$, $\log\sigma \in [-2.5, 2.5]$ の 10×10 格子から始め、有望域を2回まで細分。計 300×10 モデルを評価 (p.179-180)。
- 変数（Table 2, p.180）: 前走スピード指数、直近4走の平均スピード指数、同距離・同馬場状態での平均スピード指数、枠番、1走当たり賞金、距離延長フラグ、斤量、勝率、騎手の通算勝利数・勝率、騎手データ欠損フラグ。すべて標準化。
- 評価: 156レースで Kelly 基準（式17-18）の賭けをシミュレーション (p.181)。

## 結果

| モデル | 回収率（再投資なし） | 資金増加（再投資あり） |
|---|---|---|
| CL/CL（第1段も条件付きロジット） | 1.75% | −16.53% |
| LS-SVR(MSE)/CL | 10.96% | +112.20% |
| LS-SVR(NDCG)/CL | 17.08% | +172.48% |

出典: p.181-182, Figure 2。

- 選ばれた超パラメータは大きく違う。MSE: $C=0.11, \sigma^2=18.85$、NDCG: $C=0.004, \sigma^2=1198.99$。NDCG 選択の方が滑らかで単純なモデルになる (p.182-183)。
- 第1段の $R^2$ は NDCG 版 0.10、MSE 版 0.08 (p.183)。
- 保有外の MSE は MSE 版 0.406 < NDCG 版 0.414、保有外 NDCG は NDCG 版 0.673 > MSE 版 0.654。各モデルは自分の選択基準で最良になる (p.183, Table 3)。
- 著者の解釈: Bolton & Chapman の変数は広く知られているので線形の情報は市場に織り込み済みで、RBF カーネルが拾う非線形の相互作用だけが残っている (p.182)。

> NDCG による選択は、保有外で MSE 版より約56%多い利益をもたらしたと著者は述べる (p.182)。

## 批判的に読む

- **サンプルが小さい**: 保有外は156レースのみ。勝ち馬の配当数本で回収率が10ポイント単位で動く規模で、統計的検定はない。結論の「significant improvements」(p.184) は検定の意味ではない。
- **比較は1回の分割だけ**: ローリング評価や複数期間での再現がない。CL/CL が負けた理由が期間特有かどうか分からない。
- **回収率の計算**: 最終オッズ（控除後の実オッズと思われる）で Kelly 賭けをしているが、自分の賭けによるオッズへの影響やブックメーカー／トートの区別は本文から未確認。Kelly の再投資なし回収率と再投資ありの資金増加が並んでおり、前者は賭け金加重。
- **時系列分割は適切**: 第1段・第2段・評価が時間順に分かれており、リークは小さい。第1段の交差検証は S1 内のランダム分割だが、評価には触れない。
- **NDCG の正規化着順の向き**: 式13 では着順が大きいほど値が大きくなるように読めるが、本文は「勝ち馬が1」と説明する (p.176) 。符号の取り方は原本の式の組版から確定できなかった（未確認）。
- 第2段に入るのは1スコアだけなので、第1段の改善がそのまま回収率に出る設計。ただし $R^2$ 0.08 対 0.10 の差が回収率差の全部を説明するかは不明。

## keiba-ai での使い方

- **評価指標に合わせた早期終了・超パラメータ選択**: keiba-ai で LightGBM の第1段スコアを作るとき、検証の基準を「全頭の二乗誤差」ではなく「上位重視の NDCG@3」または最終目的の対数損失（第2段後）で選ぶ実験をする。仮説: 第1段を NDCG@3 で選ぶと、第2段（市場確率との結合）後の対数損失と回収率が MSE 選択より良い。
- **後方着順の信頼性**: 下位着順は「追っていない」ノイズを含むという指摘は、着順回帰の目的変数を「着差（秒）」「上位3着以内か」に切り替える根拠になる。着順そのものを回帰するなら、4着以下を打ち切る重みを試す。
- **二段階構成**: 第1段にオッズを入れず、第2段で $\ln q$ と結合する形は keiba-ai の基本構成の候補（[Benter 1994/2019](./2019-benter-model.md)）。第2段の係数 $\alpha, \beta$ は時系列で別期間に推定する。
- **小標本の結果を過信しない**: 本論文の 17% は156レースの値。keiba-ai では複数年のローリング評価と、ブートストラップの信頼区間を必ず付ける。
