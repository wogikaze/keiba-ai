# 競馬の勝率をレース内多項ロジットで推定する：ファンダメンタル・ハンディキャップモデルの原点

> 一言で: 各馬の「効用」を馬・騎手の10変数の線形和とし、レース内の多項ロジット（softmax）で勝率を推定した。1〜3着を順に選ばれる選択に分解する explosion で推定精度を上げ、200 レースの4分割ホールドアウトで単勝の賭け方を比べた。推定勝率が低い大穴を除外すると回収率がプラスになる場合があるが、サンプルが小さく、結果は分割ごとに大きくぶれる。

原本は Management Science 掲載版のスキャン（ProQuest ABI/INFORM 経由、gwern.net に置かれた写し、21ページ）。以下のページは雑誌のページ番号（PDF の p.N は雑誌の p.1039+N）。

## 問題設定

- パリミュチュエルの単勝で、大衆の確率 $\pi_h = w_h/W$ と真の確率 $p_h$ がずれているときに限り、正の期待収益 $p_h(r_h+1)>1$ が生じる（p.1041–1042）。$r_h$ は1ドルあたりの純配当、控除率 $\theta$ は約 18%、ブレイケージは無視する（p.1041）。
- 大衆の確率が真の確率に等しければ、どの馬に賭けても期待値は $1-\theta$ で、控除率分だけ負ける（p.1042）。
- 既存のハンディキャップは場当たりのフィルタ規則か、「勝つ/負ける」を全レース横断で回帰する二値モデルで、レース内の競争を扱えていない、と批判する（p.1042）。

## モデル

確率的効用モデル。馬 $h$ の価値を $U_h = V_h + \varepsilon_h$ とし、誤差が i.i.d. の二重指数分布（Gumbel）なら勝率は

$p_h = \exp(V_h) / \sum_{h'} \exp(V_{h'})$

となる（式 8, p.1043）。$V_h = \sum_n \theta_n z_{hn}$ は線形（式 9, p.1044）。プロビットも検討したが、多重積分が重いのでロジットにした（p.1043）。

- 当てはまりは McFadden の尤度比指数 $R^2 = 1 - L(\hat\theta)/L(0)$（式 11, p.1044）。基準は「全馬等確率」のモデル。
- 2つの部分標本が同じ $\theta$ を持つかは Watson & Westin (1975) の尤度比検定 $-2(L_{pooled} - [L_1 + L_2]) \sim \chi^2_N$ で調べる（式 12, p.1044）。

### Explosion（rank-ordered logit）

Chapman & Staelin (1982) の方法。着順 4,2,1,3 なら「4 が {2,1,3} に勝つ」「2 が {1,3} に勝つ」「1 が 3 に勝つ」の独立な選択集合に分解する（p.1045）。Luce & Suppes の Ranking Choice Theorem が根拠で、尤度は Plackett-Luce と同じ形になる。

- 下位の着順は、賞金も払戻もない馬が本気で走っていない可能性があり信頼性が下がる。そこで深さ $E$ までだけ分解する。選択集合の数は $J(E)=\sum_j \min(E, d_j, H_j-1)$（式 13, p.1045）。
- 深さの決め方を3つ挙げる: 事前知識（競馬なら3まで）、$R^2$ を $E$ に対してプロットして急落する手前で止める、Watson–Westin 検定を逐次行う（p.1045–1046）。
- 1レースのデータ作成に約1時間かかった。600 レース集める代わりに 200 レースを深さ3で分解して、ほぼ同等の精度を得たと述べる（p.1046）。

## データ

- Daily Racing Form から手作業で収集した 200 レース: Aqueduct 43、Pimlico 52、Garden State 42、Keystone 32、Suffolk Downs 31（p.1046）。年は書かれていない。
- 条件: 良または fast の馬場、距離 1〜1.25 マイル、カップリング（同一馬主の組）なし、3歳以上（p.1046）。馬場と距離はレース内で全馬共通なので、ロジットに直接入れられない。そのため条件で揃えた。

スピード指数はコースレコードを 100 とし、1/5 秒遅れるごとに1点引く（p.1047）。調教データは解釈が難しいとして入れていない（p.1047）。**市場オッズ（大衆の確率）は説明変数に入っていない。** オッズは賭けの判断（期待値の計算）にだけ使う。

- 等確率モデルとの比較で $\theta=0$ は 0.5% 水準で棄却（p.1049）。$R^2$ が小さいのは、レース編成（斤量、年齢・条件制限）がもともと各馬の勝率を揃えようとしているためと説明する（p.1049）。

- 最も効くのは平均スピード指数。斤量はほぼ効かない。騎手変数は馬の変数との共線性もあって弱い（p.1050）。

## 賭け方の評価（p.1050–1058）

評価は、200 レースから 150 レースで推定し、残り 50 レースで賭ける、を4通り繰り返す（p.1050）。4つの 50 レースのホールドアウトが重ならない4分割と読める。**時系列の分割ではない。** オッズは確定オッズを使い、自分の賭けがオッズを動かす効果は Isaacs 以外では無視する。

| 戦略 | 内容 | 主な結果 |
| --- | --- | --- |
| Isaacs (1953) | 最後の賭け手として、自分の賭けによるオッズ変化を考慮した期待値最大化 | 1レース平均 3.46 点、平均 $958。回収率は全体で −27.8%、4分割で −2.6%、−65.9%、−35.6%、−7.7%（p.1051） |
| Rosner (1975) | 期待対数収益（Kelly）最大化、オッズへの影響は無視、資金 $1000 から更新 | 資金は平均 $95.63 まで減少。レースをまたいだ回収率 −37.4%（p.1052） |
| Rosner 固定資金版 | 毎レース資金を $1000 に固定 | −6.4%。4分割で 18.7%、−58.6%、−32.1%、46.4%（p.1053） |
| 期待値の閾値 $\alpha$ | $\hat p(r+1) > \alpha$（1.0〜1.8） | 改善しない（p.1054） |
| 勝率の下限 $p_{min}$ | $\hat p > p_{min}$（0〜0.25） | Rosner 固定資金版は $p_{min}=0.07$ で約 +1.3%、0.11 で +8.2%、0.12 で −3.1%（Table 3, p.1054–1055） |
| 複数単位賭け | 期待値 >1 かつ $\hat p > p_{min}$ の全馬に1単位ずつ | 制約なしで −21.8%。$p_{min}>0.07$ の 18 値中 10 がプラス（p.1056） |
| 1点単位賭け | 期待値最大の1頭だけに1単位（期待値 >1 のとき） | 制約なしで +3.1%。26 値中 19 がプラス、最大 +38.7%（$p_{min}=0.11$）（Table 4, p.1057） |

著者の結論は、推定誤差があるなら賭けの大きさ（オッズを動かさない）と賭ける機会（推定の悪い大穴を除く）の両方を制約すべき、というもの（p.1058）。

> This study did not have a large enough data base to adequately assess the long-run rates of return across races for the various wagering strategies. (p.1058)

## 批判的に読む

- **$p_{min}$ はホールドアウトを見て選んでいる**: Table 3・4 は $p_{min}$ を 0.01 刻みで 26 通り並べ、その中から「0.07〜0.11 がよい」と結論している（p.1054）。評価データ上での閾値探索で、回収率の推定は上に偏る。しかも Table 4 は $p_{min}$ が 0.11 で +38.7%、0.12 で −10.0% と、隣り合う値で大きく跳ぶ（p.1057）。ノイズを拾っているとみるのが自然。
- **サンプルが小さい**: 単勝 50 レースを4回。Rosner 戦略の1レース平均回収率の標準誤差は分割ごとに約 27.5% と著者自身が書いている（p.1052）。+3.1% のような値は誤差の範囲内。
- **時系列分割ではない**: 150/50 の分割で、評価レースより後のレースが学習に入る。変数がレース前の情報だけでも、季節やコースの傾向がリークしうる。
- **オッズの扱い**: 確定オッズで回収率を計算し、ブレイケージを無視している（p.1041）。Rosner 系では自分の賭けの影響も無視している（p.1052）。
- **再現性**: データは非公開で、手作業で集めている。レースの年も書かれていない。

## 旧版からの訂正

- **市場確率は説明変数に入っていない。** 旧版は Sung & Johnson (2007) の記述から「ファンダメンタル変数と市場確率を同時に回帰する1段階型」としたが、原本の式 14 には市場オッズが無い（p.1046）。オッズは期待値 $\hat p(r+1)$ の計算でだけ使う。Benter (1994) の「2段階目で市場確率と結合する」という発想は、この論文には無い。
- 旧版は「Benter が市場確率との結合式の出典として p.1044 を挙げる」としていた。原本の p.1044 にあるのは McFadden の $R^2$ と Watson–Westin 検定で、結合式は無い。
- 「E=1 で $R^2$ 約 9%」「28.3%、16.8% の標準誤差減少」は原本で確認できた（p.1049）。
- 「1〜1.25 マイルに限定」は確認できた（p.1046）。理由は、レース内で一定の変数をロジットに入れられないから。
- 正の回収率が出たのは「大穴を除外する単勝戦略」だけでなく、制約なしの1点単位賭け（+3.1%）でも出ている（p.1057）。ただし上の批判のとおり、どれも統計的には弱い。

## keiba-ai での使い方

- **基本形**: 勝率モデルの出力はレース内 softmax（条件付きロジット）にする。馬場・距離のようにレース内で一定の変数は、そのままでは効かない。馬の適性との交互作用（例: 距離変更×前走距離）として入れる。NEWDIST はその初期の例。
- **Explosion の深さを実験で決める**: 仮説「1〜3着までの Plackett-Luce 尤度で学習すると、1着だけの softmax より単勝確率の対数損失が下がる。4着以下まで使うと悪化する」。深さ1〜5と全着順で比べ、Watson–Westin 型の尤度比検定と、時系列ホールドアウトの対数損失の両方を見る。JRA は着順の下位まで賞金が出る（5着まで）ので、最適な深さは米国より深い可能性がある（推測）。
- **$p_{min}$ を学習期間で決める**: 「推定勝率が閾値未満の馬に賭けない」は試す価値がある。ただし閾値は学習期間（または検証期間）で決め、評価期間では固定する。この論文の Table 3・4 のように評価期間で閾値を探さない。
- **1点買いと分散買いの比較**: 「期待値最大の1頭に定額」と「期待値 >1 の全馬に定額」「Kelly（分数 Kelly）」を同じ確率モデルで比べる。評価は控除率込みの回収率と、ブートストラップによる信頼区間で行う。
- **市場確率との結合**: 本論文はファンダメンタルのみ。Benter 型の2段階（ファンダメンタル確率と市場確率をもう1回ロジットで結合）を加えたときの改善幅を測る。
