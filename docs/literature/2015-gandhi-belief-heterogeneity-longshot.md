# 信念の異質性で FLB を構造推定する：7割の「ほぼ正しい」賭け手と3割のノイズ

> 一言で: リスク中立だが信念がばらつく賭け手の集団を、需要推定（BLP 型の混合ロジット）で米国の単勝データから推定すると、約7割はほぼ正しい信念、約3割は信念の分散が大きいノイズ型という2タイプで FLB がほぼ完全に説明でき、リスク愛好や累積プロスペクト理論より当てはまりが良い。

原本は AEA 2013 年大会で配布された 2012年9月17日版のワーキングペーパー（47ページ）。掲載版（REStud 2015）とは数値や節構成が異なる可能性がある。ページは WP の PDF ページ。

## 要旨

単勝市場を Arrow–Debreu 証券市場とみなし、信念の異質性が FLB を生む条件を理論的に示した上で、構造推定で選好ベースの説明と比べる (p.1)。主な主張は4つ (p.2–4):

1. 正しい信念が集団の信念分布の台に入っていれば、リスク中立でも本命は過小評価・穴は過大評価になる（定理1）。
2. 価格と事後の勝敗だけから、異質な賭け手のモデルを推定する方法を作った。Jullien–Salanié の最尤法に Berry–Levinsohn–Pakes の需要推定を組み合わせる。
3. 2タイプの信念異質性モデルは、異質なリスク選好モデル（HR）や累積プロスペクト理論（CPT）より当てはまる。
4. 情報量の違うレース（未勝利戦と非未勝利戦）で FLB の強さが違い、それを「ノイズ型の信念の分散」の違いとして自然に説明できる。

## なぜ少数のばらつきで足りるのか

FLB の大部分は勝率 1% 未満の大穴に集中している。平均的な馬券の期待収益は、勝率 1% 未満の大穴の2倍以上ある。推定モデルでは、平均的な馬券に比べてこうした大穴に賭けたがるのは約5%の賭け手だけだが、それで観測された過大評価が生じる (p.4)。代表的賭け手で説明しようとすると、価格 0.01 以下の馬券を平均の馬券より 50% 以上、0.005 以下を約 100% 過大評価する必要がある (p.12, Figure 2)。

> a little dispersion in beliefs suffices to induce enough demand on those longshots to generate substantial overpricing in equilibrium. (p.4)

## データ

- 北米の 176,652 レース、1,456,512 出走（2003–2006年）。paceadvantage.com の会員が収集したデータ (p.11, 脚注19)。単勝のみ。
- 平均控除率約 0.19。控除後の期待収益を見ると、価格（市場シェア）0.2 未満の馬は過大評価、0.2 超は過小評価 (p.11, Figure 1)。平均的な馬券の期待粗収益は 0.76 (p.12)。
- 馬ごとの情報（過去成績など）はデータに含まれない (p.27)。

## 推定方法

1. 賭け手 $t$ の効用を $U_t = \log ER_i + \nu_{it}$ と書く。$ER_i = (1-\tau) p_i / s_i$ は証券 $i$ の期待粗収益、$\nu_{it} = -\log r_{it}$ は正しい信念からのずれ (p.15, 式(8))。
2. 市場シェア $s_i$ は「$\delta_i + \nu_{it}$ が最大の証券を選ぶ」離散選択の集計になり、差別化財の需要と同型になる。$\delta_i$ は平均効用 (p.15, 式(9))。
3. $\nu$ を**分散の混合**ロジット $\int F(\nu \mid \sigma)\, dG(\sigma)$ とする。$G$ を有限混合にすると、各成分が賭け手の「タイプ」になる (p.16–17)。通常の BLP は平均の混合で、縮小写像が使えないので準ニュートン法でシェアの二乗誤差を最小化する (p.17)。
4. 各レースで観測シェアから $\delta$ を逆算し、そこから勝率 $p$ を復元し、勝ち馬の尤度を最大化する (p.16)。

### 未勝利戦と非未勝利戦（7.4節, p.27–32）

クレーミング競走（米国の全レースの54%超）に限り、同じ日・同じ競馬場で行われる未勝利戦と非未勝利戦を比べる。控除率は 0.190 と 0.192 でほぼ同じ (p.28 脚注44)。

- 未勝利戦の期待収益は大穴 $0.05 から大本命 $0.96 まで広がり、非未勝利戦は $0.45 から $0.89 に収まる。未勝利戦の方が FLB がずっと強い (p.28, Figure 5。原文は両方とも "maiden" と書いており誤植と思われる)。
- HR と CPT は2つの標本で選好パラメータが有意に変わる（未勝利戦ではリスク愛好、非未勝利戦ではほぼリスク中立）。選好は情報に反応しないはずなので、選好ベースの説明には不自然 (p.28–30)。
- BH の推定（Table 5, p.32）:

| | 非未勝利戦 | 未勝利戦 | 全体 |
|---|---|---|---|
| $\sigma_1$ | 0.0001 | 0.0366 | 0.028 |
| $\sigma_2$ | 0.340 | 0.6599 | 0.503 |
| $P_1$ | 0.700 | 0.727 | 0.716 |
| 観測数 | 87,394 | 29,003 | 176,466 |

タイプの割合は 70–73% で変わらず（仮説1を棄却できない）、信念の分散だけが未勝利戦で大きい（仮説2、1%水準で有意）。情報が少ないほど信念がばらつき FLB が強まる、という予測どおりの結果 (p.32)。

## 批判的に読む

- 「信念の異質性」と解釈しているが、推定しているのは選択の確率的なばらつきであり、状態依存の好みなど別の解釈もありうると著者自身が認めている (p.27 脚注42)。
- データは愛好家が集めたもので、欠測や選択の偏りは未確認。単勝のみで、連勝系との整合（Snowberg–Wolfers の識別戦略）は検討していない。
- 評価は全標本での尤度・仕様検定で、標本外予測ではない。モデル比較は KL 距離の意味での当てはまり。
- 回収率は控除後の実配当ベース（市場シェアと控除率から計算）。
- 未勝利戦と非未勝利戦では出走頭数や人気の分布も違うはずで、それらが勝率復元に与える影響は Figure 5 の比較だけでは切り分けにくい。

## keiba-ai での使い方

- **オッズ → 勝率の変換モデル**: 本論文の推定法は、単勝オッズ（市場シェア）から勝率を復元する「市場モデル」として使える。2タイプの分散混合ロジットは3パラメータで、Benter 型の「市場確率 + モデル確率」の結合で市場側の項をより良く校正する候補になる。比較対象は (a) 控除率で割っただけの確率、(b) べき乗補正（$p^\alpha$ 正規化）、(c) 本論文の BH モデル。指標は対数損失と Brier。
- **情報量で層別した FLB 補正**: 仮説: JRA でも新馬戦・未勝利戦は FLB が強く、オッズ由来確率の補正を強めるべき。実験では、クラス（新馬・未勝利・1勝クラス以上）×市場確率の分位で実際の勝率と回収率を集計し、補正係数をクラス別に推定する。地方競馬の転入初戦、海外遠征明けなど「公開情報が少ない」状況も同じ軸で扱える。
- **特徴量**: 「出走馬の過去走数の平均」「初出走馬の割合」など、レースの情報量を表す変数を市場確率との交互作用で入れる。
- 大穴（勝率1%未満）の扱い: FLB の大部分が極端な穴に集中するので、回収率評価はオッズ帯別に分け、大穴での過大評価がモデルの期待値計算を壊していないかを確認する。
