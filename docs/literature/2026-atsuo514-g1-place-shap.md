# 重賞だけで学習した G1 複勝モデルと、「回収率は券種で決まり資金配分では動かない」という検証

> 一言で: netkeiba から 2016〜2025 年の重賞（G1+G2+G3、18,272 行）を集め、LightGBM で複勝（3 着内）確率を予測し、G1 だけで年単位ローリング評価した。市場特徴ありで top1 複勝的中 63.0%、1 番人気を買うだけで 62.4% なので、市場を超える精度はほとんどない。重賞 1,233 レースの資金配分検証では「回収率は券種と買い目で決まり、配分ではほぼ動かない（複勝 84〜86%、ワイド 88%）」「定額張りと残高 5% 張りは破産する」と結論している。最もよく効いた特徴量の工夫は、各特徴をメンバー内の偏差値に直す「レース内相対化」だった。

原本は GitHub の README（`library/2026-atsuo514-g1-place-shap/source.txt`）。2026 年 6 月作成。SNS 発信・note 記事の自動生成を含む大きなツールだが、ノートでは予測と検証の部分だけを扱う。

## データ

- 入手元: netkeiba のスクレイピング（`src/scraper.py`、1 リクエスト 1 秒）。G1 一覧の発見 → 各レース結果 → 出走馬の生涯戦績 → 任意で G2/G3 と調教（追い切り）評価、の順に取る（「データ収集」の節）。
- 期間: 2016〜2025 年の重賞。学習は G1+G2+G3 の 18,272 行、評価は G1 のみ（「現状の性能」の表の注）。G1 は年 24 レースほどしかないため、評価サンプルは小さい。

## 特徴量

- 最終的に 103 → 38 特徴に絞った（重要度アブレーション。精度は同等〜微増）。
- 自前スピード指数、コース・回り適性、ペース展開、道悪・乗り替わり・前走レベル、調教評価、前走人気など。
- 決定的だったのは **レース内相対化**（各特徴を出走メンバー内の偏差値に変換）。調教評価は絶対ランク（A/B/C）では弱いが、メンバー内で相対化すると全特徴中 2 位の重要度になった、とある。
- 重要度シェア（「特徴量の視点」の節）: 市場（人気・オッズ）34%、騎手・厩舎 10%、近走・勢い 10%、グレード・地力 9%、馬体 7%、上がり 3F 7%、基本成績 7%、脚質 5%、距離適性 4%、馬場適性 2%。
- リーク対策: 対象レース日より前の戦績だけを使う。出馬表段階の予想では馬体重・オッズ・枠順を除外する（「予想の実行」の節）。

## モデルと目的変数

- 目的変数: 複勝圏（3 着内）の二値分類。
- LightGBM 分類器。チューニング版 3 シード＋保守版の平均アンサンブル。近年を重く見るサンプル重み。
- 市場特徴あり（直前用）となし（出馬表段階用）の 2 モデル。
- 買い目層（`src/value_bets.py`）: 複勝確率を合計 3 になるよう補正し、Plackett-Luce で着順をシミュレーションして単勝・連系の的中確率を出す。netkeiba のライブオッズと掛けて EV を計算する。

## 評価

- 分割: 年単位のローリング CV（2020〜2025）と、2024 年以降の単年テスト。
- 指標: top1 的中率（予測 1 位が 3 着内に来た割合）、top3 的中数、AUC、キャリブレーション。人気順ベースラインと比較する（`src/analyze.py`）。
- 回収率: 資金配分研究（`src/staking.py`）では、全重賞 1,233 レースについてリーク防止の OOF 予測と **実払戻** を使う。
- 前向き検証: `src/track_record.py` で、レース前に予想と推奨馬券を記録し、結果確定後に自動採点する台帳を持つ。過去データで選んだ「妙味アングル」を同じ期間で検証するのは「出来レース」なので、本物かどうかは未来のレースでしか測れない、という理由。

## 結果

「現状の性能（2020-2025 ローリング CV、スリム 38 特徴・重賞込み学習・G1 評価）」の表:

| | top1 的中率 | top3 的中数 | AUC |
| --- | --- | --- | --- |
| 市場特徴あり | 63.0% | 1.45/3 | 0.817 |
| 市場特徴なし | 53〜57% | 1.37/3 | 0.787 |
| 1 番人気を買うベースライン | 62.4% | – | – |

市場特徴なしモデルの AUC の積み上げ（同じ節）: G1 のみ学習 0.756 → 重賞追加 0.746 → スピード指数・適性・レース内相対化 0.775 → ペース 0.775 → 道悪・乗り替わり・前走レベル 0.779 → 調教 0.783 → 38 特徴にスリム化 0.787。

その他:

- キャリブレーション良好（予測 48.5% 帯 → 実際 48.5%）。予測 ≥50% の馬を複勝で買うと的中 63.7%（1.3 頭/レース）。
- アンサンブル化で出馬表段階の本命 top1 複勝が 55 → 58%（「能力・適性スコアカード」の節）。
- 「馬券の買い方（資金配分）研究」の結論:
  - 回収率は券種・買い目で決まり資金配分ではほぼ動かない（複勝 84〜86%、ワイド 88%）。どの配分でも長期 100% 未満。
  - 定額張りと残高 5% の厚張りは 1,233 レースの途中で破産。残高 1〜2% の比例張りは破産せず緩やかに減る。1% のほうが最大ドローダウンが浅い。
  - 唯一効くのは「信頼度の高いレースだけ買う（投下を半分に絞る）」こと。的中率が上がり（複勝上位 3 頭 90%、ワイド 49%）、回収率も微増するが、+EV にはならない。
  - 黒字の年が最も多いのはワイド（20〜29% の年）。

## 落とし穴と教訓（著者の記述）

- 「最大 EV」を鵜呑みにしない。高 EV は過小評価された人気薄に集中し、外れやすい（「期待値ベースの馬券提案」の節で「実証済み」とある）。本線は「高い好走率 × プラス期待値」に限る。
- 試したが不採用: LGBMRanker（分類器を下回った。相対化で代替でき、確率も得られる）、血統（種牡馬・母父の産駒成績。CV で効果なし〜微減。G1 級は皆良血で差が出にくく、馬自身の成績に吸収済み）。
- G1 だけで学習するより重賞を足したほうがよいと思ったが、足しただけでは AUC が下がった（0.756 → 0.746）。相対化を入れて初めて上がった。

## 批判的に読む

- 市場特徴ありモデルの top1 的中率 63.0% は 1 番人気の 62.4% とほぼ同じ。G1 は年 24 レース程度なので、6 年で 150 レース弱。0.6 ポイントの差は誤差の範囲で、モデルが市場を超えているとは言えない。著者も「24 レース/年で振れる」と注記している。
- 市場特徴は重要度の 34% を占める。市場ありモデルでは「オッズの取得時点」が重要だが、README からは学習に使ったのが確定オッズか直前オッズか分からない。確定オッズで学習して直前オッズで運用すると、評価が楽観的になる。
- 資金配分研究の回収率（複勝 84〜86%、ワイド 88%）は払戻率（複勝・ワイドとも 80% 前後）を少し上回るが、人気順で同じ買い方をした場合との差は示されていない。
- 「妙味アングル」は過去回収率 100% 超かつ前期・後期で検証済みのものを選んでいるが、多数の条件から選んだ時点で多重比較の問題がある。著者自身が前向き台帳で確かめる仕組みを作っているのは正しい。
- 重賞以外（平場・条件戦）には触れていない。G1 の結論が平場に移るとは限らない。

## keiba-ai での使い方

- **レース内相対化**（メンバー内の偏差値・順位化）は、特徴量の基本変換として最初の実験で入れる。特に調教や前走レベルのような「絶対値では弱いが相対で効く」特徴で比較する。
- 評価には必ず「1 番人気を買う」「人気順で同じ券種を買う」ベースラインを並べる。この README は表に 1 番人気を入れている点が良い手本。
- 資金配分の実験（定額 / 比例 1% / 2% / 5%、破産までのレース数、最大 DD）は、そのまま再現実験の設計にできる。回収率と資金曲線を別の評価軸として扱う。
- 前向き検証台帳（予想時点の記録 → 確定後に採点）は、バックテストとは別の評価として `experiments/` に持つ価値がある。
- 確率を合計 3 に補正して Plackett-Luce で連系確率を作る手法は、複勝モデルから連系確率を作る近道。ただし複勝確率を勝率に戻す変換の妥当性は確かめる必要がある。
