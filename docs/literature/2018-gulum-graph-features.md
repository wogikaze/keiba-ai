# 馬どうしの勝ち負けを有向グラフにして特徴量に足す（Louisville 大学の修士論文）

> 一言で: Equibase から集めた 2015〜2017年の米国の競走データで、馬を節点、先着関係を重み付きの有向辺としたグラフを作った。そこから「勝ち負け差」「重み差」「HITS」の特徴量を取り、8個の基本特徴量に足した。「同じレースの2頭のどちらが先着するか」の正解率は ANN で 78% から 92% に上がった、と報告する。ただし、グラフを作った期間がテスト期間を含むかは本文に書かれておらず、高い数字はリークの可能性を残す。

ページ番号は PDF のページ（本文の印刷ノンブルは PDF ページから 11 を引いた値）。

## 既存ノートからの訂正

原本を読む前のノートは、リポジトリの要旨とペンシルベニア大学の学部卒論（Won）の引用に頼っていた。原本で次のことが分かった。

- データ源は Equibase で正しい。同サイトの日別のレース成績 PDF を半自動スクリプトで落とし、10回ごとに出る CAPTCHA を回避しながら集めた (p.19–21)。
- グラフの辺は「先着した馬 → 負けた馬」で、重みは2頭間の勝ち数の差（win-loss spread）。推測していた「PageRank」は使っておらず、使ったのは HITS (p.34, 36)。
- Won の引用「オッズ基準 66%、ML 77%、グラフ込み 93%」は概ね合う。原本では、オッズ基準 66%、ANN 78%、ロジスティック回帰 76%、グラフ込み ANN 92%、グラフ込みロジスティック回帰 93% (p.50–52)。77% は先行研究 Davoodi らの値である。
- 「オッズ基準」は確定オッズではなく、**モーニングライン（事前の予想オッズ）**である (p.44)。

## データと基本特徴量

- 期間: 2015〜2017年の米国の全開催（Equibase の日別成績）。学習は 2015〜2016年、テストは 2017年 (p.44, 59)。
- 前処理: 距離と馬場種別が1つの列に入っているので分ける。距離はヤード・マイル・ファーロングをマイルに揃え、文字表記を数値に変換 (p.27–28)。
- 基本特徴量は8個 (p.28): 馬場種別（ダート・芝・inner）、天候、騎手（勝利数 ÷ 騎乗数）、前走着順、馬体重（斤量の意味かもしれない。本文は horse weight、例は 126lb で米国の斤量の値に近い。未確認）、出走頭数、馬場状態、距離。
- 比較の基準（baseline）はモーニングラインのオッズ (p.44)。

## グラフと特徴量

### 2種類のグラフ

1. **Labeled Edge Graph** (p.34): 馬 $i$ が馬 $j$ に先着するたびに $i \to j$ の辺を引き、逆向きの回数を引いた差を重みにする。$i$ が $j$ に3勝、$j$ が $i$ に2勝なら、$i \to j$ の重みは $3-2=1$。出次数が勝ち、入次数が負けを表す (p.33)。
2. **Multiple Labeled Edge Graph** (p.34–35): 辺に天候・馬場状態・馬場種別・距離などの条件ラベルを付ける。予測したい2頭の対戦条件（例: 1マイル・ダート）と同じ条件の辺だけを残した部分グラフから特徴量を取る。

### 特徴量 (p.36–37)

- **次数差（試合数で割る）**: Guo らの順位付けをもとに、$d_\Delta = (d_{in} - d_{out}) / n$。$n$ はその馬の出走数。出走数が違う馬を比べるために割る、と説明している。
- **辺の重み差**: Bhooshan らにならい、$d_w(i) = \sum_{(i,j)\in E} w(i,j) - \sum_{(j,i)\in E} w(j,i)$。
- **HITS**: 隣接行列 $A$ で authority $= A^\top h$、hub $= A a$ を反復する。勝ち辺の向きから、hub が「多くの馬に勝った馬」、authority が「多くの馬に負けた馬」に対応する。

本文の定義では、$d_\Delta$ の符号の向き（入次数＝負け）と「順位が高い馬ほど入る辺が多い」という Guo らの説明が逆向きになっており、どちらの向きで使ったかは原本からは読み取れない（未確認）。

## 評価の設計と結果

2017年の同じレースから2頭を無作為に選び、どちらが先着するかを当てる。これを 512 回繰り返した (p.49)。2頭とも 2015〜2016年にも出走している必要があり、組を見つけるのが難しかったと書いている (p.44, 60)。

| 手法 | 正解数 / 512 | 正解率 | 出典 |
| --- | --- | --- | --- |
| モーニングライン | 338 | 66% | p.50, Fig. 6.6 |
| ANN（基本特徴量） | 401 | 78% | p.50 |
| ロジスティック回帰（基本特徴量） | 390 | 76% | p.50–51, Fig. 6.7 |
| ANN（＋グラフ特徴量） | 472 | 92% | p.51, Fig. 6.8 |
| ロジスティック回帰（＋グラフ特徴量） | 476 | 93% | p.52, Fig. 6.9 |

条件付きグラフ（天候と距離の2条件。条件の合う組が 202 しか見つからなかった）では次のとおり (p.52–54)。

| 手法 | 正解数 / 202 | 正解率 |
| --- | --- | --- |
| モーニングライン | 148 | 73% |
| ANN / LR（基本特徴量） | 170 / 167 | 84% / 83% |
| ANN / LR（＋グラフ特徴量） | 188 / 186 | 93% / 93% |
| ANN / LR（＋条件付きグラフ特徴量） | 196 / 195 | 97% / 96% |

著者も、レース全体ではなく2頭ずつの比較なので高く出る、と認めている (p.54)。

> These values are really good and high but, we compared each time two pairs of horses not whole races that is why it can be high. (p.54)

### ケンタッキーダービー (p.55–58)

全出走馬を2頭ずつ比べて勝ち数で順位を作った。2017年は ANN・LR とも McCraken（実際は8着）を1位にし、実際の上位を当てられなかった (p.57)。2016年は 2015年のデータだけで学習し、上位4頭の順位を当てた (p.58)。どちらも1レースの事例である。

## 批判的に読む

- **グラフの期間が書かれていない。** Labeled Edge Graph は「データ中の全レース」の勝ち負け差で作るとある (p.34)。グラフを 2015〜2016年だけで作ったとは書かれていない。もし 2017年のレースも辺に入っていれば、テストする2頭の勝敗そのものが重みに入る。基本特徴量で 78% の ANN が、グラフ特徴量を足しただけで 92% になり、条件をテストの対戦条件に合わせると 97% まで上がる、という伸び方はこのリークで説明しやすい。条件付きグラフの 202 組の説明にも「2015-2016 and 2017 data」とあり (p.52)、2017年のデータが混ざっている疑いを強める。著者がリークを論じた箇所は無い。
- **基準がモーニングライン。** 確定オッズより情報が少ない。確定オッズの人気順で2頭比較をすれば 66% より高くなるはずで、「機械学習がブックメーカーの確率より良い」という結論 (p.60) はこの点で割り引く必要がある。
- **2頭比較の正解率しか見ていない。** 勝率の推定、校正、回収率の評価は無い。
- **前走着順を基本特徴量に使う。** 2頭とも過去に出走歴がある組に限っており、新馬や出走数の少ない馬はテストから外れている (p.60)。
- **再現性。** コードとデータは公開されていない。図の多くが画像で、ハイパーパラメータ（ANN の層数など）の記述も乏しい。

## keiba-ai での使い方

- **対戦グラフの特徴量は試す価値がある。** JRA では、クラスや条件の違いで直接対戦していない馬を比べる場面が多い。辺の重み差や HITS のような伝播型のスコアは、初対戦の組の比較に効く、という仮説を立てられる。ただし本論文はその効果を、リークを除いた形では示していない。
- **時点を切ってグラフを作る。** レース日 $t$ の特徴量は $t$ より前の結果だけで作ったグラフから計算する。日付順に辺を足しながら各時点のスコアを保存する。本論文の設計（期間不明の大域グラフ）はまねしない。
- **比較実験の案**: (a) 基本特徴量のみ、(b) ＋時点を切った重み差・HITS、(c) ＋Bradley–Terry や Elo の強さ、の3つを、レース内の勝率の log loss と、市場確率（確定オッズ）と混ぜたときの改善で比べる。グラフ特徴量が Bradley–Terry の強さ以上の情報を持つかを見る。
- **条件付きグラフ**は、馬場状態別・距離帯別の能力の推定に相当する。辺が少なくなるので、条件で分けた強さを全体の強さに縮約する階層モデルの方が扱いやすいと考えられる（推測）。
