# 「過小評価される要素を探す」から「いま回収率の高い予想家に乗る」へ — 有効フロンティアで予想家の買い目を束ねた大会3位AI

> 一言で: 10年以上競馬予想のアルゴリズムを作ってきた著者（インティメート・マージャー社長）が、AI競馬予想マスターズ2023 で使った「生成系競馬予想」の考え方を書いた記事（2023年12月、大会最終日の2日前）。勝ち馬を当てるモデルは回収率が75〜80%に収束するので、過小評価される要素を探す方向に進んだが、その要素もすぐ陳腐化する。そこで、いま回収率が高い予想家（netkeiba の俺プロ上位など）を定期的に見つけ、その買い方を参考に買い目を生成し、複数人の予想を株式ポートフォリオの有効フロンティアで組み合わせてボラティリティを下げる方式をとった。最終戦3位（回収率121.82%）。

大会のルールと成績は [2023年大会](./2023-netkeiba-ai-masters-2023.md) にまとめた。表彰式で著者は、大会を通じてほぼ単勝と複勝しか当てられず、他の券種の買い方に課題が残ったと話している（大会まとめの `news-party-sp.txt`）。翌年の続編は [yanashi 2024](./2024-yanashi-alternative-data.md)。

## 主張の流れ

「競馬の予想アルゴリズムの紆余曲折」の節:

- 1着を予測するアルゴリズムは1番人気ばかりを選び、控除率のため回収率は75〜80%に収束する。大会の各アルゴリズムを見ても、多くがこの範囲に収まっているという。
- 『馬券裁判』（卍氏の手法）をきっかけに、「一般に過小評価されやすい要素」をスコア化して該当する馬を買う方向が広まった。ただし同じアプローチの人が増え、要素が見つかる速度が上がり、すぐに普通の要素になって回収率が75〜80%に戻る（陳腐化）。

「この大会で使っているアルゴリズム」の節:

- 過小評価要素そのものではなく、「過小評価要素で買っている予想家」を当てる方針に切り替えた。
- 俺プロ（netkeiba の予想大会）の最上位者が月単位で回収率100%を超える割合を集計すると、最上位に入った回数が増えるほど100%超えの率はやや下がる（図のみ、数値なし）。継続的に100%を超えるのは難しいので、その時点で回収率の高い予想家を定期的に入れ替える。
- 複数人の予想から、株式ポートフォリオの有効フロンティアを解いてリスク（ボラティリティ）の低い買い目を作る。

大会プロフィールでは、最終戦では逆に有効フロンティア上のボラティリティの高いポートフォリオを組むと書いている（順位を上げるため）。

「生成AIを使った次世代予想の方法」の節: ChatGPT の Vision API にパドックや前走との比較画像を入れる、MMPose で馬のモーションキャプチャをして歩様を評価する、といった今後の構想を挙げている（実装や結果はない）。

## 批判的に読む

- 予想家の選び方（期間、閾値）、有効フロンティアの入力（各予想家の買い目の収益の平均と共分散をどう推定したか）、バックテストの結果はどれも書かれていない。
- 「最近回収率が高い予想家」の追随は、回収率の持続性に依存する。著者自身の集計は持続性が弱いことを示しており、短期の好成績の多くは運である可能性が高い。
- 大会での3位は最終戦の約1か月の結果で、手法の有効性の証拠としては弱い。

## keiba-ai での使い方

- 「他人の予想」を特徴量（あるいは集合知）として扱う発想は、予想家の印や集団予想の研究（[Mori 2010](./2010-mori-keiba-yoso-shuudanchi.md)）と比べる材料になる。
- 複数の戦略をポートフォリオとして組み合わせ、収益の分散を下げる方法は、複数モデル・複数券種の資金配分を考えるときの参考になる。ただし収益の共分散の推定には長い期間が要る。
