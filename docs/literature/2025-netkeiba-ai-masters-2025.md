# 機械学習 全国学生大会2025 — 学生が100万ptの所持ポイントを2週間で増やし合った、JRA-VAN データ提供の学生版

> 一言で: netkeiba と JRA-VAN（JRAシステムサービス）が共催し、電気通信大学データ教育センターが協力した学生限定の大会（2025年9月6日〜21日）。参加者は提供された過去データで機械学習モデルを作り、100万pt（1pt＝1円）の仮想資金を API で投票して、終了時の所持ポイントを競った。払戻は次のレースから再投資できる（複利）。優勝は所持ポイント 1,723,620pt（ランキング名 SAT）。完走27人のうち100万ptを上回ったのは10人だった。

原本は公式トップページ（`source.txt`）。ルール（`rule.txt`）、ランキング（`ranking.txt`）、閉幕のプレスリリース（`press-release.txt`、2025年10月21日）、電気通信大学データ教育センターの大会ページ（`uec-event.txt`）を添付した。出場者一覧ページ（`member_list.txt`）は中身がなく、学生大会にはプロフィールページがない。

プレスリリースによると、エントリーは110名超。優勝者の倉知さん、準優勝の宮下さん、3位の田中さん（ランキング上の名前との対応は記載がない）のコメントが載っている。3位の田中さんは、もともとボートレースのAIを作っていて、複利の最大化を目指して賭け金に差をつけたと話している。参加した Kaggle Grandmaster の堀江さんは、人によって評価指標が違い戦略性が問われる点を、他のコンペにない面白さとして挙げている。

## 上位の傾向

- 投票レース数は上位ほどノルマ（96レース）ぎりぎりで、優勝から3位までは99〜100レース。必要以上に賭けない方が控除率による目減りが少ない。
- 的中率と順位の関係は弱い。1位 SAT（55.00%）と7位 枠連のフリーレン（56.57%）は的中率が高いが、2位と3位は21%と14%。
- 100万ptを上回ったのは完走27人のうち10人。下位には所持ポイントがほぼゼロ（100〜2,560pt）になった参加者が5人いる。複利で全額を回し続けると、負けが続いたときに資金が尽きる。

## 批判的に読む

- 期間は約2週間、1人100レース前後。上位の差は運で十分に説明できる規模である。
- 解法の公開は授賞式での発表に限られ、資料は公開されていない。この大会の上位の手法を文章で確かめる手段は、見つけた範囲ではない。
- 電気通信大学の大会ページ（`uec-event.txt`）は、目的を「複利最大化」とし、問題設定（何を予測し、どう使うか）を参加者に任せることを教育上の狙いとしている。評価は所持ポイントだけで、予測の良さ（較正や対数損失）は測っていない。

## keiba-ai での使い方

- 「所持ポイントの最大化」という目的は、ケリー基準（[Kelly 1956](./1956-kelly-information-rate.md)）や分数ケリー（[MacLean 2010](./2010-maclean-kelly-good-bad-properties.md)）の議論にそのまま当てはまる。ただし2週間・100レースでは長期成長率の最大化より、ノルマの下で順位を取る戦略が有利になる。
- 入賞者の発表義務の3項目（学習・検証データの概要、目的変数、予測から投票への変換）は、keiba-ai の実験 README の最低限の記載項目としても使える。
