# 発走前オッズの時系列観測と41年オッズの考古学（rindokulab 2026）

> 一言で: JRA の単勝オッズを前夜から確定まで7時点で自動採取し、最終変動の約4割が発走5分前より後に到着すること、変動の向きは60→30分前で 73% 当たるが大きさは最後まで見えないことを示した。関連記事では、取得側のメタデータ（予想オッズ混入）で相関の符号が反転した失敗と、41年分のオッズから払戻率の制度変更（1991年・2005年）を検出した分析を書いている。

主記事「発走5分前、オッズの旅はまだ6割しか終わっていない」に、同じ著者の3記事（「『相関の符号が反転した』のは市場ではなく装置だった」「オッズデータだけで『制度変更が起きた日』を特定する」「市場が一度も疑わなかった馬」）を添付している。著者の本は [rindokulab 2026 本](./2026-rindokulab-recovery-100-discarded.md) を参照。

## データ

- 自作の観測装置で単勝オッズを毎週末採取。時点は前夜21時、当日朝8時半、発走60分前、30分前、15分前、5分前、確定。
- 主記事の分析対象は 2026年7月26日〜9月6日の13開催日のうち、6時点すべてが有効な 454レース・5,598頭（「検証条件」）。
- 有効性の判定は、配信元の公式更新時刻から10分以内の観測だけを採用。前時点のオッズが100倍超の馬と表示上限（999.9倍）の馬は変動分析から外す。
- 長期分析は netkeiba から自作クローラで取得した JRA 全レース（1986年1月〜2026年7月、138,969レース）の確定オッズと払戻。

## 手法

- 変動は対数比で計算し、表では変化率に換算。信頼区間は開催日で層化したブートストラップ1万回。
- 「実現割合」: 60分前から確定までに15%以上動いた馬（4,295頭）について、最終変動のうち各時点までに実現した割合。
- 方向一致率: 途中までの動きの向きが最終的な向きと一致した割合。
- 事後にしか分からない「60分前→確定で15%以上買われた馬」（1,199頭）を正解とし、各時点で「その時点までに10%以上買われた」で拾った場合の適合率・再現率。
- 41年分析では、全馬単勝100円購入の年別回収率と、Σ(1/確定単勝オッズ) から逆算した年別の含意払戻率を見る。

## 結果

主記事（発走前の13日間）:

- 区間ごとの変動の中央値は、60→30分前 6.4%、30→15分前 8.9%、15→5分前 14.9%、5分前→確定 16.7%。区間が短くなるのに変動は大きくなる。この単調な加速は当初「13日すべて」と書かれたが、2026-10-03 の追記で「13日中12日」に訂正された（7月26日は SD カードの読み出しエラーでデータが化けていた）。
- 実現割合の中央値は、30分前 0.102 [0.096, 0.106]、15分前 0.267 [0.258, 0.277]、5分前 0.600 [0.590, 0.611]。最終変動の約4割（13日平均 40.0%、日別 36.2〜44.2%）は発走5分前より後に来る。
- 方向一致率は、60→30分前 73.1%（日別 66.4〜80.6%）、60→15分前 82.5%、60→5分前 92.2%。
- 「大きく買われる馬」の早期検出は、30分前で適合率 47.9%・再現率 21.9%、15分前 60.8%・48.7%、5分前 70.9%・69.4%。
- 公式更新時刻と採取時刻の差の中央値は、朝 2.9分、60分前 1.4分、30分前以降 0.5〜0.6分。前夜は当初 17.1分としたが、予想オッズを除くと 3.2分（追記で訂正）。

「相関の符号が反転した」の記事:

- 一晩のフロー（前夜→朝）と直前のフロー（60分前→確定）の日別相関が、16日中6日で負（−0.32〜−0.42）。負の6日はすべて日曜だった。
- 原因は、日曜レースの前夜にはまだ発売前で、配信元が `status: "yoso"`（予想オッズ）を返していたこと。実オッズの前夜だけに絞ると 10日中10日で正（+0.06〜+0.32、中央値 +0.21、プール +0.21、n=4,369）。
- 予想オッズは値の範囲も Σ(1/オッズ) ≈ 1.25 も実オッズと見分けがつかなかった。

「制度変更が起きた日」の記事:

- 全馬単勝購入の回収率は 1986〜1991年 65.7%、1992〜2003年 73.3%。勝ち馬の確定オッズと払戻の一致率（99.72% / 99.74%）と1番人気の勝率（35.2% / 34.5%）はほぼ変わらない。
- 含意払戻率は 1986〜1990年 75.3〜75.4%、1991年 76.2%（年央で切替）、1992〜2004年 79.2%、2005年 80.2%。1991年の券種別払戻率への再編と 2005年の単勝・複勝払戻率引き上げに一致する（官報などの一次資料との厳密な照合はしていないと著者が断っている）。
- 払戻率の伸びは +5% だが、勝ち馬の平均オッズは 7.36倍 → 9.41倍（+28%）。残りは馬連導入による資金移動ではないかという仮説を、未検証のまま登録している。

ディープインパクトの記事（読み物）:

- 2004〜2026年の新馬戦デビュー 83,586頭のうち、単勝1.1倍でデビューしたのは15頭（12勝3敗）。10走以上の38,136頭で、キャリアを通じて単勝1.5倍を超えなかったのはディープインパクト1頭だけ。確定単勝1.0倍は23年で7例（6例が未勝利戦、7例とも勝利）。

## 落とし穴と教訓

- **データ源の状態列を最初に集計する**。status・flag・source・mode の類を曜日×時刻でクロス集計していれば、予想オッズの混入には初週で気づけた。
- **曜日や時刻で結果が割れたら、市場より先に取得側を疑う**。日曜だけ負、という規則性は取得手順の性質だった。
- **正しく動いている装置が別のものを測っていることがある**。装置は7月に2度壊れて修理されたが、3度目は壊れていなかった。
- **長期データの物差しは一定ではない**。払戻率の制度変更で回収率と含意確率の水準が段差状に変わる。
- 訂正を追記で公開している点は、記録として信頼できる。

## 批判的に読む

- 観測は13〜20開催日、夏開催が中心（7〜9月）。季節、G1 開催、売上規模による違いは見ていない。
- 「60分前から15%以上動いた馬」に絞った実現割合なので、小さく動く馬を含めた全体像ではない。
- 変動の中央値は、人気帯による違い（大きいオッズほど相対変動が大きい）を混ぜた値になっている。人気帯別の数値は記事にない。
- 方向一致率 73% は「最終的な向き」との一致で、それが回収率に変わるかは別問題。パリミュチュエルでは払戻が締切オッズで決まるので、早く向きが分かっても有利な価格では買えない。この壁は [marunage_kacho 2026](./2026-marunagekacho-roi177-mirages.md) が実測している。主記事は回収率には触れていない。
- 41年分析の含意払戻率は単勝だけの値。券種別の控除率の違いは扱っていない。

## keiba-ai での使い方

- **オッズを特徴量に使う時点の設計**: 発走5分前のオッズでも最終変動の4割は未着。オッズ特徴量は「何分前の値か」を明示して保存し、学習時と推論時で同じ時点に揃える。確定オッズで学習して5分前オッズで推論すると分布がずれる。
- **評価の決済価格**: 回収率は確定オッズで計算するしかないが、意思決定に使ったオッズ（何分前）と確定オッズの差を別の指標として記録する。
- **取得データの検品**: オッズを自前で採取するなら、配信 JSON の状態フィールド（発売前の予想値か実売か）を保存し、曜日×時刻で集計するテストを入れる。
- **長期データの分割**: 1991年・2005年の払戻率変更をまたぐ期間を学習に使うときは、年代ダミーか含意払戻率での正規化を検討する。ADR で分割期間を決めるときの根拠になる。
- 「向きは早い、幅は遅い」は、締切直前の資金流入（late money）を特徴量にする研究（[Hanyu 2025](./2025-hanyu-last-minute-dynamics-parimutuel.md)）と突き合わせる価値がある。
