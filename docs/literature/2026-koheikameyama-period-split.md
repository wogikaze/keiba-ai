> 一言で: JRA 11,948 レースで条件付きロジットを学習し、単勝・複勝・馬連・ワイドの選別買いを検証した。重みの大半はオッズに乗り、21特徴量を足しても学習損失は 0.2% しか改善しなかった。函館3番人気の単勝 105.2% は独立期間で 56.9% に落ちた。期間3分割、コントロール群、特徴量の別実装検算という「自分を騙さない手順」が具体的に書かれている。

## データ

- JRA の1986〜2021年のデータを使い、2018年以降で検証（「検証したこと」の節）。
- レース結果 167,177 出走 / 11,948 レース、全券種の確定払戻（単勝・複勝・馬連・ワイド）、コーナー通過順（脚質）、ラップタイム（ペース）。
- 入手元は明記されていない（期間と内容は Kaggle の JRA データセットと一致する）。

## 特徴量

- 最終的に 27 特徴量（騎手の競馬場別勝率、馬の距離帯適性、脚質、末脚、調教師成績、馬の平均着順比 `h_ratio`、3着内率 `h_top3`、過去1年出走数 `h_runs`、前走間隔 `h_layoff` など）。
- 全特徴量はウォークフォワードで計算する。各レースのスコアはそのレースより前の成績だけで計算し、採点後にそのレースの結果を統計へ反映する。

## モデルと目的変数

- 1着馬を当てる条件付きロジット（レース内で確率の合計が1）。最初は人手の100点満点の配点、次にデータから重みを学習。
- 単勝オッズ（`log_odds`）も入力に含めた版と、オッズ1つだけの版（コントロール群）を併走。
- 選別買いは「予測確率×オッズ」が閾値を超えた買い目のみ。

## 評価

期間を4つに分けている（「期間を3つに分ける」の節の表）。

| 期間 | 用途 |
| --- | --- |
| 2018 | 統計の助走 |
| 2019-01〜2020-06 | 学習 |
| 2020-07〜2020-12 | 券種と閾値の選定（何度見てもよい） |
| 2021-01〜2021-07 | 最終テスト（一度だけ） |

回収率は確定払戻で計算。買う時点のオッズは使っていない。

## 結果

- 段階別（「検証したこと」の表）: 人手の配点 的中 18.6%・回収 73.1%、条件付きロジット 33.1%・82.4%、脚質等を追加 32.8%・81.5%、1番人気だけ 32.5%・79.7%。
- 学習損失: オッズのみ 1.9781、21特徴量＋オッズ 1.9738（改善 0.2%）。重みは `log_odds` −1.532、`h_ratio` −0.165、`h_top3` −0.092、ほかは 0.06 未満（「オッズが既に全部知っている」）。
- 選別買い（「期待値が高い買い目ほど、回収率が低い」の表）: 閾値 1.0→2.0 で複勝 76.5%→59.1%、馬連 50.6%→2.7%、ワイド 47.2%→33.8%。閾値を上げるほど回収率が下がる。
- 組み合わせ馬券は単勝より悪い。確率の誤差が掛け算になり、控除率も高い（馬連・ワイド 22.5%）。
- 人気別の単勝回収率（2018-20 / 2021）: 1番人気 77.2% / 79.7%、2番人気 81.4% / 84.1%、14番人気 67.4% / 45.0%、17番人気 24.3% / 0.0%。独立2期間で再現したのは「人気薄の落ち込み」だけ。
- 函館・3番人気・単勝: 発見期間（2018-2020）432 点で 105.2%、2021 年で 56.9%。
- 選定期間で100%を超える戦略が1つもなかったので、最終テスト期間は使わずに終えた。

## 落とし穴と教訓

- **多重比較**: 競馬場10×距離帯4×馬場4×クラス×頭数×オッズ帯…に1〜3番人気の単勝・複勝を当てはめれば、105% は必ずどこかに出る。
- **欠損レースによる勾配のバグ**: レース内で定数の `field_size` は理論上勾配0のはずが、重み −3.78 が付いた。1着がいない（中止等）レースでは正解ラベル合計が0になり、`sum(p−y)=1` の勾配が湧いていた。除外すると −0.000 になった。
- **コントロール群で故障箇所を切り分け**: 多特徴量モデルの的中率が 12.4% に落ちたとき、同じ実行のオッズのみモデルは 32.8% を出していたので、評価コードではなく学習が壊れていると判断できた。損失は 2.61→3.09 と発散しており、学習率 0.5 が大きすぎた。Adam に変えて 24.3% まで戻った。
- **特徴量の別実装検算**: `h_runs` と `h_layoff` を生 CSV から別コードで再計算して 2,004 行を照合し、不一致0件、当日レース混入0件を確認。
- 効いていない特徴量は足すと悪くなる。合計スコア（18.6%）が騎手スコア単独（19.1%）を下回った。

## 批判的に読む

- 最終テスト期間（2021年前半）は7か月しかなく、函館の 56.9% は 2021 年の1年分（点数不明）との比較。56.9% 自体も小標本の揺れを含む。
- 評価は確定払戻ベースで、買う時点のオッズでの再現は検証していない。負の結果なので結論は変わらない。
- 「株では勝てた」という比較は別記事の内容で、本稿の検証範囲外。
- 1986〜2021 年のデータを使うと書いているが、学習は 2019〜2020 年中心。長期データを統計の助走以外に使ったかは不明。

## keiba-ai での使い方

- 実験テンプレートに「選定期間」と「一度だけ使う最終テスト期間」を分けて書く欄を設け、選定で100%を超えなければテスト期間を消費しない運用を ADR にする。
- すべての実験で「オッズのみモデル」と「1番人気買い」をコントロール群として同時に回し、的中率 32% 前後が出なければパイプライン故障とみなす自動チェックにする。
- 条件付きロジット／softmax 系の学習では、勝ち馬のいないレース（中止・同着の扱い）を前処理で除外する。
- 特徴量のリーク検査として、ランダム抽出行を別実装で再計算して照合するテストを用意する。
- 選別買いの閾値を上げたときの回収率の単調性を確認する。下がるならモデルが市場より強気な部分は誤りである。
