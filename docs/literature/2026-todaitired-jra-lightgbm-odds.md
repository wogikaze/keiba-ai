# Benter の枠組みを JRA で順に再現する個人ブログ: オッズの疑似R² 0.21、ファンダメンタルズだけの LightGBM で 0.14

> 一言で: TARGET frontier JV（JRA-VAN）で取った JRA 全レースを使い、(1) 単勝オッズの較正（ロングショット・バイアス）、(2) Harville モデルへの Benter 補正の JRA での推定、(3) 時系列オッズの情報量の推移、(4) オッズを使わない LightGBM lambdarank＋softmax のファンダメンタルズモデル、を Benter 流の疑似R²で一貫して評価したシリーズ。確定オッズの疑似R²が約0.21、ファンダメンタルズモデルは検証期間で0.1403。回収率の検証はまだない。

## データ

- 初期（2024〜2025年）は netkeiba を BeautifulSoup でスクレイピングしようとしたが、netkeiba・競馬ラボは 403 で、fat-tail 編は Yahoo!スポーツナビから取得し、アクセス制限で東京・中山の 992 レースで止まった（fat-tail「検証方法」）。
- 2026年からは JRA-VAN DataLab を TARGET frontier JV 経由で CSV 出力。2024年全レースの単勝・複勝の時系列オッズの取り方を手順として書いている（target-odds）。
- LightGBM 記事は 2018〜2025 年の JRA 全レース（本文「2. データ」）。

| バッファ | 2018〜2019 | 前走特徴量の計算だけに使う |

## 特徴量（LightGBM 記事「3. 特徴量」）

- 今走: 馬体重・増減、生後日数、キャリア（Z 正規化版も）、斤量体重比、馬齢斤量差、距離、充足率（頭数÷フルゲート）、芝ダ・天気・性別・所属の one-hot。
- 生涯累計賞金（当該レースを除く）。
- 騎手・調教師スコア: 過去50戦の平均ラベル（1着4、2着2、3着1）と、TARGET のクラスコード（未勝利7〜G1 195）を掛けた加重スコア。
- 前1〜5走の各12特徴: 着差、人気超過率（(人気−着順)/頭数）、クラス差、相対順位、タイム偏差（走破タイム−基準タイム）、上り3F、距離差、間隔、PCI−50、PCI3−50、RPCI−50、PCI−RPCI 差。加えて過去5走の平均距離との差。
- 血統と同コース・同距離成績はまだ入れていない。前6〜10走まで広げても改善しなかったので、直近5走が実質的な上限だったと書いている（「5. 考察」）。

天気と馬体重は当日情報で、天気は発走前に分かるが、馬体重は発走約1時間前の発表。予測時点の定義は書かれていない。

## モデルと目的変数

- LightGBM の lambdarank。ラベルは 1着4、2着2、3着1、他0（「1. フレームワーク」）。
- 出力スコアをレース内 softmax で勝率に変換する。多項ロジットと同じ形で、Benter の枠組みに合わせている。
- 評価指標は Benter 流の疑似R²: 1 − L(モデル)/L(1/N 均等)。勝ち馬の対数尤度で測る。

## 評価と結果

疑似R² がシリーズ共通の物差しになっている。回収率は LightGBM 記事では計算していない。

- 確定オッズ（正規化した単勝オッズの逆数）の疑似R²は約0.21（LightGBM 記事の冒頭で以前の記事の値として引用）。
- ファンダメンタルズ LightGBM: 2024年の検証データで疑似R² 0.1403（「4. 結果」）。importance の上位は前1走タイム偏差（18,960）、前1走相対順位（18,673）、騎手スコア（12,395）、前1走人気超過率（9,372）、前1走クラス差（4,577）。
- Benter 補正（benter-harville）: 2024年の JRA 約3,400レースで、10月末までを学習、11月以降をテストにして最尤推定。γ≈0.86、δ≈0.70。Benter (1994) の香港の値 0.81／0.65 と近く、Harville より補正モデルの疑似R²（三連単の尤度）が高かった。Harville と Benter の疑似R²の値そのものは画像の表にあり、テキストでは取れていない。
- ロングショット・バイアス（lsb）: 2024年 JRA 全レースの正規化勝率を5%刻みにすると実勝率は45度線にほぼ沿い、明確な LSB は断言できない。正規化勝率5%未満の帯は回収率が低い。
- 時系列オッズ（odds-timeseries）: 2024年 JRA 全レースで、確定、締切直前、その1つ・2つ前、確定の36分前・66分前・6時間6分前・12時間6分前の8時点のオッズを、γ=0.86、δ=0.70 の Benter モデルに入れて三連単尤度の疑似R²を比較。締切に近づくほど一貫して上昇し、締切1つ前（平均約5分前）と2つ前（約10分前）の間でも約1.0×10⁻²上がった。同オッズのタイで人気順が決まらないレースは除外している。
- fat-tail 編（2024年の東京・中山 992 レース）: 勝ち馬のオッズ分布から「オッズX以上の馬の勝率×X」を下限期待値として描き、単勝5〜10倍帯が過小評価されているように見えると結論。ただし著者自身が、これは勝ち馬のオッズ分布であって「あるオッズの馬の勝率」ではないと断っている。

## 落とし穴と教訓

- 着順順に並んだデータをそのまま使うとソート順がリークするので、馬番順に並べ替えた。
- 累計賞金・騎手スコアは当該レースを含めずに計算。
- 前の時点のオッズで期待値を計算して賭けるのは不利。対策として「直前で計算して即ベットする低遅延系」か「途中オッズから最終オッズを予測するモデル」が必要と提言（odds-timeseries「6. 考察」）。
- netkeiba のスクレイピングは 403 で止まり、最終的に JRA-VAN＋TARGET に移った。

## 批判的に読む

- 疑似R²の比較が公平でない。確定オッズの 0.21 は2024年（どの範囲か不明）の値、LightGBM の 0.1403 は2024年の検証データで、しかも早期終了やハイパーパラメータ選択に使った可能性がある（テスト2025は未使用）。同じレース集合で並べないと差 0.07 は解釈しにくい。
- LightGBM 記事の指標は勝ち馬の尤度（1着の softmax）だが、学習は 1〜3着に重みを付けた lambdarank。softmax の温度を較正していないので、疑似R²は温度の選び方で変わる。検証期間で温度を合わせたかどうかは書かれていない。
- 馬体重・天気を入れているので、予測時点は発走約1時間前以降になる。単勝オッズの比較時点と揃えるなら、どの時刻のオッズと組み合わせるかが重要になる。
- Benter 補正の推定は1年分を学習とテストに分けただけで、パラメータの標準誤差がない。
- ロングショット・バイアスの検証は1年分で、帯ごとのサンプル数と信頼区間がない。fat-tail 編は条件付けを誤っている（著者も認めている）。
- まだ賭けの結果がない。ファンダメンタルズと市場の結合（Benter の第二段）と回収率は「次のステップ」とされている。

## keiba-ai での使い方

- 評価の主指標の候補として、Benter 流の疑似R²（勝ち馬の対数尤度、1/N 基準）を回収率と並べて出す。確定オッズ・締切X分前オッズの疑似R²を同じテスト期間で計算し、「市場ベースライン」として常に併記する。JRA の目安は確定オッズで約0.21。
- 三連単など組合せ馬券の確率は Harville ではなく Benter 補正（JRA で γ≈0.86、δ≈0.70）を初期値にし、学習期間で再推定する。
- 着順でソートされた生データはレース内で馬番順などに並べ替えてから使う（lambdarank の group 内順序や `shift` を使う特徴量でのリーク対策）。
- 期待値計算に使うオッズの時点を実験設定（config.yaml）に明記する。締切直前でもオッズは情報を増やし続けるので、確定オッズで評価した回収率は実際に買える回収率より楽観的になる。
- 前走特徴量の作り方（人気超過率、相対順位、タイム偏差、PCI 系）と「5走で頭打ち」は特徴量設計の出発点として使える。
