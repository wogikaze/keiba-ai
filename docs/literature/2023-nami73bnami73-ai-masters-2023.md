# 1着・2着内・3着内の確率から Harville で全組合せを出し、直前オッズで期待値を計算して「買える買い目は全部買う」AI（湯けむり競馬部）

> 一言で: 業務と趣味で公営競技のAIを作っている著者が、AI競馬予想マスターズ2023 に「湯けむり競馬部」で参加したときのシステムと戦略の解説（2023年12月4日）。各馬の1着・2着以内・3着以内の確率を予測し、Harville の公式を応用して組合せ馬券の確率を出し、直前に取得したオッズと掛けて期待値を計算する。1か月約288レースで成績が安定するよう、期待値の条件を満たす買い目は全部買う方針で、予選1・2の1レース平均の買い目点数は28.7点（参加者中1位）。予測環境は Google Cloud 上に Cloud Functions と Cloud Scheduler で組み、発走20分前にデータ作成、15分前に予測、5分前に買い目作成と投票を自動で回した。

大会のルールと成績は [2023年大会](./2023-netkeiba-ai-masters-2023.md) にまとめた。湯けむり競馬部の公式成績は予選1 16位（回収率87.09%）、予選2 19位（76.56%）、最終戦7位（111.33%）。この記事は最終戦の最中に書かれている。翌2024年大会ではステージ1で35位（76.03%）で敗退した（[2024年大会](./2024-netkeiba-ai-masters-2024.md)）。

## データ

「システム構成」の節: netkeiba からスクレイピングで取得し（サーバーに負荷をかけない頻度で、と明記）、Cloud SQL に保存する。オッズは直前に web から取る。学習環境については「特筆することはない」として省略している。

## 特徴量・モデル

精度向上の話は他の記事に任せるとして、ほぼ書いていない。予測するのは各馬の1着・2着以内・3着以内の確率。

## 買い目の組み立て（「買い目戦略」の節）

- 組合せ馬券の確率は Harville の公式を「多少応用して」計算する。元の式は 3連単 A→B→C の確率を P(A)·P(B)/(1−P(A))·P(C)/(1−P(A)−P(B)) とするもの。応用の中身（2着内・3着内確率をどう使うか）は書かれていない。
- 予測確率とオッズの積で期待値を出す。確率とオッズに誤差がなく、無限に試行できるなら、期待値1超の買い目を買い続ければ収支100%を超えるはずだと説明する。
- ただし1か月の対象レースは約288（12レース×3場×8日）しかないので、288レースである程度当たる確率の買い目を買うのが現実的だとする。
- 買える買い目はすべて買う方針で、1レース平均28.7点。3連単が当たったときに払戻が大きくなるよう設定しているが、詳細は書けないとしている（買い目は大会サイトで公開されているので分析してほしい、とある）。

## 大会ルールの考察（「大会ルールの考察」の節）

- ラウンドは1か月単位なので、1か月で成績が安定する戦略が必要。1日単位で安定する必要はない。
- 予選で高額的中を出すと最終戦の資金が増えるが、100万円級を狙うと1か月での安定が崩れる。
- 1レース15万円・200点の上限で、一発狙いはある程度封じられている。
- 予選1で残金が7千円ほどになり、「参加するなら最低1万円」のルールと重なって使い切れず、使い残しのペナルティを受けた。

## 運用（「システム構成」の節）

Cloud Scheduler が1分ごとに起動し、発走20分前にデータ作成、15分前に予測確率の推定（Cloud Storage に置いたモデル）、5分前に買い目を作って大会 API に登録する。

## 「競馬AIには2種類ある」

自分で賭けて儲けるAIは、締め切り直前のオッズと馬体重を使え、自分の資金で戦略を立てられる。予想を販売するAIは前日・前々日に予測を作る必要があり、多くの利用者が少数のレースしか買わないので、的中寄りの買い目にしないと「1日的中なし」になる。大会は前者の条件で戦える。

## 批判的に読む

- 学習・検証の方法、予測精度、バックテストの回収率は書かれていない。Harville の応用の詳細と、期待値の閾値も非公開。
- Harville の公式には、残った馬のうち最も強い馬の2着確率を過大評価し、最も弱い馬の2着確率を過小評価する偏りが知られている（[Lo 1994](./1994-lo-comparison-harville-henery.md)、[Henery 1981](./1981-henery-permutation-probabilities.md)）。「多少応用」がこの偏りを補正しているかは分からない。
- 全部買う戦略は多数の低確率の組合せを含むので、確率の小さな誤差が期待値の判定を大きく変える。

## keiba-ai での使い方

- 発走20分前→15分前→5分前のパイプラインは、直前オッズを使う運用の時刻設計の具体例。keiba-ai で「購入時点のオッズ」でバックテストするときの時刻の基準にできる。
- 1着・2着内・3着内の3つの確率を Harville 系の組合せ確率に入れる方法は、[Harville 1973](./1973-harville-multi-entry-probabilities.md) と [Benter 2019](./2019-benter-model.md) の補正と比べて検証する対象になる。
