# netkeiba 2008〜2019 年を Selenium で集め、Keras の NN で単勝的中率 24.5%、回収率は大赤字

> 一言で: 情報系の学生が netkeiba からレース結果を Selenium + requests で収集し、Keras の全結合 NN で「1着か」「3着以内か」を予測した記録。時系列で 8:2 に分け、テスト（2017/7/23〜2019/11）で単勝正解率 0.2450、複勝正解率 0.5434。予測1位を買い続ける単勝・複勝の収支は「大赤字」。Zenn への移行時の追記で、東京ダートに絞り血統（祖先の産駒成績）を加えた LightGBM 3クラス分類も試し、正解率約 55%、回収率は 100% に届かず、しかも産駒成績が未来情報を含むリークだったと自ら指摘している。

原本は Zenn 版（2020-09-23 公開）。Qiita の元記事（2019-11-18 公開）は移動の告知だけが残る（attachments/qiita-original）。コードは GitHub の unonao/race-predict（attachments/github-race-predict に README）。

## データ

- netkeiba のレース詳細検索（`db.netkeiba.com/?pid=race_search_detail`）は検索後も URL が変わらないので、Selenium でフォームを埋めてレース結果 URL を集め、その後 requests で HTML を保存する（「さっそくデータ収集から」の節）。
- 中央10場のみ（海外・地方を除く）、2008 年〜2019 年11月。
- レース表: レース ID、R、名前、コース、天候、馬場、日時、場、1〜3着の馬番・枠番、各馬券のオッズ。馬表: 着順、馬 ID、馬番、枠番、性齢、斤量、馬体重と増減、タイム、着差、上がり、オッズ、人気。血統・馬主・調教師は見送り。

## 特徴量

- 当該レース: 馬番、枠番、年齢、斤量、馬体重、増減、斤量/馬体重、性別、距離、頭数、障害か、馬場、芝ダート、回り、天気、開催地、前走から騎手・馬主が変わったか、前走からの間隔。
- 過去5走: 同じ項目に加え、着順、タイム、途中順位の平均、上がり、平均速度。欠損は 0 埋め。
- 当日のオッズは締切まで変動するので入れない。

## モデルと評価

- Keras の全結合 NN（Dense 300, L2 0.001, Dropout 0.2 …）。「1着になる確率」と「3着以内に入る確率」の2モデル。二つの出力を平均（blend）すると正解率がわずかに上がった。
- **分割**: データの前 80% を学習（2008/1〜2017/7/23）、後 20% をテスト（2017/7/23〜2019/11 頃）。学習側の中は sklearn の `TimeSeriesSplit(n_splits=3)` で時系列交差検証。hyperas でハイパーパラメータを探索。
- 正解率 = 予測1位の馬が1着（単勝）／3着以内（複勝）だった割合。

## 結果

- 「結果」の節: 単勝正解率 0.2450、複勝正解率 0.5434。予測1位を買い続けた単勝・複勝の収支は図で、いずれも「大赤字」。
- 「追記」の節（7頭以下と障害レースを学習から除いた後）、頭数別の正解率（単勝 / 複勝）: 8頭 0.350 / 0.704、9頭 0.269 / 0.657、10頭 0.306 / 0.641、11頭 0.258 / 0.547、12頭 0.260 / 0.583、13頭 0.289 / 0.586、14頭 0.230 / 0.538、15頭 0.253 / 0.533。いずれもランダム（1/頭数、3/頭数）を上回る。
- 「さらに追記」の節（Zenn 移行時）: 東京・ダートに絞り、過去3走 + 4代の父系祖先（父、父母父、母父、母母父）の産駒成績（ダート勝率など）と種牡馬ランキングを結合。目的変数は着順上位（1〜3着）・中位（4〜7着）・下位（8着〜）の3クラス。LightGBM、学習 33,715 行・121 特徴量で、検証の multi_error 約 0.42（正解率約 55%）。重要度上位は前走結果、頭数、年齢、前走からの間隔、父の産駒成績（ダート）。回収率は 100% を超えなかった。

## 落とし穴と教訓（著者）

- **産駒成績のリーク**: 種牡馬ページの産駒成績はスクレイピング時点の累計なので、対象レースより後の成績を含む。「このデータは不適切」と本文で認めている。
- 同着レースのスクレイピングに失敗していた。欠損を 0 埋めした。
- 東京ダートに絞ると、多くのレースに出ている馬が少なく、過去走を3走に減らした。

## 批判的に読む

- 単勝正解率 24.5% は、1番人気の勝率（JRA で概ね 30% 強、[gara_gara 2020](./2020-gara-gara-lightgbm-leak.md) の京都 2013〜2019 で 31.7%）を下回る。オッズを入れないモデルとしては妥当だが、市場より弱い。
- 回収率は図のみで数値がない。どのオッズで計算したかも書かれていない。
- Zenn 版のコメント欄で「前走の結果を特徴量に入れるとテスト内でリークする」という指摘があるが、前走はレース前に確定している情報で、リークではない。この誤解は実践者の間でよく見かける。
- LightGBM 版は検証の正解率だけで、テスト期間の扱いが明確でない。

## keiba-ai での使い方

- **血統集計は時点を切る**: 種牡馬・母父の産駒成績は、対象レースの前日までの累計を自前の結果テーブルから計算する。netkeiba の種牡馬ページの累計値をそのまま使わない。本記事は時点を切らない集計が混入する典型例。
- **頭数別の正解率**: 正解率は頭数に強く依存するので、モデル比較はランダム基準（1/頭数）や1番人気の勝率との差で行う。
- **学習内部の検証も時系列で**: `TimeSeriesSplit` を早くから使っている点は良い手本。
