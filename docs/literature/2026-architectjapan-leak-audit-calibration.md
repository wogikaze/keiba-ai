# リーク監査で単勝の構造回収率は77〜81%に落ち、Benter 型の市場合成と882戦略からの選抜で再び100%超えへ

> 一言で: TARGET frontier JV のローカル DB（1954〜2025年、1,730万レコード）から LightGBM の勝率モデルを作った1か月の記録の第2話。最初の「ROI 800%」はリーク（単勝オッズ列の欠損パターン、着順の数値版）で、除去後の3年ウォークフォワードでは単勝の構造回収率が77〜81%だった。そこから Benter 型の市場オッズとの合成（α=0.2825, β=0.8597）と、7券種×EV閾値×点数×α/β の882戦略からの選抜で、確定オッズのバックテスト上 100% を超える戦略を拾った。著者自身が、選抜後の再評価・確定オッズ・年数の少なさを限界として明記している。

Claude Code を使って作った（タグと前編から）。文体は LLM 的で長く、後半は先行研究の紹介（Harville、Bolton & Chapman、Benter、Kelly など）に割かれている。前編「ROI 140%より先に税金が気になった話」（attach: `part1-roi140-tax`）では、オッズを使わない約40次元のモデルで単勝 hold-out ROI 約140% と書いていた。第2話はそれを自分で崩した記録として読める。

## データ

- TFJV（TARGET frontier JV）のローカル DB 5.58GB から 1954〜2025年の約1,730万レコードを Parquet 化。SE/RA/UM/HR/HN/SK など17種類のレコード（「Phase0」の節）。JRA-VAN DataLab 会員の個人利用範囲。
- 仕様書のない独自バイナリで、オフセットが1列ずれて数日はまった（前編の「toroku が全部77」事件）。
- 血統: UM の3代血統から公開データで補完して9代まで拡張（211,409頭×2,048列）。

## 特徴量

- 第1段: 25特徴量（オッズ特徴量なし）。
- 集計型血統: 父・母父・父の父・母の父の母などの年別集計を Bayesian smoothing（事前 α=5, β=15、事前平均25%）で平滑化。距離・コース適性、系統、簡易 Nicks 指標（父×母父の相性、3.39M 行）、Wright の近交係数（9代、F>0 は 5,993頭＝約2.8%で、著者自身が低すぎると検査中）。
- ラベルエンコーディング込みで254特徴量の版もある（Phase4）。
- TabNet のエンティティ埋め込み（種牡馬7,000以上のクラス）は集計版より弱く不採用。

## モデルと目的変数

- LightGBM の二値分類（1着か否か）＋レース内 softmax 正規化。LambdaRank は未実装（6月の TODO）。
- Isotonic 回帰で較正してから市場と合成。
- 市場との合成（Benter 型）: P_final ∝ P_model^α × P_public^β。P_public は単勝オッズの逆数をレース内で正規化したもの。全期間（n=20,626レース）の最尤推定で α=0.2825, β=0.8597（ΔLL=+0.1569）。部分学習（n=483）では α=0.3143, β=0.7945 だった（「2.3」「Phase7」の節）。
- 三連単は Plackett-Luce（勝率をそのまま強さとして逐次選択）で 18頭なら4,896通りの確率を出す。

## 評価

- 評価系が段階で違い、著者は表に「評価条件」の列を付けている（「第0章」の節）: (1) オッズ特徴量なしモデルの代理評価、(2) HR（払戻）レコードの単勝配当ベースの3年ウォークフォワード、(3) 確定オッズでの6年ウォークフォワード戦略バックテスト、(4) 1988〜2025年の38年バックテスト。
- 戦略は「EV 閾値 × 上位 N 頭（N=1, 5, 10…）× α/β（MLE 値か α=β=1）× 券種」の格子で、計882戦略。
- 不確実性は6年の年別回収率を10,000回リサンプリングした「参考レンジ」。著者は信頼区間ではないと注記している。
- 掛け金は1点100円の均等。Kelly は戦略確定後の課題。

## 結果

「第0章」の表と「第4章」から:

- Phase1（25特徴量、代理評価）132.5% → Phase2（集計型血統を追加）141.5%。
- **Phase3（リーク監査後、HR 払戻ベース、3年ウォークフォワード）: 構造回収率77〜81%**。単勝の控除率20%とほぼ一致。
- Phase5（Plackett-Luce 三連単、上位1点）: hold-out で 134.4% だったが、確定オッズ6年では平均136%・年別 2022年69%・2023年78%・2025年272%（ばらつき203ポイント）で、過学習とみなして不採用。三連単（α=β=1、上位10点、EV≥1.5）は平均105%で保留候補。
- 882戦略のうち100%を超えたのは単勝43・三連単17・複勝0・馬連0・ワイド0・馬単0・三連複0（「第0章」の注記）。
- 旧主力（単勝 EV≥1.5、上位1頭）: 旧 α/β で平均200.3%（年186点、2021年は50%）。新 MLE 値で再評価すると EV≥1.5 を通る馬が約1/8 になり、年25点・平均307%・ばらつき969ポイント、参考レンジ [77%, 620%] で採用不可（「Phase8」「Phase9」の節）。
- 新主力候補（単勝 MLE、EV≥1.2、上位5頭）: 6年平均187.6%、参考レンジ [130%, 249%]、年353点。
- 38年バックテスト: 軽量キャッシュ（130列）では全戦略が約78%（控除率どおり）。馬データ・血統78列を足した中量キャッシュ（208列）では新主力候補が平均178.1%、38年中30年（79%）で100%超（「Phase10」の節）。

## 落とし穴と教訓

- **単勝オッズ列のリーク**: SE レコードの単勝オッズ列は5着までしか値が入っておらず、1着馬だけ系統的に高い値を持っていた（「Phase1」の節）。値の有無と大きさが着順を漏らす。JRA-VAN 系データで成績レコード側のオッズを特徴量に使うときの具体的な罠。
- **着順の数値版**（chaku_num）が特徴量に混入し、ROI 988% を出して発覚。リーク列を `feature_pool.LEAK` として明示的に管理する。
- 「hold-out ROI が200%を超えたら、まずリークを疑う」。
- 前編では、血統情報が950頭（全21万頭の約0.45%）にしかない列を入れたら ROI 140%→108% に落ちた。カバレッジが極端に低い列は入れない（前編「4.2」の節）。
- 市場合成の α を少し動かすだけで EV 閾値を通る馬の数が8分の1になり、戦略の統計力が崩れる。EV 閾値戦略は較正パラメータに強く依存する。
- 年別に見ると、平均136%の戦略が69%・78%・272%に分かれる。平均だけで判断しない。

## 批判的に読む

- **確定オッズ**: 戦略バックテストも市場合成の P_public も確定オッズ。著者は odds drift を限界として明記している。
- **選抜バイアス**: 882戦略から最良を選んだあと、同じ6年で年別リサンプリングしている。参考レンジ [130%, 249%] は選抜後の数字で、多重比較の補正がない。38年バックテストも戦略探索後の再評価で、特徴量セットも6年側（254列）と違う（208列）。著者自身がこの3点を注記している。
- **構造回収率80%と戦略回収率187%の差の出どころ**: モデル単体が控除率どおりなのに、市場オッズとの合成と EV 閾値で回収率が倍以上になるのは、市場確率を混ぜた後の確率が確定オッズに対して何らかの系統的な差を拾っているか、選抜の産物か、のどちらか。確定オッズと市場確率の両方に同じオッズを使っているので、評価に使うオッズとモデルに入れるオッズが同一である点も注意がいる。
- **α/β の値**: β が大きい（市場を強く信じる）のはモデルが中程度の強さであることの表れ、という著者の解釈は妥当。ただし Isotonic 較正、市場合成、EV 閾値の3段がすべて同じ期間で決められているかどうかは明記されていない。
- 先行研究の紹介部分には、細部の不正確さがある（例: LambdaRank を「Burges (2007)」としている、勾配ブースティングで MNL より「2〜5ポイント精度が上がる」の根拠が示されていない）。先行研究はこのノートからではなく、各論文のノートから読む。
- 結果編（5/25予定）は本記事時点で未公開。

## keiba-ai での使い方

- JRA-VAN 系データでは、成績レコード（SE）側のオッズ・人気列を特徴量に使わない。オッズはオッズ専用レコードから購入時点のものを取る。着順・タイム・配当に由来する列はリーク列リストとして `src/keiba_ai/` に明示的に持ち、特徴量生成時に検査する。
- 回収率の評価は、モデル単体（オッズなし）の構造回収率と、市場合成＋戦略の回収率を分けて記録する。前者が控除率付近なら、後者の超過分は選抜と較正の産物を疑う。
- 戦略の格子探索をするときは、探索期間と評価期間を分ける（探索後の同じ期間で区間推定しない）。試した戦略の数を記録する。
- Benter 型合成の α/β は学習期間内で最尤推定し、テスト期間で固定する。α/β を変えたときに EV 閾値を通る件数がどれだけ変わるかを報告する。
- 集計型の血統特徴量は、事前分布での平滑化（事前の件数と全体平均で α, β を決める）を標準にする。
