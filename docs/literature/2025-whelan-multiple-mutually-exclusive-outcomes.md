# 1つのレースで複数の馬に賭けるなら、単勝ごとの Kelly より強気になる：ヘッジとしての負の期待値の賭け

> 一言で: 勝者が1人だけの事象で複数の結果に賭けるとき、凹効用（CRRA）の期待効用を正しく最大化すると、結果ごとに「当たるか外れるか」の2択 Kelly を当てはめるより賭け額が大きくなり、期待値が負の賭けもヘッジとして買う。ただしオッズが正しい（自分にエッジがない）なら、この強気の戦略は2択ルールより大きく損をする。

原本は著者のウェブサイトにある改訂稿（2024年2月、"Revised Draft"）。掲載版との差は未確認で、ページは改訂稿のもの。

## 2結果の場合：fractional Kelly は CRRA の近似にならない

価格 $p$ で1ドル払い戻す賭け（オッズ $O = 1/p$）、主観確率 $\pi$、富 $w$、効用 $U$ で $\max_x \pi U(w + x(1-p)) + (1-\pi)U(w - xp)$ を解く (p.4, 式1)。
CRRA 効用（相対的危険回避度 σ）では閉形式の解がある (p.5, 式5)。σ = 1（対数効用）が Kelly。

よく言われる「CRRA の最適解は Kelly を $1/\sigma$ 倍した fractional Kelly で近似できる」は、オッズと確率によって比率が大きく変わり、一般には成り立たない (p.3, p.5, Figure 1)。

## N 結果の場合

### 一意性がない（控除率ゼロで、売りも買いもできるとき）

結果 $i$ の価格 $p_i$、主観確率 $\pi_i$、賭けの数 $x_i$（負なら「その結果が起きない」に賭ける lay bet）として

$\max_x \sum_i \pi_i U\big(w + x_i - \sum_k x_k p_k\big)$ (p.7, 式8)

を解く。$\sum p_i = 1$（控除率ゼロ）なら、全結果に同じ額 ε を足しても資産は変わらないので、解は一意に決まらない (p.8, 式13)。1階条件の行列 $A$ の列和がゼロで階数 $N-1$ になるため (p.8, 式14-15)。

### 一意になる条件

現実の2つの要素で一意になる (p.9-10):

1. 価格の和が1を超える（控除率、overround。競争的な市場で約 4%）。
2. 買い（back）だけで、売り（lay）ができない（$x_i \ge 0$）。

価格の和が1を超えると、全結果を同額買う戦略は確実に損なので、**少なくとも1つの結果には賭けない**（非負制約が効く）(p.9-10)。

対数効用の場合、賭ける集合 $S$ が決まれば [Smoczynski 2010](./2010-smoczynski-explicit-kelly-horse-races.md) の閉形式 $x_i = w\Big(\dfrac{\pi_i}{p_i} - \dfrac{1 - \sum_{k\in S}\pi_k}{1 - \sum_{k\in S}p_k}\Big)$（式19。PDF の抽出テキストが崩れているため、1頭なら Kelly に一致することから再構成した形）で賭け数が出る。集合 $S$ は $\pi_i/p_i$ の大きい順に足していく反復法で決める (p.10)。著者は Matlab の fmincon（内点法）で任意の凹効用について解き、Smoczynski–Tomkins の2つの数値例と一致することを確認した (p.10-11)。プログラムは著者のサイトで公開。

## 例：3結果

主観確率はすべて 1/3。価格は控除率 4%（$\sum p = 1/0.96$）で、結果2は期待損失 4% に固定し、結果1と3の価格を逆向きに動かす (p.11)。

- 有利な賭けへの額は、2択 Kelly より最大で約 8% 多い (p.11)。
- **期待値が負（−4%）の結果2にも賭ける**。価格のずれが大きいとき、賭け総額は2択 Kelly より約 50% 多い (p.11, Figure 2)。
- 期待対数資金は、最もずれが大きい点で最適戦略 0.134、2択 Kelly 0.121 (p.12)。
- $p_1 = 1.04(1/3 - 0.2)$ のとき最適解は $(x_1, x_2, x_3) = (1.76, 0.32, 0)$ で、幾何平均の資産は 1.143。負の期待値の $x_2$ を外して $(1.76, 0, 0)$ にすると 1.128 に下がる (p.12, 式21-22)。結果2が起きたときの損失を和らげるヘッジとして働くため。

## シミュレーション（5結果）

ブックメーカーの確率を平均 1/5 の周りに散らし（標準偏差 γ = 0.02）、控除率 4%。賭ける側の主観確率は、ブックメーカーの確率に標準偏差 θ のずれを加える (p.17-18)。10,000 回。

主観的な最適戦略の性質 (p.20, Table 1):

| | θ=0.01 | θ=0.02 | θ=0.03 |
|---|---|---|---|
| 2択ルールに対する賭け総額の比（σ=1） | 1.33 | 1.86 | 2.19 |
| 期待値が負の賭けの割合（σ=1） | 0.119 | 0.175 | 0.212 |
| 1事象あたりの平均の賭けの数（σ=1） | 1.73 | 2.65 | 3.03 |

σ = 2（より危険回避的）でも比は 1.33〜2.44 で、むしろ大きい。

### オッズが正しいときの損失

ブックメーカーの確率が真で、賭ける側の主観的なずれは単なる誤りだとすると（対数効用）(p.23, Table 2):

| | θ=0.01 | θ=0.02 | θ=0.03 |
|---|---|---|---|
| 1回あたりの平均損失（最適戦略） | 0.060% | 0.280% | 0.590% |
| 同（2択ルール） | 0.046% | 0.150% | 0.270% |
| 賭けに出す資産の割合（最適戦略） | 1.51% | 7.11% | 14.66% |
| 同（2択ルール） | 1.14% | 3.80% | 6.73% |
| 52回後の期待資産（最適戦略） | 0.969 | 0.862 | 0.737 |
| 同（2択ルール） | 0.976 | 0.924 | 0.869 |

ランダムに資産の 3% を賭けると 52 回後に 0.939 (p.23)。どの戦略の賭けも平均損失率は控除率の 4% なので、損失は賭ける総額で決まる。最適戦略は賭け額が多いぶん損も大きい (p.23)。σ = 0.5、θ = 0.03 では1年で資産の 40% を失う (p.23, Table 4)。

著者は、一般に入手できる方法で継続的にスポーツ賭けで利益を上げられる証拠はないとし、有名なプロ（StarLizard）でも利益率は 1〜3% 程度と報じられていることを挙げる (p.22)。

## 批判的に読む

- **理論と数値例のみ**で、実データでの検証はない。シミュレーションの「主観確率のずれ」は真の確率と無関係なノイズで、本当にエッジがある場合の有利さ（Figure 3 の期待効用の差）は主観的な評価にとどまる。
- 「最適戦略は強気」の比較対象は、各結果を独立に扱う2択ルール（同じレースの複数馬にそれぞれ単独の Kelly を当てはめる）。[Smoczynski 2010](./2010-smoczynski-explicit-kelly-horse-races.md) の同時最適化と比べた新しさは、CRRA 一般への拡張と一意性の議論、性質の整理にある。
- 先行研究の Sung & Johnson（英国競馬 1,910 レース）では、最適ルールでもほとんどのレースで賭けず、複数馬への賭けや負の期待値の賭けはまれだった (p.17)。著者はこれを、推定確率がオッズに近かったためと解釈している。つまり、強気になる度合いは推定確率と市場のずれの大きさ次第。
- パリミュチュエル（自分の賭けでオッズが変わる）は扱わず、固定オッズの価格を前提とする。

## keiba-ai での使い方

- **同じレースの複数馬への単勝は、1頭ずつの Kelly を足してはいけない**。同時最適化（Smoczynski–Tomkins の閉形式、または CVXPY）で解く。本論文によれば、同時に解くと賭け額は増え、期待値がわずかに負の馬も買う。
- **ただしエッジが本物でなければ損が増える**。モデルの確率と市場の確率のずれが大きいレースほど同時最適化は強気になる。ずれの大部分が推定誤差なら、これは過大賭けそのもの。Table 2 の θ が大きい状況に近い。
- **実験案**: 仮説「単勝の同時最適 Kelly は、1頭ずつ Kelly の合計よりも、評価期間の対数成長率が低い（モデルのずれの多くが誤差のため）」。両方のルールで、賭け総額・負の期待値の買い目の割合・1レースあたりの買い目数（本論文の Table 1 の3指標）と対数成長率を出す。モデルと市場のずれの大きさ（例えば KL）でレースを層別すると、どこで差が出るかが分かる。
- 「期待値が負の買い目を、ヘッジとして買う」ことは、回収率だけでフィルタする運用では起きない。資金配分を最適化すると出てくるので、バックテストで「負の期待値の買い目」の寄与を分けて見る。
