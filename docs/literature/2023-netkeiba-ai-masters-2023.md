# AI競馬予想マスターズ2023 — 40の予想AIが仮想資金500万円×3か月で払戻額を競った第1回大会

> 一言で: netkeiba が主催した、予想AIだけが参加できる馬券大会の第1回（2023年10月7日〜12月24日）。JRA全レースを対象に、予選1・予選2（各500万円の仮想資金）と最終戦の3部構成で払戻額を競った。優勝は「AIゆま」（最終戦の回収率 395.21%）。予選は回収率70%台でも通過でき、最終戦は少数の高額的中で決まったため、順位はモデルの精度よりも賭け方（資金を使い切ること、勝負所での大振り）に強く左右された。

原本は公式の出場者一覧（`source.txt`）。大会ルール・ランキング・トップページ・レース一覧・全41件の出場者プロフィールは `attachments/` にある（`rule.txt`, `ranking.txt`, `index.txt`, `profile-<id>.txt`）。表彰式の記事（`news-party-sp.txt`）と上位入賞者のデビュー告知（`debut-info.txt`）も添付した。数値はすべてこれらの公式ページから写した。

| 項目 | 内容 |

| 使い切り | 予選の500万円は使い切る。残した分は払戻金から差し引く |
| 券種 | 単勝・複勝・枠連・馬連・馬単・ワイド・3連複・3連単（制限なし） |

| 締め切り | 発走3分前。締め切り前なら上書きで再投票できる。買い目は発走時刻に公開 |
| 順位 | 払戻金の合計 → レース的中率 → ◎勝率 の順 |

締め切りが実際の馬券と同じ発走3分前なので、直前オッズや馬体重を使える。一方で予選は払戻額で順位を決めるため、回収率が同じなら多く賭けた方が上に来る。最低1万円ルールと使い切りルールが組み合わさると、残金が1万円未満になった時点で使い切れずペナルティが確定する（湯けむり競馬部の参加記 [nami73bnami73 2023](./2023-nami73bnami73-ai-masters-2023.md) に実例がある）。

## 上位の傾向

- **予選は回収率70%台で通過できた。** 予選1 の29位（最後の通過枠）のLaplaceは回収率71.31%。予選2 の通過ライン（21位）のかめさんは74.44%。優勝したAIゆまも予選1は72.41%で、通過ぎりぎりだった（[buysake 2023](./2023-buysake-ai-masters-2023.md) も同じ点を指摘）。
- **最終戦は高額的中で決まった。** 最終戦の払戻はAIゆま 29,639,880円、AISS 21,366,410円で、3位以下（1,000万円前後）を大きく離した（`ranking.txt` の最終戦の節）。トップページの高額的中速報には、AISS の阪神2R（2歳未勝利）10,267,240円や EquineGenius の有馬記念 3,291,340円が並ぶ（`index.txt`）。
- **予選の上位が最終戦で崩れた。** 予選1の1位 SAI-O（129.30%）、2位 MEUちゃん、4位 mag は最終戦で下位か脱落した。予選の高回収率は約1か月の結果で、ばらつきが大きい。
- **優勝者は他の参加者を見て賭け方を変えた。** 表彰式の記事（`news-party-sp.txt`）で AIゆま は、他の参加者の券種・点数・的中率のデータを集めてシミュレーターを作り、優勝確率が上がる馬券戦略を日々計算していたと話している。予選落ちの心配がなくなった最終戦で大振りに切り替えたとも言う。AISS も12月の途中で戦略を変えたと話し、3位の生成系競馬予想は単勝と複勝しか当てられなかったと振り返っている。
- **「ウマい馬券」組が上位を占めた。** 最終戦の上位10のうち9が「ウマい馬券からの参戦」枠。この枠のAIは日常的に予想を運用しており、システムの安定性と運用経験で有利だった可能性がある（[thoroughlytics 2024](./2024-thoroughlytics-ai-masters-2024.md) が2024年大会で同じことを書いている）。

## 批判的に読む

- 3か月・1区間あたり8日前後の開催で、1参加者の投票は100〜300レース程度にとどまる。区間ごとの回収率は運の影響が大きく、順位をモデルの良し悪しと読むことはできない。
- 順位は払戻額で決まり、回収率の期待値ではなく分布の右裾（大穴の的中）を取りにいく方が優勝確率は上がる。優勝確率を最大化する賭け方と、長期の回収率を最大化する賭け方は別物である。
- 締め切りが発走3分前なので、最終オッズとの差は小さい。ただし大会の投票は仮想資金で、実際の売上には影響しない（自分の賭けでオッズが下がる効果がない）。
- 自己紹介は自己申告で、手法の検証はできない。

## keiba-ai での使い方

- 回収率の評価で、短期間（1か月・数百レース）の数字のばらつきを見積もる材料にする。予選の上位が最終戦で崩れた例は、短い検証期間で戦略を選ぶ危うさを示す。
- 「順位で報酬が決まる大会」と「長期の資産成長」は目的関数が違う。ケリー基準系（[Kelly 1956](./1956-kelly-information-rate.md)）は後者の話で、大会では [sol12378 2026](./2026-sol12378-masters-kit.md) のような到達確率の最適化が問題になる。
- 運用面（締め切りまでに自動で投票する、残金を追跡する）の要件定義に、参加記の失敗談を使う。
