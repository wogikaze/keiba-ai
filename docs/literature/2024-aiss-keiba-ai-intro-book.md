# AI競馬予想マスターズ2023準優勝の開発者による入門書 — TARGET のデータで2022年1年分を学び、時系列2:1分割でロジスティック回帰の複勝的中率と回収率を出す

> 一言で: netkeiba「ウマい馬券」で2020年から予想を配信し、AI競馬予想マスターズ2023で準優勝した AISS が書いた、無料の Zenn 本（2024年5月24日公開、2025年12月更新、14章・約20万字）。Excel と Python の基礎から、JRA-VAN データラボ会員向けソフト TARGET frontier JV のデータでの前処理・特徴量・モデル（ロジスティック回帰）・運用システムまでを手順で示す。手法としての新しさは少ないが、自分の配信AIの目的変数「アイスコア」の考え方（的中率と回収率のバランス、着順・着差を加味し、中穴が他馬を引き離して勝つと高くなる評価値）を明かしている点が他にない。続編『競馬AI開発～実践編～』（2025年10月、有料）は目次だけ保存した。

大会での成績は [2023年大会](./2023-netkeiba-ai-masters-2023.md)（予選1 5位 108.41%、予選2 4位 102.39%、最終戦2位 202.72%、払戻 21,366,410円）と [2024年大会](./2024-netkeiba-ai-masters-2024.md)（ステージ1の2週目に回収率下位で脱落、62.47%）。2024年のプロフィールでは開発歴約6年、ローカルPC。2023年の表彰式では、12月の途中で戦略を変えたことが功を奏し、買い目とシステムが弱かったと話している。

## データ（第3章「競馬データの準備」、第8章「データ選定と基本的なデータ加工」）

- TARGET frontier JV から出力した CSV と Excel を使う。手を動かすには JRA-VAN データラボの有料会員が必要。Windows が前提。
- 例題は2022年の JRA 全レース1年分。データを選ぶ観点として、取得できるか、定量化できて信頼できるか、過去と将来の両方で取れるか（クッション値は2020年9月から公表なので過去が足りない例）、迷ったら取っておく、を挙げる。
- 騎手のように新しい値が毎年出るカテゴリは、学習しても予測時に使えなくなる場合があると注意している。

## 特徴量（第9章「基本的な特徴量の作成」）

距離変化量、斤量変化量、ダート牝馬、ダート→芝替わり、昇級戦などの単純なフラグと差分。目的変数として「勝利」と「3着以内」のフラグを作る。予想家の予想法・馬券術を読み、データ化できるものを特徴量にすることが回収率100%超えに不可欠だとし、「勝ち馬を当てる」ではなく「馬券を攻略する」視点を勧めている。

## モデルと評価（第10章「機械学習モデリング入門」）

- レースを時系列順に並べ、前の2/3を学習、後ろの1/3をテストに分ける。
- 説明変数から単勝オッズ・着順・配当を除く。目的変数は「3着以内」（または「勝利」）。
- ロジスティック回帰で学習し、各レースで予測値最大の馬を本命とし、複勝（単勝）の的中率と回収率（払戻合計 ÷ 予測数×100円）を計算する。標準化や MinMax 正規化で的中率が上がることを示すが、1番人気の複勝的中率が60%以上あるので精度はまだ不十分だとしている。数値の結果は画像で、本文テキストにはない。
- 外れ値（例: 着差2分6秒6の記録）を四分位範囲で切り詰める方法を紹介する。
- 精度向上のアイデアとして、5年分程度にデータを増やす、GBDT・アンサンブル、k分割交差検証によるハイパーパラメータ最適化を挙げる。

## 「儲ける」ための目的変数（第10章の最終節）

- 一般的な競馬AIの買い目は、予測確率とオッズから期待値を出して高いものを買う。ただし前日などの事前予想ではオッズがほとんど使えない。
- そこで目的変数自体に「馬券的妙味」を入れる。AISS の配信用AIは「アイスコア」という評価値を目的変数にしている。計算式は非公開だが、回収率と的中率のバランスと着順・着差を総合的に加味し、中穴で他馬を引き離して勝つと高く、人気馬や大穴馬が勝っても長期的な旨味が少ないので低くする。評価値の式は開発当初からほとんど変えていない。

## 運用（第12・14章「pythonによる業務効率化と実運用に向けて」「TARGETデータを活用した運用システム構築」）

枠順確定後の出馬表データを TARGET から CSV で出力し、学習時と予測時で項目名や値が違う部分を合わせてから予測する。Discord への自動通知も扱う。

## 批判的に読む

- 例題は1年分のデータで、2:1の時系列分割1回だけの評価。回収率の数値はテキストにない。
- 目的変数「アイスコア」は式が非公開で、検証できない。人気（市場の評価）をラベル側に入れる設計は、入力のリークにはならない。ただしラベルに確定人気を使い、配信は前日に行うなら、学習した「妙味」と実際に買える時点のオッズの妙味はずれる。
- 入門書なので、特徴量や検証の工夫は実践編（有料、未保存）に回されている。

## keiba-ai での使い方

- 「勝利フラグ」ではなく、回収率の観点から設計した目的変数（人気と着差を加味した評価値）を学習する案として、keiba-ai の目的変数の比較実験に入れる。比較対象は着順・1着二値・期待値ラベル。
- 「予測時に取れないカテゴリ値」「学習時と予測時のスケーリング基準をそろえる」「TARGET の出力で学習時と予測時の項目名が違う」は、運用時の再現性チェックの項目として使える。
