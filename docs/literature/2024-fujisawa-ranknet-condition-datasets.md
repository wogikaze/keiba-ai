# 条件別に学習したペアワイズ RankNet ＋ Bradley-Terry による JRA 芝の着順予測

> 一言で: 競馬場・距離帯・馬場状態ごとにデータを分けて「2頭のどちらが先着するか」を学習するニューラルネット（RankNet 型）を作り、Bradley-Terry で各馬の強さに戻して順位付けした。図で見る限り提案法が平均では最良だが、誤差棒は他手法と大きく重なり、検証分割の記述もない、6ページの研究会報告である。

ページ番号は研究会資料の通し番号（pp.19–24）で示す。PDF の 1 ページ目が p.19。

## 要旨

1着か否かの2値分類では正例が少なく不均衡になる。著者は、同じレースを走った2頭の組を1件の学習例にするペアワイズ化でこれを避け、さらに「重馬場が得意」「長距離が得意」といった条件適性を扱うために、条件ごとに別モデルを学習する (p.19)。
各ペアの予測値を Bradley-Terry モデルで馬ごとのスカラー強さ $\lambda_i$ に集約し、降順に並べて着順予測とする (p.21)。
比較手法は Random Forest、MLP、LightGBM、Factorization Machine（FM）。要旨では XGBoost も比較したと書かれているが、本文の結果図（図2）には HRM（提案法）・FM・LGBM・MLP の4つしか載っていない (p.22)。

## モデル

全レースの結果を $D=\lbrace (r,x,s)\rbrace $（状況 $s$ で特徴 $x$ の馬が $r$ 着）とし、状況ごとに $D_s=\lbrace (r,x,s); S=s\rbrace $ に分ける (p.20)。

1. 同じレースの2頭 $i,j$ を選ぶ。
2. 共通の馬エンコーダ $f$ で $z_i=f(x_i)$, $z_j=f(x_j)$ を得る。エンコーダは全結合 76→128→256→128（BatchNorm、ReLU、Dropout 0.2 を挟む）(p.20)。入力 76 次元なので、特徴量は one-hot 展開後で 76 次元と推測される。
3. 差ベクトルエンコーダ $g(z_i,z_j)$ が 128→32→16→4→1、最後に tanh を通して $\hat y_{ij}$ を出す (pp.20–21)。
4. 教師信号は $y_{ij}=\tanh(r_j-r_i)$。$i$ が上位なら正で、着差（着順差）が大きいほど ±1 に近い (p.20)。純粋な RankNet の勝敗 0/1 ではなく、着順差を tanh で圧縮した回帰に近い。
5. Bradley-Terry: $\Pr(i \triangleright j)=\exp(\lambda_i)/(\exp(\lambda_i)+\exp(\lambda_j))$、つまり $\mathrm{logit}\Pr(i\triangleright j)=\lambda_i-\lambda_j$。ペア予測から最尤推定で $\lambda_i$ を求める（Hunter 2004 の MM 法を引用）(p.21)。

$\hat y_{ij}\in(-1,1)$ をどう Bradley-Terry の勝率（あるいは勝敗データ）に変換して最尤推定に入れたかは書かれていない（未確認）。

## データ

| 項目 | 内容 |
|---|---|
| 出典 | netkeiba から収集 (p.21) |
| 期間 | 2015年1月〜2023年3月、中央競馬 |
| 対象 | 芝レース 312,191 件（件数の単位は書かれていないが、レース数としては多すぎるので出走馬単位と推測） |
| 特徴量 | 馬体重、斤量、開催回数、騎手の競馬場別勝率・距離別勝率・対象馬との共起頻度（騎乗回数と思われる）、前走の競馬場・距離・着順 (p.21) |
| 条件分割 | place1–10（札幌〜小倉の10場）、distance1–5（<1400, 1400–1800, 1800–2200, 2200–2800, ≥2800 m）、state1–4（良・稍重・重・不良）(p.21) |

オッズ・人気は特徴量に入っていない。過去走は前走1走だけで、スピード指数や上がりタイムもない。特徴量はかなり薄い。

## 評価

指標は2つ (p.22)。

- ランキング誤差: $\bar e = (|r_1-1|+|r_2-2|+|r_3-3|)/N$。予測1〜3位の馬の実着順 $r_1,r_2,r_3$ と 1,2,3 のずれの合計。式では $N$（状況 $s$ のレース数）で割っているが、図の値が 8〜14 程度なので、実際にはレース平均の合計ずれと読むのが自然（推測）。
- トップ1正解率: 予測1位の馬が実際に1着だった割合。

## 結果

図2（誤差棒付き、数値表はない）を目で読んだおおよその値 (p.22, 図2)。

| モデル | ランキング誤差（中央値、範囲） | トップ1正解率（中央値、範囲） |
|---|---|---|
| HRM（提案） | 約 9.2（7.6–11.2） | 約 0.25（0.15–0.31） |
| FM | 約 10.9（8.4–14.3） | 約 0.20（0.11–0.29） |
| LGBM | 約 10.0（8.3–11.8） | 約 0.22（0.15–0.30） |
| MLP | 約 10.4（8.3–14.0） | 約 0.21（0.08–0.29） |

誤差棒が何の範囲か（条件別モデル間のばらつきか、標準偏差か）は書かれていない。どれも大きく重なっており、「提案手法が最も精度が高い」(p.22) は平均値での比較にとどまる。

条件別の交差評価（縦軸＝学習条件、横軸＝テスト条件のヒートマップ、図3・図4）からの所見 (pp.22–24)。

- 提案法では distance1（1400 m 未満）で学習したモデルの性能が悪い。distance5（2800 m 以上）のテストデータは、どの条件のモデルに入れても精度が高い。
- FM だけは対角成分（学習条件＝テスト条件）の誤差が小さく、条件適性を表現している「直観に合致した」結果になった (p.22)。
- place2（函館）・place3（福島）はどのモデルでも精度が低い。著者は短距離レースが多いためと推測している (p.22)。

> 距離が短いレースにおいて，競走馬のパフォーマンスに影響を与える要因を今回用いた特徴量だけでは表現できないことが原因であると考えられる． (p.22)

## 批判的に読む

- **検証分割が書かれていない。** 訓練・テストを時系列で分けたのか、ランダムに分けたのかの記述がない。2頭ペアをランダム分割すると、同じレースの別ペアが訓練とテストに分かれて入るリークが起きうる。騎手の勝率特徴も、計算期間がテスト期間を含むなら未来情報が入る。
- **distance5 の精度が高い理由は別にありうる。** 2800 m 以上は頭数が少なく、出走馬の力差も大きいレースが多い。トップ1正解率もランキング誤差も頭数に強く依存するので、頭数や人気のばらつきを揃えずに条件間比較をすると「モデルの適応性」と「レースの易しさ」が区別できない。
- **基準線がない。** 1番人気の勝率（JRA 全体でおよそ 3 割強）と比べると、トップ1正解率 0.25 は人気順より低い可能性が高い（推測、論文に比較はない）。オッズなしモデルなので当然だが、実用上の位置づけが分からない。
- 回収率、確率の較正、対数尤度は評価していない。Bradley-Terry の $\lambda$ を勝率に変換すれば評価できたはずである。
- 条件分割は場・距離・馬場を別々に1次元ずつ分けただけで、組み合わせ（例: 東京の芝 2400 m 良）ではない。分割で学習データが減る副作用の検討もない。
- RF と XGBoost は手法説明や要旨にあるが、結果図に出てこない。

## keiba-ai での使い方

- **評価の条件別分解。** 距離帯・競馬場・馬場で精度が大きく違うという所見は、指標を条件別に分けて報告する根拠になる。ただし頭数で層別するか、頭数に依存しない指標（対数損失、較正、オッズ比の改善）で比べる必要がある。仮説: 「距離帯別の精度差は、頭数と 1 番人気の支持率を揃えると大半が消える」。
- **ペアワイズ＋Bradley-Terry は Plackett-Luce の特殊形。** 1着確率の softmax（条件付きロジット）と同じ形の $\lambda$ を得るので、keiba-ai の基準モデル（conditional logit / LambdaRank）と並べる比較候補にはなる。ただし $O(n^2)$ のペア生成と、BT への集約の手間に見合う改善があるかは、この論文からは判断できない。
- **条件別モデルより、条件との交互作用特徴量。** 分割学習はデータを細らせる。FM が対角で強かったことは、「馬×条件」の交互作用（距離適性、馬場適性）を特徴量として入れれば条件別モデルは要らない、という方向を示唆する。実験案: 全体モデル＋馬の距離帯別過去成績特徴と、距離帯別モデルを時系列分割で比べる。
- 教師信号 $\tanh(r_j-r_i)$ は着順差を使うので、1着だけでなく下位の着順情報も使える。着差（秒）を使う版も考えられる。
