# 競馬AIで回収率100.6%を出し、捨てた（rindokulab 2026）

> 一言で: netkeiba を自作クローラで取得した JRA 12年半・61万頭走（後に41年・186万頭走へ拡張）で、上がり3F仮説の検証から LightGBM の複合モデルまで作り、最終的な単勝回収率は 88.9%（95%CI 82.4〜95.4%）。途中で3回「勝てる数字」（90.5%、100.6%、104%）が出たが、監査でリーク・欠損パターンリーク・消えかけのエッジだと判明して全部捨てた記録。

本ノートは本の無料公開部分（序章、第3章、第5章、追補）と、同じ著者の Zenn 記事4本に基づく。有料の第1〜2章、第4章、第6〜12章、付録（リーク防止25項目）は読んでいない。

## データ

- netkeiba から自作クローラで取得した JRA 全レース。本の執筆時点で 2014年からの約12年半・61万頭走。仮説検証は過去3走の参照期間を除いた 2019〜2026年の 20,185 レース（序章「先に結論を言ってしまう」）。
- 出版後に 2004年からの23年分・77,771レース・約109万頭走、さらに 1986〜2026年の41年・138,969レース・約186万頭走へ拡張。5系統の完全性監査（年別カバレッジ・欠損率・重複・整合性・著名レース収録）をしたと書いている（追補 4節、記事「20年前に教わった『必勝法』」）。
- 血統（父・母父の産駒成績）は別途、約6.6万頭（記事によっては17万頭）の血統ページをクロールした。
- オッズ・払戻は確定値。

## 特徴量

- 出発点は「過去3走の上がり3F平均が速い順に5頭」という単一指標（序章）。
- 複合モデルは約60特徴量（第4章のタイトル。本文は有料）。無料部分で確認できるのは、調教師の時点別勝率 `t_win_rate`、複勝率 `t_top3_rate`（修正後も重要度上位10位以内）、コース適性、血統8列（`sire_top3_rate` など）、馬場バイアス、展開予測（第5章、序章）。
- 時点別集計は `shift(1)` を挟んだ累積平均で作る。後述のとおり、調教師や種牡馬のように同じレースに複数行が出るキーでは、この方法が壊れる。

## モデルと目的変数

- LightGBM の複合モデル。目的変数の詳細は無料部分にない（単勝・複勝の的中を予測していると読める）。
- LightGBM とは別に、重みを探索するルールベースの「素朴な予想式」も維持していた（第5章の末尾）。
- 購入戦略は期待値フィルタ。オッズ上限（30倍以下）を設けている（追補 2節）。

## 評価

- walk-forward 検証。過去だけで学習し、その先の年で答え合わせをする（第5章冒頭）。追補では学習・較正・閾値選択を全部過去データだけで行い、2008年まで遡っている。
- 回収率は確定オッズ・実払戻ベース。出走取消・競走除外は購入対象外。控除率込みの実測値。
- ベースラインを3本並べる（第3章「ベースラインは3本並べて走らせる」）。
  - 人気順トップ5（市場の知識）
  - ランダム5頭（ゲームの構造。20試行、シード 1000, 1001, … で固定）
  - 全馬購入（市場平均。2022〜2026年の単勝回収率 71.4%）
- 信頼区間は年内層化ブートストラップ1万回。時代比較は購入単位のリサンプル（記事「20年前に教わった『必勝法』」の検証条件）。

## 結果

- 上がり3F上位5頭: 単勝的中率 48.0%、複勝的中率 86.3%。ランダム5頭は 37.2% / 77.1%、人気順トップ5は 81.3% / 98.4%（第3章の表）。ランダム5頭の複勝 77% は組合せ計算 1 − C(11,5)/C(14,5) ≈ 0.769 とほぼ一致する。上がり3F の本物の情報量は単勝で +10.8pt。単勝回収率は 73.0% で、全馬購入と大差ない（記事「ランダムに5頭買っても77%当たる」）。
- 頭数別のランダム5頭の複勝的中率は、17〜18頭立て 65.8%、13〜16頭 73.3%、9〜12頭 88.6%、8頭以下 97.7%（第3章「数学が最初から答えを知っていた」）。
- 最終到達点: 回収率 88.9%（95%CI 82.4〜95.4%）。全馬購入 71.4% を 17.5pt 上回り、独立した検証期間でも一貫して上回った（序章）。
- 錯覚1: 回収率 90.5% → 修正後 87.0%。原因は調教師特徴量への同厩舎僚馬の当日結果の混入（第5章）。
- 錯覚2: 回収率 100.6%（2022年単年 153.2%、オッズ上限なしの変種 170%）。血統8列を外すと 87.3% に戻る。原因は血統の取得順序による欠損パターンリーク。取得完了後に測り直すと、血統の寄与は +8.4pt（記事「機械学習で回収率100.6%が出たとき、最初に疑ったこと」）。
- 錯覚3: 特定のオッズ帯への集中と血統のふるい分けを併用した変種で回収率 104%。年10pt のペースで市場に食われて消えつつあるエッジの名残と判定（序章。詳細は有料の第10章）。
- 追補（23年・41年データ）:
  - 上がり3F上位5頭の三連複BOX（10点）は、2006〜2026年の56,751レースで的中率 8.29%（ランダムの約2.4倍）、回収率 69.25%。2009年 101.5%、2012年 100.6%、2017年 106.5% と 100% 超の年はあるが、2018年以降は一度も 70% に届かない。n 加重回帰の年次トレンドは −1.83pt/年で、単勝・複勝（−0.44pt/年）の約4倍の速さで劣化した。
  - 複合モデル（血統特徴量なし）を 2008年まで遡った walk-forward では、期待値フィルタ戦略（オッズ30倍以下）が 2008〜2013年に回収率 100.18%（11,733点、95%CI [93.3, 107.0]）。2022〜2026年は 81.5% で、差 18.7pt は P=0.0001。
  - 120超のクラス×時代のセルを調べたが、CI の下限が 100% を超えるセルはゼロ。三連複×G3 の 111.2% は、2012年オーシャンS の1レース（払戻 389,450円）を除くと 80.0%。

## 落とし穴と教訓

1. **キーが1レースに複数回現れると `shift(1)` が壊れる**（第5章）。`(trainer_id, date, race_id)` でソートして `shift(1)` すると、同じレースに出る同厩舎の2頭目以降に、1頭目のそのレースの結果が入る。複数頭出しは全行の 6.93%、汚染行は 3.48%。騎手は1レースに1頭しか乗らないので、同じコードでも無事だった。修正は「調教師×レース単位で集計し、累積和から当該レース分を引いて全出走行に展開する」。種牡馬系の特徴量にも同じ関数を使う。
2. **無作為な抜き取り監査は条件付きのリークを見逃す**。無作為50件では不一致0件だった（汚染率 3.48% で50件すべてが外れる確率は約17%）。複数頭出しに絞った50件では23件で混入が見つかった。
3. **欠損パターンが未来情報になる**（記事「データの取得順序が未来情報になる」）。血統を「直近に出走した馬から」クロールしたため、過去レースで血統が埋まっている馬は「その後も現役を続けた馬」に偏った。LightGBM は欠損をどちらの枝に流すかを学習するので、値が全部正しくてもリークが起きる。年別の血統非欠損率は 2014年 0% → 2022年 59.1% → 2024年 99.8%。検出法は、(1) 追加列の非欠損率を年・月で集計して勾配を見る、(2) is_missing フラグだけのモデルを回す、(3) その列群を外した版との A/B 切除比較。
4. **リークは良い方向にしか間違えない**。だから想定以上の上振れが出たら、集計バグ → 値のリーク → 欠損パターンのリーク の順に疑う。
5. **的中率は構造効果で水増しされる**。複勝5頭買いはランダムでも 77% 当たる。「的中率○○%」はランダムと人気順の間に置いて初めて評価できる。
6. **エッジは時代とともに閉じる**。2008〜2013年に損益分岐並みだった戦略が、2022〜2026年には 81.5% に落ちた。著者は「壁は最初からそこにあったのではなく、閉まっていく扉だった」と書いている（追補 2節）。

## 批判的に読む

- 自己監査が丁寧で、数値の出所（監査ログ、2系統独立実装、ブートストラップ）も明示されている。個人記録としては珍しい水準。ただし 88.9% のモデル本体（約60特徴量、目的変数、ハイパーパラメータ、期待値の閾値）は有料部分にあり、無料部分だけでは再現できない。
- 確定オッズで期待値を計算して買う設定なので、実運用では締切前オッズとのずれで回収率はさらに下がりうる。著者自身は続編で発走前オッズの時系列を観測している（[rindokulab 2026 オッズ時系列](./2026-rindokulab-odds-time-series.md)）。
- 2008〜2013年の 100.18% は「損益分岐と区別できない」までしか言えない。著者もそう書いている。時代差 18.7pt の有意性は購入単位のリサンプルなので、レース内の相関を無視している可能性がある。
- 年別に 100% を超えた年を挙げているが、120超のセルを見たのと同じ多重比較の構造がある（著者も単年は深追いしないと断っている）。
- 期間・頭数のどちらでもデータが大きく、選択バイアスは小さい。

## keiba-ai での使い方

- **特徴量生成のユニットテスト**: 調教師・種牡馬・馬主など、1レースに複数行が出るキーの時点別集計は、「レース単位で集計してから当該レースを引く」実装に統一する。同じレースの同じキーを持つ行で、特徴量の値が全行一致することを assert する。
- **欠損率の時間勾配チェック**: 新しいデータソースを繋いだら、列ごとの非欠損率を年別に出して、勾配があれば使用を止める。is_missing だけのモデルでの AUC チェックも評価パイプラインに入れる。
- **ベースライン3本の常設**: 実験の results.json に「人気順トップK」「ランダムK頭（シード固定）」「全馬購入」の回収率と的中率を必ず並べる。
- **標的監査**: リークが起きうる条件（複数頭出し、同日複数騎乗、出走取消、データ取得途中）を先に列挙し、その条件に絞って特徴量を独立に再計算して突き合わせる。
- **エッジの年次減衰**: 時系列分割の評価で、テスト年ごとの回収率と年次トレンド（n 加重回帰の傾き）を出す。全期間平均だけで判断しない。
- 1991年・2005年の払戻率変更でオッズの物差しが変わる点は、長期データを使うなら分割期間の設計に効く（[rindokulab 2026 オッズ時系列](./2026-rindokulab-odds-time-series.md)）。
