# 出走メンバーの組合せで順位が変わることを Factorization Machine で表す（京大 DEIM 2018）

> 一言で: 各馬の特徴ベクトルに「自分の ID」と「同じレースの全出走馬の ID」の one-hot を連結して FM に入れ、馬どうしの相性（得手・不得手）を因子ベクトルの内積で表すランキング学習を提案した。JRA の 1600万以下・オープン戦のテスト 639 レースで、オッズを使わない条件付きロジットより nDCG@3 が 0.314 → 0.345 に上がった（p.6, 表2）。

## 要旨

京都大学情報学研究科の DEIM（データ工学と情報マネジメントに関するフォーラム）2018 の発表論文（6ページ、査読なし）。
情報検索のランキング学習は「各文書の適合度はその文書とクエリだけで決まる」（適合性の独立性）を前提にしている。
競馬や選挙のように、順位が競争相手の特徴にも依存する領域ではこの前提が崩れる（p.1）。
そこで、順位付けの対象（エンティティ）の組合せを入力に含め、FM の交互作用項で相手との関係を表すモデルを提案した。

## モデル

### FM の復習（p.2）

$$\hat{y}(\mathbf{x}) = w_0 + \sum_i w_i x_i + \sum_{i<j} \langle \mathbf{v}_i, \mathbf{v}_j \rangle x_i x_j$$

$\mathbf{v}_i \in \mathbb{R}^k$ は各次元の因子ベクトル。交互作用の重みを内積で表すので、学習データで同時に観測されなかった組合せの交互作用も推定できる。

### 組合せ依存型の特徴量（p.3, 式5〜8）

レース $j$ の $i$ 番目の馬の入力 $\mathbf{x}^{(j)}_i \in \mathbb{R}^{2M+n}$ を、次の3つの連結で作る。

1. エンティティインデックス $\mathbf{x}^e_i \in \lbrace 0,1\rbrace ^M$: その馬自身の one-hot（$M$ はデータ中の全馬の数）。
2. 組合せインデックス $\mathbf{x}^{c^{(j)}} \in \lbrace 0,1\rbrace ^M$: そのレースに出走する全馬の位置が 1 のベクトル（自分も含む）。
3. 文脈ベクトル $\mathbf{x}^f_i \in \mathbb{R}^n$: 自由に設計する特徴量。実験では Lessmann ら（2012）の特徴量（過去の出走成績など）。

パラメータは $w_0$、$\mathbf{w} \in \mathbb{R}^{2M+n}$、$V \in \mathbb{R}^{(2M+n)\times k}$（式9）。
$V$ の 1〜$M$ 行目は「馬固有の性質」、$M+1$〜$2M$ 行目は「組合せの中にいるときの馬の性質」と解釈する（p.3）。
馬 $i$ と $k$ が同じレースにいるとき、$\langle \mathbf{v}_i, \mathbf{v}_{M+k}\rangle$ と $\langle \mathbf{v}_k, \mathbf{v}_{M+i}\rangle$ の符号の組で、「互いに高め合う」「互いに下げ合う」「$i$ が $k$ を得手とする」「$i$ が $k$ を不得手とする」の4つの関係を表せる、と論じている（p.3）。

### 学習（p.4, 式10）

目的変数は着順をレース内で $[0,1]$ に正規化した値 $y^{(j)}_i = (FP_i - FP_{\min})/(FP_{\max} - FP_{\min})$。
これを二乗誤差の回帰として SGD で学習する（pointwise の回帰で、ペアワイズ・リストワイズの損失ではない）。
ハイパーパラメータ $k = 8$（p.6）。

## 比較対象（p.4–5）

Benter（2008）の2段階条件付きロジットの第1段だけ。
過去成績と騎手の成績から条件付きロジットで勝率 $p_h = \exp(X_h\beta)/\sum_j \exp(X_j\beta)$ を出す（式17）。
第2段（第1段の出力とオッズを再度条件付きロジットで結合、式18〜19）も説明されているが、オッズは勝率と相関が強く他の変数の影響を隠すとして（Edelman 2007 を引用）、実験では第1段の出力だけを使う（p.5）。
つまり両手法ともオッズなしで比べている。
評価は、提案手法は予測着順の昇順、ベースラインは勝率の降順で並べた順位の nDCG。

## データ（p.4, 表1）

- JRA の 10 競馬場、2010〜2016年に開催されたレース。
- 馬の情報は「競馬新聞&スピード指数」（jiro8.sakura.ne.jp）、騎手の情報は netkeiba から抽出。
- 全体で 23,098 レース、平均出走頭数 14.51（表1）。
- このうち、各馬が比較的多くの過去出走を持つ「1600万円以下とオープン」の一般競争・特別競争に絞った 2,639 レースを使用（p.4）。新馬・未勝利・500万・1000万は除外。
- テストは 639 レース（p.6）。残り 2,000 レースが学習とみられるが、分割方法（時系列か無作為か）は書かれていない。

表1の「全競馬場」の出走数は 38,631 と書かれているが、競馬場ごとの出走数を足すと 336,024 になり、23,098 × 14.51 ≈ 335,000 とも整合する。全体行の誤植とみられる。

## 推定結果（p.6, 表2、図1〜2）

| 指標（639 レースの平均） | 条件付きロジット（CL） | 提案手法（CD） |
|---|---:|---:|
| nDCG@3 | 0.314 | 0.345 |
| nDCG@5 | 0.412 | 0.446 |

nDCG の累積度数分布（図1〜2）でも、提案手法の分布は全体的に高い側にある。
有意性の検定、乱数シードによるばらつき、関連度（gain）の定義（着順からどう作ったか）は書かれていない。

## 批判的に読む

- 比較が限定的。ベースラインは「オッズなしの条件付きロジット」だけで、同じ特徴量の FM（ID なし）、LambdaMART などのランキング学習、勾配ブースティングとの比較がない。nDCG の改善が「組合せ」の効果なのか、「馬 ID の one-hot（馬固有の効果）」の効果なのか、FM の非線形性の効果なのかを分けるアブレーションがない。
- 馬 ID を入力に使う。テストに出る馬の多くは学習期間にも出ていないと $\mathbf{v}_i$ は学習されない。分割が無作為なら、同じ馬の未来のレースが学習に入り、馬 ID の埋め込みが将来の成績を覚えるリークになる。分割方法が書かれていないので、この点は確認できない。
- 1600万以下とオープンに絞ったのは、馬 ID と組合せを学習できるだけの対戦履歴があるからで、下級条件・新馬には適用しにくい。
- 回帰の目的変数（正規化着順）は着差の情報を捨て、頭数の違いも正規化で消している。確率を出さないので、log loss・較正・回収率の評価ができない。
- サンプルは 2,639 レースと小さく、因子数 $k=8$ の $V$ は $(2M+n)\times 8$ と大きい。過学習の対策（正則化）は書かれていない。
- 実装・データは公開されていない。

## keiba-ai での使い方

- 「相手関係」を明示的にモデル化する国内の先行例。keiba-ai で相手関係を入れるなら、馬 ID の埋め込みより「同じレースの他馬の特徴量の集約」（相手の平均指数、最大指数、自分との差、レース内順位）を使う方が汎化しやすく、新しい馬にも使える。
- 仮説 H1: レース内の相対特徴（自分の指数 − 他馬の平均・最大）を加えた GBDT は、絶対値だけの GBDT より log loss が下がる。改善は主に頭数の多いレースで出る。
- 仮説 H2: 本論文の「得手・不得手」のような馬どうしの相性は、同じ馬どうしの対戦回数が少ないので、データから安定して推定できない。過去の直接対決の結果を特徴量にしても効果は小さい（アブレーションで確認）。
- 評価: 本論文は nDCG だけ。keiba-ai では順位指標は補助にとどめ、主指標は log loss / Brier とし、回収率は実オッズで計算する。nDCG の数値（0.3〜0.45）は、gain の定義が不明なので他研究とそのまま比べない。
- Benter の2段階モデル（基本モデル → オッズと結合）の説明が日本語で読める資料として参照できる。
