# 各馬のタイムを「平均・分散・飛び率」付きの分布で表し、積分と総積で全3連単の確率を出す — AI競馬予想マスターズ出場者の方法論

> 一言で: AI競馬予想マスターズ2023・2024 に「ウマ博士」で出場した著者が、自分の予想手法の基礎を説明したnote（2022年5月公開、2023年11月更新）。各馬の発揮能力（タイム）に確率分布を仮定し、1着確率を「馬iがタイムtを出す確率密度 × 他の全馬がt以上の確率」の積分で、3連単まで同様に求める。分布は不利や事故で圏外に飛ぶ確率（tobi）を混ぜた「修正ガウス分布」。能力の平均は競走条件ごとの重み付き和、分散は情報量・年齢・騎手などの関数で、重みは機械学習で推定する。最後にオッズと比べて妙味（期待値）を出す。昨年秋〜冬の成績で回収率112%と書いている。

大会での成績は [2023年大会](./2023-netkeiba-ai-masters-2023.md)（予選1 17位 82.94%、予選2 7位 98.64%、最終戦18位 24.28%）と [2024年大会](./2024-netkeiba-ai-masters-2024.md)（ステージ1 39位 73.03%）。2024年のプロフィールでは開発歴3年程度、macOS 上の C++ と Python、「順位確率の数学的な定式化が先で、後から機械学習を組み合わせた」と書いている。

## 予想の2つのアプローチ（「２種類の分析アプローチ」の節）

- ファンダメンタルズ: 馬の能力を推定して順位の確率を出す。著者の主眼。
- メタ: 投票行動や情報の不均衡からオッズの妙味を探す。公理として、オッズ（支持率）は長期的にほぼ実現確率を反映する、1倍台は過小評価・100倍以上は過大評価が起こりうる、ランダムに買うと回収率は70〜80%に収束する、を挙げる。報道や著名予想家・有名AIアカウントの予想で支持が増えた馬は過大評価になる、という例もある。

## 確率モデル（「ファンダメンタルズ分析」「修正ガウス分布」の節）

- 能力の平均 μ は「w1×スピード + w2×スタミナ + w3×パワー + …」、分散 σ² は情報量・年齢・騎手などの関数。初ダート・長期休養明け・新馬戦など証拠が少ないときは分散が大きい。
- 1着確率は、馬iのタイム密度 f_i(t) と、他の全馬kがt以上である確率 g_k(t) の総積の積を、tで積分して求める。3連単も同様に求めて全馬券のオッズと比べる（式が煩雑なので記事では省略）。
- 分布形について、馬は能力以上には速く走れないので下側に裾が長いはずだとし、ガンマ分布を仮定した文献として Henery (1981) を挙げたうえで（Henery 1981 の中心は正規分布版で、ガンマ分布版は Stern 1990。著者の引用はずれている可能性がある）、ガウス分布の下側累積確率 lp に飛び率 tobi を混ぜて「lp + (1−lp)×tobi」とする修正ガウス分布を使う。

## パラメータの推定（「パラメータ・重みの推定」「整理・工夫して学習させる」の節）

- 芝・ダート、内回り・外回り、距離、年齢、馬場、枠や脚質の有利不利などで重み w が変わる。重みを競走条件から求める部分を機械学習の対象にしている。
- 各影響因子への逆伝播を近似的に求めて学習する。偏微分が陽に求まらないので、学習中に結果への感度を記憶し、感度がそろうよう動的に調整した定数を微分係数として使う。正の値は指数関数、−1〜1 はシグモイドで表して制約なしの最適化にしている。

## 結果

「現在の成績」の節に、昨年の秋〜冬の成績で回収率112%とある。期間、レース数、券種、オッズの時点は書かれていない。

## 批判的に読む

- 確率モデルの骨格は、各馬の走破タイムに独立な分布を置いて順位確率を出す Thurstone 型の順位モデルで、正規分布なら Henery 型、指数分布なら Harville 型に対応する（[Henery 1981](./1981-henery-permutation-probabilities.md)、[Lo 1994](./1994-lo-comparison-harville-henery.md)、[Stern 1990](./1990-stern-gamma-permutations.md)）。新しいのは飛び率の混合と、分散を馬ごとに変える点。
- 学習の目的関数（何を最小化しているか）と、検証の分割方法が書かれていない。回収率112%の根拠は自己申告で、大会では最終戦で24.28%だった。
- 各馬のタイムを独立と仮定しているので、展開（ペース）による馬同士の相関は入らない。

## keiba-ai での使い方

- 馬ごとに分散を持たせた Thurstone 型モデルは、keiba-ai で Plackett-Luce（[Plackett 1975](./1975-plackett-analysis-of-permutations.md)）と比べる候補になる。特に「証拠が少ない馬ほど分散を大きくする」設計は、新馬・休み明けの扱いとして試す価値がある。
- 飛び率の混合は、人気馬の着外（競走中止・大敗）を確率モデルに入れる簡単な方法。
- 3連単の確率を順位モデルから直接出すので、組合せ馬券の期待値計算の一貫性が保てる。
