# 機械学習 全国学生大会2026 — 的中率1.96%の優勝者と、所持ポイント200万pt超が11人の2回目の学生大会

> 一言で: 2025年に続く2回目の学生大会（2026年8月29日〜9月21日。参加記によると台風の影響で延長され、9月22日に終了）。ルールは2025年とほぼ同じで、100万ptの仮想資金を API で投票し、終了時の所持ポイントを競う。完走65人。優勝の「そる」は204レースに投票して払戻が購入額を上回ったのは4レース（的中率1.96%）、所持ポイント5,504,260pt。11位までが200万ptを超え、2025年の優勝ライン（172万pt）を大きく上回った。

原本は公式トップページ（`source.txt`）。ルール（`rule.txt`）とランキング（`ranking.txt`）を添付した。出場者一覧ページ（`member_list.txt`）は中身がない。

## 上位の傾向

- **優勝は「ほとんど当たらないが、当たると大きい」賭け方だった。** そる の的中率1.96%は完走者で最も低い部類である。[sol12378 2026](./2026-sol12378-masters-kit.md) は、予測モデルは市場確率をわずかに補正するだけで、勝負は「残りレース数と所持ポイントからどの価格帯にいくら賭けるか」を動的計画法で決めた点にあり、期待値ではなくリスクを取る時期を決める道具だと書いている。平均では資金が減り、中央値ではほぼゼロになる戦略だという。
- **上位は二極化している。** 2位・3位・7位は的中率10〜15%の高配当型、6位・8位・12位は的中率60%前後の堅実型だった。
- **ノルマぎりぎりの参加者が多い。** 3位の Tommy は96レースちょうど。参加記のロロも、50万pt・96レースのノルマを1日12レース・62,500pt に割り振る運用から始めている。
- **前年の優勝者が41位。** 2025年1位と同名の SAT は 48,290pt だった（同一人物かどうかは確認できない）。100レース前後の大会では、前年の順位は翌年をほとんど予測しない。

## 批判的に読む

- 優勝ポイントは2025年の3倍以上だが、優勝者自身が運の要素が大きいと書いている。複利で全額を回す形式では、分散の大きい戦略ほど上位と全損の両方に出やすい。順位分布の両端が厚いことは、そのまま期待値の高さを意味しない。
- 解法の公式な公開はない。上位の手法は、自主的に公開した参加者（そる、ロロ）からしか分からない。

## keiba-ai での使い方

- 「目標額への到達確率を最大化する」問題と「期待対数成長率を最大化する」（ケリー）問題の違いを示す実例として使う。[sol12378 2026](./2026-sol12378-masters-kit.md) の動的計画法は前者の典型例。
- 評価では、所持ポイントや回収率だけでなく、全損した参加者の割合も見る。大会の順位表は生存者バイアスなしで全員分が見えるので、戦略の分布を見る材料になる。
