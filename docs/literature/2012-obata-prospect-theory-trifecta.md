# 3連単の全組み合わせの票数で「微小確率の過大評価」を測る（JRA 2009年）

> 一言で: JRA 2009 年の全 3,453 レース、3連単の全組み合わせ 9,398,790 件の票数を使い、単勝票数から Harville 公式で作った確率に対して3連単の得票率がどれだけ多いか（人気度）を調べた。推計オッズが高いほど人気度が上がり、特に 500 倍以上で過剰人気が目立つ (pp.218-219)。

## 何を測ったか

### 主観確率と「客観確率」

- **主観確率**: 3連単の各組み合わせの得票率（票数 / そのレースの3連単総票数）(p.217)。
- **客観確率**: 単勝の得票率を各馬の勝率とみなし、Harville (1973) の式 $P_{ABC}=P_AP_BP_C/\lbrace (1-P_A)(1-P_A-P_B)\rbrace $ で作った3連単確率 (p.217, 脚注1)。
- **人気度** = 主観確率 / 客観確率。1 を超えれば過大評価 (pp.217-218)。
- **推計オッズ** = 客観確率の逆数。10,000 なら客観確率 0.01% (p.218, 脚注3)。

単勝を「客観」とみなす理由として、著者は2点を挙げる (p.217)。単勝はギャンブル性が低く大穴バイアスがかかりにくいこと、知識の多い投票者が中心とされること。加えて、JRA の単勝の払戻率は基本 80% で3連単の 75% より高いので、合理的な投票者は単勝に多いと考える。著者は単勝の回収率から、単勝の大穴バイアスが弱いことを確認したと述べる (p.217, 脚注2)。

**実際の着順（どの組み合わせが来たか）は使っていない。** 本論文の「客観確率」は結果の頻度ではなく、別の市場（単勝）の価格から作った確率である。

### データの特徴

先行研究は的中した組み合わせの払戻から得票率を逆算していたため、的中馬券しか観測できなかった。本研究は外れ馬券を含む全組み合わせの票数を JRA から提供を受けて使っており、的中に限った分析で生じうる選択バイアス（例: インサイダーが買った組み合わせが的中しやすい）を避けられる (p.217)。また得票率でなく票数なので、売上規模を考慮した分析もできる (p.217)。

## 結果

### 図による確認

推計オッズを1万分位にまとめて人気度の平均をプロットすると右上がりで、大穴ほど過剰人気になる。本命側を拡大すると、過剰人気が起こるのは推計オッズ 500 倍以上の水準 (pp.218-219, 図1)。

### 回帰

人気度を $\ln$（推計オッズ）に単回帰（OLS、不均一分散頑健標準誤差）。0票と1票の組み合わせは除外した。0票は極端に低く、1票は極端に高い人気度を示してノイズになるためで、除外は大穴バイアスを小さく見せる方向に働くと著者は説明する (p.219)。

| 標本 | 係数（ln 推計オッズ） | $R^2$ | 件数 |
|---|---|---|---|
| 全体 | 3.788 | 0.071 | 9,272,473 |
| 第1分位（本命側） | 0.091 | 0.034 | 469,939 |
| 第5分位 | 0.243 | 0.002 | 469,939 |
| 第10分位 | 0.615 | 0.002 | 469,925 |
| 第15分位 | 2.013 | 0.005 | 468,717 |
| 第19分位 | 11.076 | 0.030 | 442,739 |
| 第20分位（大穴側） | 94.033 | 0.239 | 393,491 |

(p.218, 表1 から抜粋)。推計オッズで20分位に分けると、全分位で係数が正に有意で、本命側から大穴側へ一貫して大きくなる (p.219)。

頑健性として、(1) 0票・1票の組み合わせを含むレースを丸ごと除く、(2) 総票数上位 50% のレースに限る、(3) Harville の代わりに馬単と3連複の得票率から3連単確率を作る、を試し、いずれも同じ傾向だったとする (p.219)。ただし数値は示されていない。

## 批判的に読む

- **Harville の偏りと区別できない。** Harville は本命の2・3着確率を過大に、人気薄の2・3着確率を過小に見積もることが知られている（[Lo 1994](./1994-lo-comparison-harville-henery.md)、[Lo 2008](./2008-lo-ordering-probabilities-approximation.md)）。すると大穴側の組み合わせの「客観確率」が小さく出て、人気度は機械的に上がる。観測された右上がりのどこまでが投票者のバイアスで、どこまでが Harville の誤差かは分離されていない。頑健性 (3) の馬単・3連複ベースの推計がこの点に一部答えるはずだが、数値がない。
- **結果の頻度で検証していない。** 3連単市場が本当に大穴を買いすぎているなら、大穴側の組み合わせの的中頻度は得票率より低いはず。実際の着順を使えば検証できるが、本論文はしていない。
- **人気度の比を OLS で回帰**しており、大穴側では分母が極小で比が爆発しやすい。第20分位の係数 94 と $R^2$ 0.239 は外れ値の影響を強く受けている可能性がある。対数比での回帰や中央値での集計の方が頑健。
- 1年分（2009年）のデータ。単勝の払戻率 80%、3連単 75% という控除率の違いは、人気度の定義（得票率同士の比）では相殺されるが、払戻率の比較には効く。
- 4ページのプロシーディングスで、図1の詳細や頑健性の数値は省略されている。続報は [Obata 2014](./2014-obata-horse-racing-prospect-theory.md)。

## keiba-ai での使い方

- **3連単の期待値計算の前提**: 3連単オッズは、単勝オッズから Harville で作った確率に比べて大穴側で低い（買われすぎ）。したがって「単勝モデル → Harville → 3連単オッズと比較」で期待値を出すと、大穴側の期待値は低く、本命側の組み合わせに割安が集まりやすい。これは Harville 自体の偏りと相殺し合う可能性があるので、着順確率は discount 補正を入れて推定する。
- **仮説 H1（検証実験）**: JRA の3連単で、(a) Harville、(b) discount 補正、(c) 3連単オッズ（控除率で正規化）の3つの確率を、実際の着順に対する対数尤度で比べる。推計オッズ帯ごとに「実際の的中率 / 3連単オッズの暗黙確率」を描けば、本論文が結果を使わずに出した結論を直接確かめられる。
- **特徴量**: 単勝オッズから Harville で作った3連単確率と、実際の3連単オッズの比（人気度）を、組み合わせ単位の特徴量にできる。人気度の高い組み合わせを避けるフィルタとして使う。
- **データ**: 3連単の全組み合わせのオッズは JRA が公表しているので、票数がなくても、オッズの逆数を控除率で正規化すれば同等の分析ができる。
