# 血統の「俗説」を Claude Code に統計検定させる仮説検証ループの紹介。予測モデルと回収率は出てこない

> 一言で: 2023〜2024年の全競走成績を使い、「ゴールドシップ産駒は荒れ馬場が得意」「ディープインパクト産駒は芝中長距離が得意」といった俗説を Claude Code に EDA と検定で検証させた。前者は Mann-Whitney U 検定 p=0.33 で有意差なし、後者は p<0.001 で有意。さらに仮説の立案と検証を自動で繰り返させ、第1サイクルの一部だけが 5% 有意だった。タイトルに回収率とあるが、予測モデルや回収率の話はない。

2025年8月8日の AIAgent 勉強会での登壇資料（全 21 枚、Speaker Deck 公開は 8月11日）。原本はページのトランスクリプトで、スライド PDF を attach し、画像になっている検定結果は PDF から読んだ。ページ番号はスライド番号。

## データ

- 2023年・2024年の全競走成績（p.9）。入手元（JRA-VAN、netkeiba など）と中央・地方の別は書かれていない。

## 内容

ユースケース1（p.10〜13）: 「ゴールドシップ産駒は馬場が荒れている方が好成績」を検証。
- 重馬場系と良馬場で着順分布を比べ、Mann-Whitney U 検定 p=0.3298、Kolmogorov-Smirnov 検定 p=0.3372 で有意差なし（p.11 の画像）。
- 数値上は、重馬場の方が3着内率 29.2% 対 27.1%、平均着順 6.26 対 6.46 で良いが、勝率は 7.5% 対 9.2% で低い。
- 「体感では正しそう」なので勝利経験馬に限定しても、U 検定 p=0.5425、KS 検定 p=0.5457 で有意差なし。3着内率 31.5% 対 30.5%、勝率 9.1% 対 10.9%（p.13）。著者は俗説は正しくないと結論。

ユースケース2（p.14〜15）: 「ディープインパクト産駒は芝中長距離が得意」を、芝 1800m 以上に絞って他の種牡馬の産駒と比較。
- 着順分布の U 検定 p<0.000001、勝率のカイ二乗検定 χ²=7.38、p=0.0066 で有意（p.15）。著者は「芝1800m以上ではディープインパクト産駒フラグを特徴量に加える妥当性がある」とする。

ユースケース3（p.16〜19）: 他の種牡馬についても仮説の立案→検証→新しい仮説を自動で繰り返させた。5% 有意だったのは第1サイクルの一部で、ブラックタイド産駒の勝率が高い、ハーツクライ産駒は長距離の勝率が高い、という結果。血統の時系列トレンドや「ダート血統が芝で優位」は有意でなかった（p.17）。Claude が次に出した「季節適応性」「血統×展開適性」の仮説を、季節フラグを作ってから検証する予定としている（p.19）。

ツールの評価（p.7）: Claude Code は統計手法の選び方と複数の可視化の解釈が他ツールより妥当だったが、知識を多く与えるとコードの精度が落ち、複雑なものを部分的に簡素化してしまう（気付きにくい）弱みがあった、という著者の印象。

## 批判的に読む

- 検定の単位（馬ごとか出走ごとか）、比較群（重馬場の定義、「他の産駒」の範囲）がスライドからは分からない。出走単位の検定なら、同じ馬の繰り返し出走で独立性が崩れ、p 値が小さく出る。
- ユースケース2 の U 検定はサンプルが大きく（統計量 1.5 億）、p 値がほぼ 0 になるのは当然で、効果量が示されていない。勝率の差の大きさが不明なので、特徴量として意味があるかは判断できない。
- ユースケース3 は多数の仮説を自動生成して検定しており、多重検定の補正がない。「5% 有意だったのは一部」という結果は、偶然で出る程度の件数かもしれない。
- 産駒の強さ（クラス・人気）を調整していないので、「ディープインパクト産駒が芝中長距離で強い」はそもそも上級条件に多く出る馬が多いことの反映でもありうる。予測に使うなら、オッズや能力指標を条件付けたうえで残る効果かを見る必要がある。
- 2年分のデータで、時系列の検証や将来期間での再現は見ていない。

## keiba-ai での使い方

- LLM エージェントに仮説の生成と検定を回させる場合は、検定の単位・効果量・多重検定の補正を必須項目にした出力テンプレートを与える。この発表は、それがない場合の典型例として参照できる。
- 血統×条件の特徴（種牡馬×芝ダ×距離帯の過去成績）は、検定で選ぶより、予測時点までの集計値として特徴量に入れ、時系列の検証期間でアブレーションして採否を決める（[Sugiura 2026](./2026-sugiura-leakage-aware-evaluation.md) のブロック単位の増分評価）。
- 「俗説」の検証結果は、オッズを条件付けた残差（市場がすでに織り込んでいるか）で見ると、賭けへの意味がはっきりする。
