# データ源

keiba-ai で使う（使う予定の）データ源の一覧。
各ページには、提供内容・取得方法・提供期間・利用規約上の制約・リークの注意点をまとめる。

生データは git に入れない（`data/raw/` は `.gitignore` 済み）。
公開リポジトリなので、ここには仕様の要約と出典だけを書き、仕様書の表やデータそのものは載せない。

## JRA-VAN の位置づけ

JRA-VAN Data Lab. は JRA の公式データを配信する有料サービスで、keiba-ai の**主データ源**にする。

- 中央競馬のレース・出走馬・払戻・確定オッズが 1986 年から揃う（オッズは券種によって 1993〜2004 年から）。
- 発走前の**時系列オッズ**（単勝・複勝・枠連・馬連）を、過去のレースについても取れる。回収率の評価を「買う時点のオッズ」で行うための根拠になる。詳しくは [JRA-VAN のページ](./jra-van.md)の「時系列オッズ」の節。
- 一方で、Windows の COM 部品（JV-Link）経由でしか取れない。契約を終えたらデータを消す必要がある。詳しくは [JRA-VAN のページ](./jra-van.md)の「利用規約上の制約」の節。

## 今後足す枠

- **netkeiba**: JRA-VAN にない情報（独自指数、コメント類）があるか、スクレイピングの規約上の扱いと合わせて調べる。先行研究の多くが使っている（[先行研究](/literature)）。
- **地方競馬**: JRA-VAN Data Lab. が持つ地方競馬の情報は、2000 年以降の中央との交流競走と、中央に出走した地方馬の過去走だけ（JV-Data仕様書「データ種別一覧」の注1）。地方全体を扱うには別のデータ源が要る。[masachaco 2022](../literature/2022-masachaco-keiba-ai-data.md) によると、地方競馬DATA は JV-Data とほぼ同じ形式。

新しいデータ源を足すときは、このページの表に行を足し、同じ構成（仕組み・取得方法・提供期間・規約・リーク表）で 1 ページ書く。
